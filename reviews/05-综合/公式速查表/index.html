公式速查表（带记忆提示）

用法：左侧公式为精确数学表达，右侧"记忆提示"提供一句话助记法，“使用场景"标注该公式在考试/推导中的实际用途。按四模块组织，末尾附收敛率速查、邻近算子速查、对偶关系速查三张快速检索表。

模块一：基础概念 (Ch1-3)

1.1 凸集与凸函数

公式 名称 记忆提示 使用场景
$\theta x+(1-\theta)y \in C$ 凸集定义 “线段还在集合里” 判定可行域是否为凸集
$f(\theta x+(1-\theta)y) \le \theta f(x)+(1-\theta)f(y)$ 凸函数定义 “碗型，弦在上方” 判定目标函数是否为凸函数
$f(y) \ge f(x) + \nabla f(x)^T(y-x)$ 可微凸函数一阶条件 “切线总在函数下方” 推导收敛性界的核心工具
$\nabla^2 f(x) \succeq 0$ 凸函数二阶条件 “Hessian 半正定” 易验证的凸性判据
$\min_x f_0(x) ; \text{s.t.} ; f_i(x) \le 0, ; a_j^T x = b_j$ 凸优化标准形式 “凸目标 + 凸不等式 + 线性等式” 识别问题是否为凸优化
$\lim_{|x|\to\infty} f(x) = +\infty$ 强制性 (coercive) “跑到无穷远，函数爆炸” 结合闭凸保证极小点存在

1.2 梯度下降法核心公式

公式 名称 记忆提示 使用场景
$x_{k+1} = x_k - \alpha_k \nabla f(x_k)$ 梯度下降迭代 “沿负梯度走一步” 光滑凸优化的基本算法
$|\nabla f(x) - \nabla f(y)| \le L|x-y|$ L-smooth 条件 “梯度变化不剧烈，上限 L” 定义光滑性，所有收敛分析的起点
$f(y) \le f(x) + \nabla f(x)^T(y-x) + \frac{L}{2}|y-x|^2$ 二次上界 “函数被抛物线压住” 推导充分下降的核心不等式
$f(y) \ge f(x) + \nabla f(x)^T(y-x) + \frac{\mu}{2}|y-x|^2$ $\mu$-强凸定义 “函数托起一个抛物线” 推导线性收敛的核心不等式
$f(x_{k+1}) \le f(x_k) - \frac{1}{2L}|\nabla f(x_k)|^2$ 充分下降引理 “每步下降量 ≥ 梯度的平方/L” 所有收敛分析的基石
$\kappa = L/\mu$ 条件数 “扁碗 vs 圆碗” 决定强凸情形收敛快慢
$f(x_k - \alpha \nabla f(x_k)) \le f(x_k) - c\alpha|\nabla f(x_k)|^2$ Armijo 回溯条件 “下降够多才接受步长” 线搜索的实现依据

1.3 次梯度理论

公式 名称 记忆提示 使用场景
$g \in \partial f(x) \iff f(y) \ge f(x) + g^T(y-x), \forall y$ 次梯度定义 “全局线性下界” 不可微函数的梯度推广
$\partial |x|_1 = {g: g_i = \text{sign}(x_i),(\text{若 }x_i\neq 0);, g_i \in [-1,1],(\text{若 }x_i=0)}$ $\ell_1$ 范数次微分 “正1负-1，零点闭区间” LASSO 最优性条件
$\partial f(x) = \text{conv}{\bigcup_{i\in I(x)} \partial f_i(x)}$ 逐点上确界次微分 “取达到最大值的那些函数的次微分，再取凸包” $\max$ 函数的次梯度计算
$0 \in \partial f(x^*)$ 无约束一阶最优性条件 “零向量落进次微分集合” 凸优化充要条件
$0 \in \partial f(x^) + N_C(x^)$ 约束一阶最优性条件 “次微分 + 法锥 含零” 约束凸优化的充要条件

模块二：一阶方法 (Ch4-6)

2.1 次梯度法

公式 名称 记忆提示 使用场景
$x_{k+1} = x_k - \alpha_k g_k, ; g_k \in \partial f(x_k)$ 次梯度法迭代 “换梯度为次梯度，步长必须递减” 不可微凸函数的一阶方法
$\sum \alpha_k = \infty, ; \sum \alpha_k^2 < \infty$ 递减步长的收敛条件 “步长趋于零但不能太快” 保证次梯度法收敛
$\alpha_k = \gamma / |g_k|$ 固定增量长度步长 “每步位移长度固定” 简化步长选择

2.2 随机次梯度法

公式 名称 记忆提示 使用场景
$x_{k+1} = x_k - \alpha_k \tilde{g}_k$ SGD 迭代 “用一个随机向量替真梯度” 大规模/随机优化的基本方法
$\mathbb{E}[\tilde{g}_k \mid x_k] \in \partial f(x_k)$ 无偏估计条件 “平均来看是对的” 保证 SGD 收敛的前提

2.3 投影梯度法

公式 名称 记忆提示 使用场景
$P_C(y) = \arg\min_{x\in C} |x - y|^2$ 投影算子定义 “回到可行集的最近点” 约束优化的基本操作
$(y-x^)^T(z-x^) \le 0, ; \forall z \in C$ 投影的变分刻画 “投影点与集合夹角 ≥ 90°” 判定投影是否正确
$x_{k+1} = P_C(x_k - \alpha_k g_k)$ 投影次梯度法 “走一步 + 拍回来” 带约束的不可微优化
$P_{\mathbb{R}^n_+}(y) = \max{y, 0}$ (逐分量) 非负象限投影 “负数清零” 非负约束
$P_{[l,u]}(y)_i = \max{l_i, \min{y_i, u_i}}$ 箱子约束投影 “夹在上下界之间” 区间约束
$P(y) = r \cdot y / \max{r, |y|_2}$ $\ell_2$ 球投影 “超出半径就缩回球面” 范数约束

模块三：近端加速 (Ch7-9)

3.1 邻近梯度法 (ISTA)

公式 名称 记忆提示 使用场景
$\min_x F(x) = f(x) + g(x)$ 复合优化问题 “光滑 + 非光滑” ISTA/FISTA 的标准问题形式
$\text{prox}_g(x) = \arg\min_z {\frac{1}{2}|x-z|^2 + g(z)}$ 邻近算子定义 “离 x 不远，又让 g 小的点” 处理非光滑项 g
$z = \text{prox}_g(x) \iff x - z \in \partial g(z)$ 邻近算子的次梯度刻画 “差落在次微分里” 计算邻近算子
$x_{k+1} = \text{prox}_{\alpha g}(x_k - \alpha \nabla f(x_k))$ ISTA 迭代 “先梯度步，再邻近步” 复合凸优化的标准算法
$x_{k+1} = S_{\lambda\alpha}(x_k - \alpha \nabla f(x_k))$ ISTA 求解 LASSO “梯度步后软阈值” LASSO 的迭代求解
$\mathcal{G}\alpha(x) = \frac{1}{\alpha}(x - \text{prox}{\alpha g}(x - \alpha\nabla f(x)))$ 梯度映射 “复合目标的广义梯度” 复合优化的最优性度量

3.2 加速邻近梯度法 (FISTA/NAG)

公式 名称 记忆提示 使用场景
$y_k = x_k + \beta_k(x_k - x_{k-1})$ Nesterov 外推 “往前跳一点再算” 动量加速的核心
$t_{k+1} = \frac{1+\sqrt{1+4t_k^2}}{2}$ 动量参数递推 “$t_k \approx k/2$” FISTA 的标准动量
$\beta_k = \frac{t_k - 1}{t_{k+1}}$ 动量系数 “近似于 $\frac{k-1}{k+2}$” 外推步长
$y_k = x_k + \beta_k(x_k - x_{k-1}), ; x_{k+1} = y_k - \alpha \nabla f(y_k)$ NAG (光滑版) “在外推点算梯度” 光滑函数的加速梯度法

3.3 共轭函数与 Moreau 包络

公式 名称 记忆提示 使用场景
$f^*(y) = \sup_x {y^T x - f(x)}$ 共轭函数定义 “sup，不是 min！” 对偶问题构造的核心
$f$ 为 $\mu$-强凸 $\iff$ $f^*$ 为 $1/\mu$-smooth 强凸-光滑对偶 “强凸 ↔ 共轭光滑” 对偶方法的理论基础
$y \in \partial f(x) \iff x \in \partial f^*(y)$ 共轭次梯度关系 “互为反函数关系” 次梯度空间的对偶转换
$x_{k+1} = \text{prox}_{\alpha f}(x_k)$ 邻近点法 “全邻近，无梯度” 非光滑函数的隐式方法
$M_f(x) = \min_z {f(z) + \frac{1}{2}|z-x|^2}$ Moreau 包络 “给 f 包一层光滑皮” 非光滑函数的光滑化
$\nabla M_f(x) = x - \text{prox}_f(x)$ Moreau 包络的梯度 “邻近点法 = Moreau 上的 GD” 统一邻近点法和梯度法的视角
$x = \text{prox}f(x) + \text{prox}{f^*}(x)$ Moreau 分解 “原+共轭的邻近 = 恒等” 借助共轭函数绕开难算的邻近算子

模块四：对偶分解 (Ch10-15)

4.1 对偶方法与分解

公式 名称 记忆提示 使用场景
$\min_x f(x) + h(Ax)$ II 型复合凸优化 “f + h∘A” 对偶方法的标准原始形式
$\max_\lambda -f^(-A^T\lambda) - h^(\lambda)$ Fenchel 对偶 “减号！不是加号！” II 型复合优化的对偶问题
$\lambda_{k+1} = \text{prox}_{\alpha h^}(\lambda_k + \alpha A \nabla f^(-A^T\lambda_k))$ 对偶邻近梯度法 “在对偶空间做 ProxG” 原问题强凸时的高效方法
$\begin{cases} x_i^{k+1} = \arg\min_{x_i} {f_i(x_i) + (\lambda^k)^T A_i x_i} \ \lambda^{k+1} = \lambda^k + \alpha_k(\sum_i A_i x_i^{k+1} - b) \end{cases}$ 对偶分解法 “N 个子问题并行求，乘子汇总” 可分离约束优化并行求解
$L_\rho(x, \lambda) = f(x) + \lambda^T(Ax-b) + \frac{\rho}{2}|Ax-b|^2$ 增广 Lagrange 函数 “Lagrange + 二次惩罚” 乘子法和 ADMM 的基础
$\begin{cases} x^{k+1} = \arg\min_x L_\rho(x, \lambda^k) \ \lambda^{k+1} = \lambda^k + \rho(Ax^{k+1} - b) \end{cases}$ 乘子法迭代 “无约束 min + 乘子更新” 带等式约束的优化

4.2 DR 分裂与 ADMM

公式 名称 记忆提示 使用场景
$R_f = 2\text{prox}_f - I$ 反射算子 “邻近映射的镜面反射” DR 分裂法的基本算子
$z^{k+1} = \frac{1}{2}(I + R_f R_g)(z^k)$ DR 分裂 (不动点) “两个反射的平均” I 型复合优化
$\begin{cases} x^{k+1} = \arg\min_x L_\rho(x, z^k, \lambda^k) \ z^{k+1} = \arg\min_z L_\rho(x^{k+1}, z, \lambda^k) \ \lambda^{k+1} = \lambda^k + \rho(Ax^{k+1} + Bz^{k+1} - c) \end{cases}$ ADMM 三步骤 “交替而非联合” 两块可分离凸优化
$\min_{x,z} f(x) + g(z) ; \text{s.t.} ; Ax + Bz = c$ ADMM 标准问题 “两块，线性耦合” ADMM 适用的标准形式
$x^{k+1} = (A^TA + \rho I)^{-1}(A^Tb + \rho z^k - \lambda^k)$ ADMM 求解 LASSO (x 步) “岭回归闭式解” 光滑子问题的闭式
$z^{k+1} = S_{\lambda/\rho}(x^{k+1} + \lambda^k/\rho)$ ADMM 求解 LASSO (z 步) “软阈值闭式解” 非光滑子问题的闭式

4.3 PDHG

公式 名称 记忆提示 使用场景
$\min_x f(x) + g(Kx)$ PDHG 原始问题 “I 型复合的推广” PDHG 的标准问题形式
$\begin{cases} x^{k+1} = \text{prox}{\tau f}(x^k - \tau K^T y^k) \ \bar{x}^{k+1} = x^{k+1} + \theta(x^{k+1} - x^k) \ y^{k+1} = \text{prox}{\sigma g^*}(y^k + \sigma K \bar{x}^{k+1}) \end{cases}$ PDHG 迭代 “原始步 + 外推 + 对偶步” 原始-对偶邻近法
$\tau\sigma|K|^2 < 1$ PDHG 步长条件 “两步步长乘积小于 1/∥K∥²” 保证收敛的步长约束

收敛率速查

光滑方法

方法 光滑凸 强凸 记忆方法
GD $O(1/k)$ $O\left(\left(\frac{\kappa-1}{\kappa+1}\right)^{2k}\right)$ “光滑则慢 O(1/k)”
NAG $O(1/k^2)$ $O((1 - \sqrt{\mu/L})^k)$ “加速平方，强凸指数”
ISTA $O(1/k)$ $O\left(\left(\frac{\kappa-1}{\kappa+1}\right)^{2k}\right)$ “同 GD”
FISTA $O(1/k^2)$ $O((1 - \sqrt{\mu/L})^k)$ “同 NAG”

次梯度方法

方法 凸 (Lipschitz) 强凸 记忆方法
次梯度法 (递减步长) 最优值 $O(1/\sqrt{k})$ $O(1/k)$ “次梯度更慢，开方号”
SGD $\mathbb{E}[f(\bar{x}_k)-f^*] = O(1/\sqrt{k})$ $O(1/k)$ (衰减步长) “同次梯度”
投影次梯度法 $O(1/\sqrt{k})$ $O(1/k)$ “投影不改变率”

达到 $\epsilon$ 精度所需迭代次数（复杂度）

方法 凸 强凸 记忆方法
GD $O(1/\epsilon)$ $O(\kappa \log(1/\epsilon))$ “凸=一次方，强凸=对数”
FISTA / NAG $O(1/\sqrt{\epsilon})$ $O(\sqrt{\kappa} \log(1/\epsilon))$ “加速=开根号，条件数也开”
次梯度法 $O(1/\epsilon^2)$ $O(1/\epsilon)$ “次梯度二次方，慢一个量级”

对偶 / 分裂方法

方法 本质 收敛特点 记忆方法
对偶邻近梯度 对偶空间的 ProxG 原问题强凸时线性收敛 “对偶也梯度”
对偶分解法 对偶次梯度法 $O(1/\sqrt{k})$ (慢) “分解=次梯度速度”
乘子法 对偶邻近点法 $O(1/k)$ 或线性 “乘子=邻近点”
DR 分裂法 不动点迭代 一般次线性 “不动点=慢”
ADMM 对偶 DR 分裂法 一般 $O(1/k)$ “ADMM=DR对偶”
PDHG 预条件邻近点法 一般 $O(1/k)$ “PDHG=预条件”

邻近算子速查

函数 $g(x)$ $\text{prox}_g(x)$ 记忆方法
$\delta_C(x)$ (指示函数) $P_C(x)$ “指示→投影”
$\lambda|x|_1$ $S_\lambda(x) = \text{sign}(x)\cdot\max{|x|-\lambda, 0}$ “绝对值→软阈值”
$\lambda|x|_2$ (组LASSO) $\max{1 - \lambda/|x|_2, 0} \cdot x$ “ℓ₂ 范数→块状软阈值”
$\lambda|X|_*$ (核范数) $\text{SVT}\lambda(X) = U S\lambda(\Sigma) V^T$ “核范数→SVD 软阈值”
$\frac{1}{2}|Ax-b|^2$ $(I + A^TA)^{-1}(x + A^Tb)$ “最小二乘→岭回归”
$|\cdot|_\infty$ 指示函数 $\text{clip}(x, \lambda) = \min{\max{x, -\lambda}, \lambda}$ “ℓ∞ 指示→裁剪”

对偶关系速查

关系 数学表述 记忆方法
邻近点法 = Moreau 上 GD $x_{k+1} = \text{prox}_{\alpha f}(x_k) = x_k - \alpha \nabla M_f(x_k)$ “邻近=隐式梯度”
乘子法 = 对偶邻近点法 $\lambda_{k+1} = \text{prox}_{\alpha d^*}(\lambda_k)$ “乘子=对偶邻近”
ADMM = 对偶 DR 分裂法 乘子法 → 交替子问题 → 等价 DR “ADMM=DR的对偶”
PDHG $\supseteq$ DR $K=I, \theta=1$ 时 PDHG 退化为 DR “PDHG 含 DR”
强凸 $\iff$ 共轭光滑 $f$ 为 $\mu$-强凸 $\iff$ $f^*$ 为 $1/\mu$-smooth “强凸对光滑”
投影 = 指示函数的邻近算子 $P_C = \text{prox}_{\delta_C}$ “投影=特殊邻近”
软阈值 = $\ell_1$ 的邻近算子 $\text{prox}_{\lambda|\cdot|1} = S\lambda$ “ℓ₁→软阈值”
Moreau 分解 $x = \text{prox}f(x) + \text{prox}{f^*}(x)$ “原+共轭邻近=恒等”
次梯度的共轭关系 $y \in \partial f(x) \iff x \in \partial f^*(y)$ “互反的次梯度”
