第1章：凸优化基础

核心思想：凸性是优化问题"好解"的根本原因——在凸函数上，任何一个局部极小点自动是全局极小点。这意味着我们不需要担心"走错路掉进坑里"，只要沿着下降方向一路走到底，就能到达最优解。

前置知识回顾

在深入学习本章之前，请确认你已掌握以下基础知识（每一项只需一句话即可唤起记忆）：

知识领域 关键概念 一句话说明
线性代数 向量 $x \in \mathbb{R}^n$ $x$ 是一个含有 $n$ 个实数分量的列向量，可以想象成 $n$ 维空间中的一个点
线性代数 矩阵 $A \in \mathbb{R}^{m \times n}$ $A$ 是一个拥有 $m$ 行、$n$ 列的数值阵列，代表从 $\mathbb{R}^n$ 到 $\mathbb{R}^m$ 的线性变换
线性代数 内积 $\langle x, y \rangle = x^T y = \sum_{i=1}^n x_i y_i$ 两个向量的"点乘"，结果是一个标量，反映两者方向的相似程度
线性代数 正定矩阵 $A \succ 0$ 对任意非零向量 $x \neq 0$，都有 $x^T A x > 0$，即所有特征值均严格大于零
线性代数 半正定矩阵 $A \succeq 0$ 对任意 $x$，都有 $x^T A x \geq 0$，即所有特征值均 ≥ 0
微积分 梯度 $\nabla f(x)$ 函数 $f$ 在点 $x$ 处的"最陡上升方向"，是一个 $n$ 维列向量，由所有偏导数组成
微积分 Hessian 矩阵 $\nabla^2 f(x)$ 梯度的梯度，一个 $n \times n$ 的对称矩阵，记录函数在点 $x$ 处的"弯曲程度"
微积分 一阶 Taylor 展开 $f(y) \approx f(x) + \nabla f(x)^T (y-x)$，用切平面（线性函数）局部近似原函数
微积分 二阶 Taylor 展开 $f(y) \approx f(x) + \nabla f(x)^T (y-x) + \frac{1}{2}(y-x)^T \nabla^2 f(x)(y-x)$，用二次曲面局部近似

1.1 凸集

1.1.1 定义与直观理解

定义：设 $C$ 是 $\mathbb{R}^n$（$n$ 维实数空间）中的一个集合。若对 $C$ 中任意两点 $x$ 和 $y$（都是 $n$ 维列向量），以及任意比例系数 $\theta \in [0, 1]$，它们的"凸组合"（加权平均）始终留在 $C$ 内部，则称 $C$ 为凸集。

$$\boxed{\theta x + (1-\theta)y \in C, \quad \forall x, y \in C, \; \forall \theta \in [0, 1]}$$

逐字解释：

  • $\theta x + (1-\theta)y$：将 $x$ 和 $y$ 按比例 $\theta$ 和 $(1-\theta)$ 混合，得到线段上的一个点。当 $\theta = 0$ 时该点就是 $y$，当 $\theta = 1$ 时该点就是 $x$，当 $\theta = 0.5$ 时就是两点正中间。
  • 要求这段线段上每一个点都在 $C$ 中，不能有一个"跑出去"。

直观类比：想象一个实心圆盘——在盘内任意选两点，连接它们的线段完全在盘内。而月牙形（弯月）不是凸集，因为从一端到另一端的线段会穿过缺口（月牙的凹陷部分）。

1.1.2 常见凸集清单

集合名称 数学表达式 为什么是凸集
全空间 $\mathbb{R}^n$ 任意两个 $n$ 维向量的凸组合仍然是 $n$ 维向量，当然属于 $\mathbb{R}^n$
半空间 ${x \in \mathbb{R}^n \mid a^T x \leq b}$ 线性不等式定义：若 $a^T x \leq b$ 且 $a^T y \leq b$，则 $a^T(\theta x + (1-\theta)y) = \theta a^T x + (1-\theta)a^T y \leq \theta b + (1-\theta)b = b$
超平面 ${x \in \mathbb{R}^n \mid a^T x = b}$ 同上，将 $\leq$ 换成 $=$ 即可：$a^T(\theta x + (1-\theta)y) = \theta b + (1-\theta)b = b$
多面体 ${x \mid Ax \leq b, ; Cx = d}$ 有限个半空间和超平面的交集，而凸集的交集仍然是凸集
椭球 ${x \mid (x-x_c)^T P^{-1}(x-x_c) \leq 1}$，$P \succ 0$ 由二次不等式定义，本质是一个被"压扁"的球。验证：对满足条件的 $x, y$，权重组合也满足（由 $P^{-1}$ 的正定性保证）
范数球 ${x \mid |x - x_c| \leq r}$ 对任意 $x, y$ 满足 $|x-x_c| \leq r$ 和 $|y-x_c| \leq r$，由三角不等式 $|\theta x + (1-\theta)y - x_c| \leq \theta|x-x_c| + (1-\theta)|y-x_c| \leq r$
半正定锥 $\mathbb{S}^n_+ = {X \in \mathbb{S}^n \mid X \succeq 0}$ $\mathbb{S}^n$ 是所有 $n \times n$ 对称矩阵的集合。若 $X \succeq 0$ 且 $Y \succeq 0$（即两者均为半正定矩阵），则对任意 $\theta \in [0, 1]$，$\theta X + (1-\theta)Y$ 也是半正定矩阵
概率单纯形 ${x \in \mathbb{R}^n \mid x_i \geq 0, ; \sum_{i=1}^n x_i = 1}$ 非负象限（凸集）与超平面 ${x \mid \sum x_i = 1}$（凸集）的交集，凸集的交仍凸

1.1.3 非凸集的典型反例

反例集合 表达式 为什么不凸
单位球面 ${x \mid |x| = 1}$ 取 $x$ 和 $-x$（模长均为 1），中点 $0.5x + 0.5(-x) = 0$，模长为 $0 \neq 1$，不在球面上
整数集 $\mathbb{Z}^n$ 取 $0$ 和 $1$，中点 $0.5$ 不是整数
非凸多边形 如月牙形 存在两点其连线段穿过凹陷区域
开口圆盘 ${x \mid |x| < 1}$ 虽然是凸集！（开圆盘内任意两点连线都在盘内）——说明"开"与凸无关

记忆要点：凸 ≠ 闭。开圆盘是凸集但不是闭集。闭集要求包含所有极限点，凸集只要求包含线段。

1.1.4 保凸运算

已知若干凸集，通过以下运算可以构造出新的凸集：

运算 说明 为什么保凸
任意多个凸集的交 $C = \bigcap_{i \in I} C_i$ 若 $x, y$ 属于所有 $C_i$，则它们的凸组合也属于每个 $C_i$，因此属于交集 $C$
仿射变换 $f(C) = {Ax + b \mid x \in C}$，$A \in \mathbb{R}^{m \times n}, b \in \mathbb{R}^m$ 取任意 $u, v \in f(C)$，存在 $x, y \in C$ 使 $u=Ax+b, v=Ay+b$，则 $\theta u + (1-\theta)v = A(\theta x + (1-\theta)y) + b \in f(C)$
Minkowski 和 $C_1 + C_2 = {x+y \mid x \in C_1, y \in C_2}$ 取 $u_1+u_2$ 和 $v_1+v_2$，凸组合为 $\theta(u_1+u_2)+(1-\theta)(v_1+v_2) = [\theta u_1+(1-\theta)v_1] + [\theta u_2+(1-\theta)v_2] \in C_1 + C_2$
直积（Cartesian 积） $C_1 \times C_2 = {(x, y) \mid x \in C_1, y \in C_2}$ 各分量独立取凸组合，每个分量留在各自的凸集中

注意：凸集的并一般不保凸。例如 $C_1 = {0}$ 和 $C_2 = {1}$ 都是一维凸集，但它们的并 ${0, 1}$ 不是凸集（中点 $0.5$ 不在其中）。

1.2 凸函数

1.2.1 定义（Jensen 不等式）

定义：设 $f: \mathbb{R}^n \to \mathbb{R} \cup {+\infty}$（即 $f$ 以 $n$ 维实向量为输入，输出一个实数或 $+\infty$）。函数 $f$ 称为凸函数，若其定义域 $\text{dom} f = {x \mid f(x) < +\infty}$ 是凸集，且对任意 $x, y \in \text{dom} f$ 和 $\theta \in [0, 1]$：

$$\boxed{f(\theta x + (1-\theta)y) \leq \theta f(x) + (1-\theta)f(y)}$$

逐字解释：

  • 左边 $f(\theta x + (1-\theta)y)$：先取 $x$ 和 $y$ 的加权平均点，再在该点处计算函数值。
  • 右边 $\theta f(x) + (1-\theta)f(y)$：先在 $x$ 和 $y$ 处分别计算函数值，再对函数值取加权平均。
  • 不等式说的是：函数曲线上任意两点间的"割线"（即连接 $(x, f(x))$ 和 $(y, f(y))$ 的直线段）始终位于函数图像的上方——这正是"碗形"（开口向上，$\cup$）的数学刻画。

重要提醒：中文日常语义中，“凸"通常指向外鼓出（如凸透镜，$\cap$ 形），但数学中凸函数是 $\cup$ 形（开口向上）。这是最常见的入门混淆。

1.2.2 一阶条件

定理：设 $f$ 为可微函数（即梯度 $\nabla f(x)$ 在定义域内处处存在）。$f$ 为凸函数当且仅当：

$$\boxed{f(y) \geq f(x) + \nabla f(x)^T (y-x), \quad \forall x, y \in \text{dom} f}$$

逐字解释：对任意点 $x$，以 $x$ 为基点的"一阶 Taylor 近似” $f(x) + \nabla f(x)^T (y-x)$（即 $x$ 处的切平面）始终位于原函数 $f(y)$ 的下方，对所有 $y$ 成立。“切线永远托住函数图形”。

必要性证明（凸 $\Rightarrow$ 一阶条件）——每一步都详细拆解：

Step 1：从凸函数定义出发。对任意 $x, y$ 和 $\theta \in (0, 1]$：

$$f(x + \theta(y-x)) = f(\theta y + (1-\theta)x) \leq \theta f(y) + (1-\theta)f(x)$$

这里将 $\theta x + (1-\theta)y$ 换了一种写法：$\theta y + (1-\theta)x = x + \theta(y-x)$，两者等价，因为 $\theta y + (1-\theta)x = \theta y + x - \theta x = x + \theta(y-x)$。

Step 2：移项，将 $f(x)$ 移到左边：

$$f(x + \theta(y-x)) - f(x) \leq \theta [f(y) - f(x)]$$

Step 3：两边同除以 $\theta > 0$（正数除不等式方向不变）：

$$\frac{f(x + \theta(y-x)) - f(x)}{\theta} \leq f(y) - f(x)$$

Step 4：令 $\theta \to 0^+$（从正侧趋近于 0）。左边是一个极限形式——这正是方向导数的定义：

$$\lim_{\theta \to 0^+} \frac{f(x + \theta(y-x)) - f(x)}{\theta} = \nabla f(x)^T (y-x)$$

这里用到了微积分中的方向导数公式：$\lim_{t \to 0^+} \frac{f(x+td)-f(x)}{t} = \nabla f(x)^T d$，其中取 $d = y-x$。

Step 5：取极限后不等式保持（极限保号性）：

$$\nabla f(x)^T (y-x) \leq f(y) - f(x)$$

Step 6：移项得 $f(y) \geq f(x) + \nabla f(x)^T (y-x)$，证毕。

充分性证明（一阶条件 $\Rightarrow$ 凸）——需要证明定义式成立：

Step 1：对任意 $x, y$，令 $z = \theta x + (1-\theta)y$（连接 $x$ 和 $y$ 的线段上的一点，加权系数 $\theta$）。

Step 2：对点对 $(z, x)$ 应用一阶条件：

$$f(x) \geq f(z) + \nabla f(z)^T (x - z) \quad \cdots \quad (1)$$

对点对 $(z, y)$ 应用一阶条件：

$$f(y) \geq f(z) + \nabla f(z)^T (y - z) \quad \cdots \quad (2)$$

Step 3：对 $(1)$ 乘 $\theta$，对 $(2)$ 乘 $(1-\theta)$，然后相加：

$$\theta f(x) + (1-\theta)f(y) \geq \theta[f(z) + \nabla f(z)^T (x-z)] + (1-\theta)[f(z) + \nabla f(z)^T (y-z)]$$

Step 4：整理右边。先合并 $f(z)$ 的系数：$\theta f(z) + (1-\theta)f(z) = f(z)$。

再合并梯度项：

$$\theta \nabla f(z)^T (x-z) + (1-\theta) \nabla f(z)^T (y-z) = \nabla f(z)^T [\theta(x-z) + (1-\theta)(y-z)]$$

Step 5：计算括号内：

$$\theta(x-z) + (1-\theta)(y-z) = \theta x - \theta z + (1-\theta)y - (1-\theta)z$$

$$= [\theta x + (1-\theta)y] - [\theta + (1-\theta)]z = z - z = 0$$

Step 6：因此梯度项消失，得到：

$$\theta f(x) + (1-\theta)f(y) \geq f(z) = f(\theta x + (1-\theta)y)$$

这正是凸函数的定义式！证毕。

几何直觉：一阶条件是最重要的凸函数判定工具。“切线托函数”——对于一元函数 $f(x) = e^x$，在任意点 $x_0$ 画切线，指数曲线永远在切线上方。这就是一阶条件的直观含义。

1.2.3 二阶条件

定理：设 $f$ 为二次可微函数（即 Hessian 矩阵 $\nabla^2 f(x)$ 处处存在）。$f$ 为凸函数当且仅当 Hessian 矩阵在定义域上处处半正定：

$$\boxed{\nabla^2 f(x) \succeq 0, \quad \forall x \in \text{dom} f}$$

回忆：$\nabla^2 f(x) \succeq 0$ 表示对任意方向向量 $d \in \mathbb{R}^n$（$n$ 维列向量），有 $d^T \nabla^2 f(x) d \geq 0$。通俗地说，沿任何方向看，“弯曲"都是向上的（不向下凹）。

必要性推导（凸 $\Rightarrow$ Hessian 半正定）：

Step 1：对任意 $x$ 和任意方向 $d$，由一阶条件（Step 6 已证一阶条件等价于凸性）：

$$f(x + td) \geq f(x) + \nabla f(x)^T (td) = f(x) + t \nabla f(x)^T d$$

Step 2：左边用二阶 Taylor 展开（带 Peano 余项——即 $o(t^2)$ 表示比 $t^2$ 更快趋近于零的项）：

$$f(x + td) = f(x) + t \nabla f(x)^T d + \frac{t^2}{2} d^T \nabla^2 f(x) d + o(t^2)$$

Step 3：将 Step 2 代入 Step 1 的不等式左边，消去公共项 $f(x) + t \nabla f(x)^T d$：

$$\frac{t^2}{2} d^T \nabla^2 f(x) d + o(t^2) \geq 0$$

Step 4：两边同除以 $\frac{t^2}{2} > 0$：

$$d^T \nabla^2 f(x) d + \frac{o(t^2)}{t^2/2} \geq 0$$

Step 5：令 $t \to 0$，此时 $\frac{o(t^2)}{t^2} \to 0$（这就是小o的定义），得到：

$$d^T \nabla^2 f(x) d \geq 0, \quad \forall d \in \mathbb{R}^n$$

Step 6：由 $d$ 的任意性，这正是 $\nabla^2 f(x) \succeq 0$ 的定义，证毕。

充分性推导（Hessian 半正定 $\Rightarrow$ 凸）：

Step 1：由带 Lagrange 余项的 Taylor 展开（存在 $\xi$ 在线段 $[x, y]$ 上，即 $\xi = x + t(y-x)$ 对某 $t \in (0, 1)$）：

$$f(y) = f(x) + \nabla f(x)^T (y-x) + \frac{1}{2}(y-x)^T \nabla^2 f(\xi)(y-x)$$

带 Lagrange 余项的 Taylor 展开：$f(y) = f(x) + \nabla f(x)^T (y-x) + \frac{1}{2}(y-x)^T \nabla^2 f(\xi)(y-x)$，其中 $\xi$ 位于 $x$ 和 $y$ 之间。这一公式要求 $f$ 二阶可微且定义域为凸集。

Step 2：因为 $\nabla^2 f(\xi) \succeq 0$，二次项非负：

$$\frac{1}{2}(y-x)^T \nabla^2 f(\xi)(y-x) \geq 0$$

Step 3：代入 Step 1，得 $f(y) \geq f(x) + \nabla f(x)^T (y-x)$，即一阶条件成立。由 1.2.2 节的充分性证明，一阶条件 $\Rightarrow$ 凸性，证毕。

1.2.4 为什么凸函数的驻点就是全局极小点？

结论：若 $f$ 是可微凸函数，且 $\nabla f(x^) = 0$（即 $x^$ 是驻点），则 $x^*$ 必为 $f$ 的全局极小点。

推导——只用一行不等式即可证明：

由凸函数的一阶条件（对任意 $y$）：

$$f(y) \geq f(x^*) + \nabla f(x^*)^T (y - x^*)$$

将 $\nabla f(x^*) = 0$ 代入：

$$f(y) \geq f(x^*) + 0^T (y - x^*) = f(x^*), \quad \forall y$$

这直接说明对任意 $y$，$f(y) \geq f(x^)$，即 $x^$ 是全局极小点。

为什么这很重要？ 对于一般非凸函数，$\nabla f(x^) = 0$ 只能保证 $x^$ 是驻点——可能是极小、极大或鞍点。但对凸函数，驻点自动就是全局极小！这大大简化了优化算法：我们只需要找到梯度为零的点就行了。

1.2.5 典型凸函数清单

函数 表达式 凸性条件 判定方法
二次函数 $f(x) = \frac{1}{2}x^T Q x + b^T x + c$ $Q \succeq 0$（$Q$ 为对称半正定矩阵） Hessian：$\nabla^2 f = Q \succeq 0$
指数函数 $f(x) = e^{ax}$（$a \in \mathbb{R}$） 恒凸 二阶导数 $a^2 e^{ax} \geq 0$
负对数 $f(x) = -\ln x$（$x > 0$） 恒凸 二阶导数 $1/x^2 > 0$
范数 $f(x) = |x|$（任意范数） 恒凸（但非光滑） 三角不等式直接验证定义
Logistic损失 $f(x) = \ln(1 + e^x)$ 恒凸 二阶导数 $\frac{e^x}{(1+e^x)^2} > 0$
对数-求和-指数 $f(x) = \ln\left(\sum_{i=1}^n e^{x_i}\right)$ 恒凸 Hessian半正定（可验证）
$\ell_p$ 范数 $f(x) = |x|_p = (\sum_i x_i ^p)^{1/p}$
max函数 $f(x) = \max{x_1, x_2, \ldots, x_n}$ 恒凸 仿射函数的逐点最大，保凸运算
带约束的指示函数 $\delta_C(x) = \begin{cases} 0 & x \in C \ +\infty & x \notin C \end{cases}$ $C$ 为凸集时凸 验证定义：对 $x, y \in C$，组合 $\theta x+(1-\theta)y \in C$，故指示为 $0 = \theta \cdot 0 + (1-\theta) \cdot 0$

典型反例（非凸函数）：

  • $f(x) = x^3$：二阶导数 $6x$ 在 $x < 0$ 时为负，不是凸函数
  • $f(x) = \sin x$：二阶导数 $-\sin x$ 振荡变号，不是凸函数
  • $f(x) = -x^2$：二阶导数恒负（$-2 < 0$），这是凹函数
  • $f(x) = -e^x$：二阶导数 $-e^x < 0$，光滑但凹

1.2.7 保凸运算

已知凸函数可通过以下运算组合产生新的凸函数：

运算名称 公式 为什么保凸
非负加权和 $f = \sum_{i} w_i f_i$，$w_i \geq 0$ 展开定义：$f(\theta x+(1-\theta)y) = \sum w_i f_i(\cdots) \leq \sum w_i[\theta f_i(x)+(1-\theta)f_i(y)] = \theta f(x)+(1-\theta)f(y)$
仿射复合 $h(x) = f(Ax + b)$ 变量替换：$h(\theta x+(1-\theta)y) = f(A(\theta x+(1-\theta)y)+b) = f(\theta(Ax+b)+(1-\theta)(Ay+b)) \leq \theta f(Ax+b)+(1-\theta)f(Ay+b) = \theta h(x)+(1-\theta)h(y)$
逐点最大 $f(x) = \max_{i=1,\ldots,m} f_i(x)$ 设 $k$ 使 $f_k(\theta x+(1-\theta)y)$ 取最大值，则 $f(\theta x+(1-\theta)y) = f_k(\cdots) \leq \theta f_k(x)+(1-\theta)f_k(y) \leq \theta f(x)+(1-\theta)f(y)$
逐点上确界 $f(x) = \sup_{y \in \mathcal{A}} g(x, y)$，每 $g(\cdot, y)$ 凸 同理：上确界一族凸函数仍是凸函数

记忆口诀：「凸函数取 max 仍凸，凹函数取 min 仍凹。」注意逐点最小（$\min_i f_i(x)$ 对凸函数族）不保凸！例如 $f_1(x) = x$ 和 $f_2(x) = -x$ 都是凸函数（仿射函数），但 $\min{x, -x} = -|x|$ 是凹函数。

1.3 凸优化问题

1.3.1 标准形式

凸优化问题的标准形式为：

$$\boxed{\begin{aligned} \min_{x \in \mathbb{R}^n} \quad & f_0(x) \\ \text{s.t.} \quad & f_i(x) \leq 0, \quad i = 1, 2, \ldots, m \\ & a_j^T x = b_j, \quad j = 1, 2, \ldots, p \end{aligned}}$$

各部分的逐字解释：

  • $x \in \mathbb{R}^n$：待求解的决策变量，是一个 $n$ 维实数列向量。
  • $f_0(x)$：目标函数，必须是凸函数。我们要让它尽可能小。
  • $f_i(x) \leq 0$：不等式约束，共 $m$ 个，每个 $f_i$ 都必须是凸函数。要求 $x$ 只能取使所有 $f_i(x) \leq 0$ 的值。
  • $a_j^T x = b_j$：等式约束，共 $p$ 个，每个必须是仿射函数。这很关键——等式约束不能是非线性的，否则可行集可能不再是凸集。这里 $a_j \in \mathbb{R}^n$ 是系数向量，$b_j \in \mathbb{R}$ 是常数。

为什么等式约束必须是仿射的？ 考虑约束 $h(x) = 0$。若 $h$ 是凸函数，${x \mid h(x) \leq 0}$ 是凸集，但 ${x \mid h(x) = 0}$ 一般不是。唯一例外是 $h$ 既是凸又是凹——即仿射函数。例如：${x \mid |x|^2 = 1}$（球面）不是凸集，因为球面上两点的连线会"穿透"球内部。

1.3.2 核心性质：局部最优即全局最优

定理：若 $x^$ 是凸优化问题的局部极小点，则 $x^$ 也必然是全局极小点。

逐行证明（反证法）：

Step 1（设定矛盾假设）：假设 $x^$ 是局部极小但不是全局极小。这意味着存在某个点 $y$（可行点，满足所有约束）使得 $f_0(y) < f_0(x^)$。

Step 2（利用局部极小定义）：因为 $x^$ 是局部极小，存在一个以 $x^$ 为球心、半径 $\varepsilon > 0$ 的小球 $B(x^, \varepsilon)$，使得球内所有可行点处的函数值都不小于 $f_0(x^)$。

Step 3（构造 $x^*$ 和 $y$ 之间的点）：考虑线段上的点 $z_\theta = \theta y + (1-\theta)x^*$。由于可行集是凸集（由约束条件保证），$z_\theta$ 也是可行点。

Step 4（取 $\theta$ 充分小）：选择足够小的 $\theta > 0$，使得 $z_\theta \in B(x^, \varepsilon)$。这是可能的，因为当 $\theta \to 0$ 时，$z_\theta \to x^$，所以当 $\theta$ 足够小时 $z_\theta$ 一定落在球内。具体可取 $\theta < \frac{\varepsilon}{|y - x^*|}$。

Step 5（应用凸性）：由目标函数 $f_0$ 的凸性：

$$f_0(z_\theta) = f_0(\theta y + (1-\theta)x^*) \leq \theta f_0(y) + (1-\theta)f_0(x^*)$$

Step 6（导出矛盾）：因为 $f_0(y) < f_0(x^*)$，所以：

$$\theta f_0(y) + (1-\theta)f_0(x^*) < \theta f_0(x^*) + (1-\theta)f_0(x^*) = f_0(x^*)$$

因此 $f_0(z_\theta) < f_0(x^)$。但 $z_\theta \in B(x^, \varepsilon)$，这与 $x^$ 是局部极小矛盾！因此假设不成立，$x^$ 必须是全局极小点。

这个证明的核心价值：一旦我们确认问题是凸的，就不需要担心"陷入局部最优”——任何找到的局部极小点自动就是全局最优解。这是凸优化在理论上和实践上都如此重要的根本原因。

1.4 存在性定理

1.4.1 Weierstrass 定理

定理陈述：若函数 $f: \mathbb{R}^n \to \mathbb{R}$ 连续（即 $x$ 变化很小时 $f(x)$ 变化也很小），且可行集 $S \subseteq \mathbb{R}^n$ 是非空紧集（即有界且闭——有界意味着存在一个大球包含 $S$ 中所有点；闭意味着 $S$ 包含其所有极限点），则 $\min_{x \in S} f(x)$ 一定存在全局解。

完整证明（5 步构造法）：

Step 1：设 $m = \inf_{x \in S} f(x)$。由于 $f$ 在紧集 $S$ 上连续，根据连续函数在紧集上的性质，$f$ 必然有下界，所以 $m > -\infty$（有限值）。

Step 2：由下确界的定义，存在序列 ${x_k}_{k=1}^{\infty} \subseteq S$，使得 $f(x_k) \to m$（即随着 $k$ 增大，$f(x_k)$ 无限逼近 $m$）。

下确界定义：$m = \inf_{x \in S} f(x)$ 意味着对任意 $\varepsilon > 0$，存在 $x \in S$ 使 $f(x) < m + \varepsilon$。依次取 $\varepsilon = 1, 1/2, 1/3, \ldots$，构造出所需的逼近序列。

Step 3：由于 $S$ 是有界集，${x_k}$ 是有界序列。由 Bolzano-Weierstrass 定理（$\mathbb{R}^n$ 中任意有界序列必存在收敛子列），存在子列 ${x_{k_j}}{j=1}^{\infty}$ 收敛到某个极限点 $x^*$，即 $x{k_j} \to x^*$。

Step 4：由于 $S$ 是闭集（包含其所有极限点），$x^* \in S$。

Step 5：由 $f$ 的连续性，$f(x^) = \lim_{j \to \infty} f(x_{k_j}) = m$。因此 $x^$ 处的函数值恰好等于下确界，即 $x^*$ 是全局极小点。

1.4.2 强制性（Coercivity）

若可行域不紧（如 $S = \mathbb{R}^n$ 无界），可用强制性替代紧性保证存在性：

定义：函数 $f$ 称为强制的（coercive），若当 $|x| \to \infty$（即 $x$ 远离原点趋向无穷远）时，$f(x) \to +\infty$。

$$\boxed{\lim_{\|x\| \to \infty} f(x) = +\infty}$$

推论：若 $f$ 连续且强制，则 $\min_{x \in \mathbb{R}^n} f(x)$ 存在全局解。

证明思路：取任意初始点 $x_0$，设 $L = f(x_0)$。由强制性，存在半径 $R > 0$ 使得球外 $|x| > R$ 的所有点处 $f(x) > L$。因此极小点一定在紧球 ${x \mid |x| \leq R}$ 内（因为球外的函数值都大于 $f(x_0)$，不可能是最小值）。在紧球上应用 Weierstrass 定理即得。

1.5 典型例题精讲

例题 1：二次函数的凸性判定（定义法）

题目：证明 $f(x) = \frac{1}{2}x^T Q x + b^T x + c$（其中 $Q \in \mathbb{S}^n_+$，即 $Q$ 是 $n \times n$ 对称半正定矩阵，$b \in \mathbb{R}^n$ 是常数列向量，$c \in \mathbb{R}$ 是标量常数）是凸函数。

考点标签：#凸函数 #定义法 #二次函数 #Jensen不等式

详细解答：

Step 1（验证定义域凸性）：$\text{dom} f = \mathbb{R}^n$，这是全空间，显然是凸集。

Step 2（设定变量）：取任意 $x, y \in \mathbb{R}^n$（两个 $n$ 维列向量）和 $\theta \in [0, 1]$（连接比例）。

Step 3（计算左边）：计算 $f(\theta x + (1-\theta)y)$：

$$f(\theta x + (1-\theta)y) = \frac{1}{2}(\theta x + (1-\theta)y)^T Q (\theta x + (1-\theta)y) + b^T(\theta x + (1-\theta)y) + c$$

展开矩阵乘积 $(\theta x + (1-\theta)y)^T Q (\theta x + (1-\theta)y)$：

$$= \theta^2 x^T Q x + \theta(1-\theta)x^T Q y + \theta(1-\theta)y^T Q x + (1-\theta)^2 y^T Q y$$

由于 $Q$ 对称（$Q = Q^T$），$x^T Q y = y^T Q x$，所以中间两项可合并为 $2\theta(1-\theta)x^T Q y$。

展开线性项 $b^T(\theta x + (1-\theta)y) = \theta b^T x + (1-\theta)b^T y$。加上常数 $c = \theta c + (1-\theta)c$。

所以左边 = $\frac{1}{2}[\theta^2 x^T Q x + 2\theta(1-\theta)x^T Q y + (1-\theta)^2 y^T Q y] + \theta b^T x + (1-\theta)b^T y + \theta c + (1-\theta)c$

Step 4（计算右边）：

$$\theta f(x) + (1-\theta)f(y) = \theta\left(\frac{1}{2}x^T Q x + b^T x + c\right) + (1-\theta)\left(\frac{1}{2}y^T Q y + b^T y + c\right)$$

Step 5（作差）：计算 $\theta f(x) + (1-\theta)f(y) - f(\theta x + (1-\theta)y)$。

二次型部分相减：

$$\frac{\theta}{2}x^T Q x + \frac{1-\theta}{2}y^T Q y - \frac{1}{2}[\theta^2 x^T Q x + 2\theta(1-\theta)x^T Q y + (1-\theta)^2 y^T Q y]$$

合并 $x^T Q x$ 系数：$\frac{\theta}{2} - \frac{\theta^2}{2} = \frac{\theta(1-\theta)}{2}$

合并 $y^T Q y$ 系数：$\frac{1-\theta}{2} - \frac{(1-\theta)^2}{2} = \frac{(1-\theta) - (1-\theta)^2}{2} = \frac{(1-\theta)[1-(1-\theta)]}{2} = \frac{\theta(1-\theta)}{2}$

合并 $x^T Q y$ 项：$-\frac{1}{2} \cdot 2\theta(1-\theta)x^T Q y = -\theta(1-\theta)x^T Q y$

二次型部分汇总：$\frac{\theta(1-\theta)}{2}[x^T Q x + y^T Q y - 2x^T Q y]$

注意：$x^T Q x + y^T Q y - 2x^T Q y = (x-y)^T Q (x-y)$

线性项和常数项在左右两边完全抵消。

Step 6（判定）：因此：

$$\theta f(x) + (1-\theta)f(y) - f(\theta x + (1-\theta)y) = \frac{1}{2}\theta(1-\theta)(x-y)^T Q (x-y)$$

由于 $Q \succeq 0$（半正定），$(x-y)^T Q (x-y) \geq 0$。且 $\theta(1-\theta) \geq 0$（因为 $\theta \in [0, 1]$）。所以差 ≥ 0，即：

$$f(\theta x + (1-\theta)y) \leq \theta f(x) + (1-\theta)f(y)$$

这正是凸函数定义式。证毕。

关键观察：差值恰好是 $\frac{1}{2}\theta(1-\theta)$ 乘以 $Q$ 在差向量上的二次型。这个差 ≥ 0 当且仅当 $Q \succeq 0$。如果 $Q$ 不是半正定（比如有负特征值），则存在方向使差 < 0，$f$ 就不是凸函数。

例题 2：指数函数的凸性证明（一阶条件法）

题目：用一阶条件证明 $f(x) = e^{ax}$（$a \in \mathbb{R}$ 为任意实常数）在 $\mathbb{R}$ 上是凸函数。

考点标签：#凸函数 #一阶条件 #指数函数

详细解答：

Step 1（计算梯度）：$f$ 是一维函数，$\nabla f(x) = f’(x) = a \cdot e^{ax}$。

Step 2（写出需要验证的不等式）：一阶条件要求对任意 $x, y$：

$$e^{ay} \geq e^{ax} + a e^{ax}(y - x)$$

Step 3（因式分解）：两边同除以 $e^{ax} > 0$（指数函数恒正，除法不改变不等式方向）：

$$e^{a(y-x)} \geq 1 + a(y-x)$$

Step 4（变量代换）：令 $t = a(y-x)$，$t$ 可以是任意实数（因为 $y$ 任意）。需证：

$$e^t \geq 1 + t, \quad \forall t \in \mathbb{R}$$

Step 5（证明 $e^t \geq 1 + t$）：构造函数 $\phi(t) = e^t - 1 - t$。

计算导数：$\phi’(t) = e^t - 1$

分析单调性：

  • 当 $t < 0$ 时：$e^t < 1$，所以 $\phi’(t) < 0$，$\phi$ 在 $(-\infty, 0]$ 上严格递减。
  • 当 $t > 0$ 时：$e^t > 1$，所以 $\phi’(t) > 0$，$\phi$ 在 $[0, +\infty)$ 上严格递增。
  • 在 $t = 0$ 处：$\phi’(0) = 0$。

因此 $t = 0$ 是 $\phi$ 的全局极小点，且 $\phi(0) = e^0 - 1 - 0 = 0$。所以 $\phi(t) \geq 0$ 对所有 $t \in \mathbb{R}$ 成立，即 $e^t \geq 1 + t$。

Step 6（结论）：一阶条件成立，$f$ 是凸函数。

几何直觉：指数曲线 $y = e^t$ 完全在切线 $y = 1 + t$ 的上方（$t = 0$ 处相切）。这是指数函数"加速增长"的数学表现——增长率本身也在增长。

例题 3：Hessian 判定法 —— Logistic 损失函数

题目：判定 $f(x) = \ln(1 + e^x)$ 的凸性。

考点标签：#凸函数 #二阶条件 #Hessian #Logistic函数

详细解答：

Step 1（计算一阶导数）：

$$f'(x) = \frac{d}{dx} \ln(1 + e^x) = \frac{1}{1 + e^x} \cdot e^x = \frac{e^x}{1 + e^x}$$

回忆 sigmoid 函数 $\sigma(x) = \frac{1}{1 + e^{-x}} = \frac{e^x}{1 + e^x}$，所以 $f’(x) = \sigma(x)$。

Step 2（计算二阶导数）：

$$f''(x) = \frac{d}{dx}\left(\frac{e^x}{1 + e^x}\right) = \frac{e^x(1 + e^x) - e^x \cdot e^x}{(1 + e^x)^2} = \frac{e^x + e^{2x} - e^{2x}}{(1 + e^x)^2} = \frac{e^x}{(1 + e^x)^2}$$

Step 3（判断符号）：$e^x > 0$ 对所有 $x$ 成立，分母 $(1 + e^x)^2 > 0$，所以 $f’’(x) > 0$ 对所有 $x \in \mathbb{R}$ 成立。

Step 4（结论）：$f’’(x) > 0$（严格正），根据二阶条件，$f$ 是严格凸函数。

常见混淆警告：机器学习中常见的 logistic 损失 $\ln(1 + e^{-x})$（注意负号）的二阶导数为 $\frac{e^x}{(1+e^x)^2} > 0$…等一下，让我重新算。$\frac{d^2}{dx^2}\ln(1+e^{-x}) = \frac{e^x}{(1+e^x)^2} > 0$？不是的。

重新计算：设 $g(x) = \ln(1 + e^{-x})$。$g’(x) = \frac{-e^{-x}}{1 + e^{-x}} = -\frac{1}{1 + e^x}$。$g’’(x) = \frac{e^x}{(1+e^x)^2} > 0$。所以 $\ln(1 + e^{-x})$ 居然也是凸的！但标准的 margin-based logistic loss $\ln(1 + \exp(-y \cdot w^T x))$ 对 $w$ 是凸的吗？这个需要具体分析，因为 $y \in {\pm 1}$。总之，在做凸性分析时，自变量是什么要搞清楚。

例题 4：强制性验证 —— 二次函数

题目：证明 $f(x) = x^T Q x + b^T x$（其中 $Q \succ 0$，即 $Q$ 为对称正定矩阵——所有特征值 > 0）是强制函数。

考点标签：#强制性 #Weierstrass #二次函数 #存在性

详细解答：

Step 1（下界分析）：设 $\lambda_{\min} = \lambda_{\min}(Q) > 0$（$Q$ 的最小特征值，因为 $Q$ 正定所以 > 0）。对任意 $x \in \mathbb{R}^n$：

$$x^T Q x \geq \lambda_{\min} \|x\|^2$$

回忆：$|x|^2 = x^T x = \sum_{i=1}^n x_i^2$，即向量 $x$ 的各分量平方和。

Step 2（线性项下界）：对线性项 $b^T x$，由 Cauchy-Schwarz 不等式（$|u^T v| \leq |u| |v|$）：

$$|b^T x| \leq \|b\| \cdot \|x\|$$

所以 $b^T x \geq -|b| \cdot |x|$（因为 $b^T x$ 可能为负，最坏情况是不小于负的 $|b| |x|$）。

Cauchy-Schwarz 不等式：对于两个同维度的向量 $u$ 和 $v$，它们的内积满足 $|u^T v| \leq |u| \cdot |v|$。等号当且仅当 $u$ 和 $v$ 平行时成立。

Step 3（合并下界）：

$$f(x) = x^T Q x + b^T x \geq \lambda_{\min} \|x\|^2 - \|b\| \cdot \|x\|$$

Step 4（配平方技巧）：将右边写成关于 $|x|$ 的完全平方形式：

$$\lambda_{\min} \|x\|^2 - \|b\| \|x\| = \lambda_{\min}\left(\|x\|^2 - \frac{\|b\|}{\lambda_{\min}} \|x\|\right)$$

补全平方：

$$= \lambda_{\min}\left[\left(\|x\| - \frac{\|b\|}{2\lambda_{\min}}\right)^2 - \frac{\|b\|^2}{4\lambda_{\min}^2}\right]$$

$$= \lambda_{\min}\left(\|x\| - \frac{\|b\|}{2\lambda_{\min}}\right)^2 - \frac{\|b\|^2}{4\lambda_{\min}}$$

Step 5（取极限）：当 $|x| \to \infty$，平方项 $\lambda_{\min}(|x| - \frac{|b|}{2\lambda_{\min}})^2 \to +\infty$，而常数项 $-\frac{|b|^2}{4\lambda_{\min}}$ 是固定有限值。因此 $f(x) \to +\infty$。

Step 6（存在性结论）：由强制性和 $f$ 的连续性，$\min_{x \in \mathbb{R}^n} f(x)$ 一定存在全局极小点。

关键观察：当 $Q$ 仅为半正定（$Q \succeq 0$，可能 $\lambda_{\min}=0$），配平方技巧失效——当 $\lambda_{\min} = 0$ 时二次项 $x^T Q x$ 在某些方向为零，不足以压倒线性项 $b^T x$。例如 $f(x_1, x_2) = x_2^2 + x_1$（$Q = \text{diag}(0, 1)$），沿 $x_1 \to -\infty$ 方向函数值 $x_1 \to -\infty$，不强制。

例题 5：梯度与 Hessian 计算 + 凸性综合判定

题目：设 $f(x) = |Ax - b|^2$，其中 $A \in \mathbb{R}^{m \times n}$（$m \times n$ 矩阵），$b \in \mathbb{R}^m$（$m$ 维列向量）。求 $\nabla f(x)$ 和 $\nabla^2 f(x)$，并判定 $f$ 的凸性。

考点标签：#梯度 #Hessian #凸性判定 #最小二乘

详细解答：

(1) 计算梯度 $\nabla f(x)$

Step 1：展开目标函数：

$$f(x) = (Ax - b)^T (Ax - b) = (x^T A^T - b^T)(Ax - b)$$

$$= x^T A^T A x - x^T A^T b - b^T A x + b^T b$$

Step 2：注意标量 $x^T A^T b$ 和 $b^T A x$ 互为转置，且都是标量（$1 \times 1$），以 $A^T b$ 为系数简化：

$$x^T A^T b = (x^T A^T b)^T = b^T A x$$

所以 $f(x) = x^T A^T A x - 2b^T A x + b^T b$

这里 $b^T A x$ 是一个标量，$(b^T A)x$ 等价于内积 $\langle A^T b, x \rangle$。

Step 3：对 $x^T A^T A x$ 求梯度：

$$\nabla_x (x^T A^T A x) = (A^T A + (A^T A)^T)x = 2A^T A x \quad (\text{因为 } A^T A \text{ 是对称矩阵})$$

对线性项 $-2b^T A x$ 求梯度：

$$\nabla_x (-2b^T A x) = -2A^T b$$

对常数项 $b^T b$ 求梯度：$0$。

Step 4：合并：

$$\nabla f(x) = 2A^T A x - 2A^T b = 2A^T(Ax - b)$$

(2) 计算 Hessian $\nabla^2 f(x)$

对梯度 $\nabla f(x) = 2A^T A x - 2A^T b$ 再次求导。常数项 $-2A^T b$ 的导数为零，线性项 $2A^T A x$ 的导数即系数矩阵：

$$\nabla^2 f(x) = 2A^T A$$

注意 Hessian 与 $x$ 无关——这是二次函数的特性。

(3) 凸性判定

Step 1：检查 $\nabla^2 f(x) = 2A^T A$ 是否半正定。对任意向量 $v \in \mathbb{R}^n$：

$$v^T (2A^T A) v = 2(Av)^T (Av) = 2\|Av\|^2 \geq 0$$

因此 $2A^T A \succeq 0$（常数正因子 $2$ 不影响半正定性）。

Step 2：由二阶条件，$f$ 是凸函数。

补充说明：

  • 若 $A$ 列满秩（即 $A$ 的各列线性无关，等价于 $\text{rank}(A) = n$），则 $A^T A \succ 0$（正定），此时 $f$ 是严格凸函数。
  • 若 $A$ 不满列秩，存在非零 $v$ 使 $Av = 0$，此时 $v^T A^T A v = 0$，$f$ 沿 $v$ 方向没有曲率——是凸但不严格凸。
  • $f(x) = |Ax - b|^2$ 是最经典的最小二乘问题的目标函数，其凸性意味着 $\nabla f(x^) = 0$（即正规方程 $A^T A x^ = A^T b$）的解就是全局最小二乘解。

核心要点

1.1 凸集

  1. 定义记忆：连接集合内任意两点的线段整体落在集合内 → 凸集
  2. 保凸运算：任意个凸集的交仍凸；凸集的仿射变换仍凸；凸集的并一般不凸
  3. 关键反例：球面 ${x \mid |x| = 1}$ 是常见非凸集（直径两端点的中点在原点）
  4. 超平面既是凸集也是仿射集，而仿射集一定是凸集
  5. 可行性判定：凸优化问题要求可行集是凸集，这等价于不等式约束函数是凸的（$\leq 0$ 形式），等式约束必须是仿射的

1.2 凸函数

  1. 定义（Jensen）：$f(\theta x + (1-\theta)y) \leq \theta f(x) + (1-\theta)f(y)$ — “割线在函数上方”
  2. 一阶条件：$f(y) \geq f(x) + \nabla f(x)^T (y-x)$ — “切线托住函数”；凸 ⇔ 一阶条件 ⇔ 二阶条件（对 $C^2$ 函数）
  3. 二阶条件：$\nabla^2 f(x) \succeq 0, \forall x$ — “处处弯曲向上”，是最实用的判定工具
  4. 关键定理：凸函数的驻点（$\nabla f(x^*) = 0$）自动是全局极小点 — 不需要检查二阶条件
  5. 常见混淆：中文"凸"（$\cup$ 形）= 数学凸函数；中文"凹"（$\cap$ 形）= 数学凹函数

1.3 凸优化问题

  1. 标准形式三要素：凸目标 + 凸不等式约束 + 仿射等式约束 → 凸优化问题
  2. 核心性质：局部极小 $\Rightarrow$ 全局极小 — 这是凸优化在理论和实践中最重要的性质
  3. DCP 规则：建模工具通过"保凸运算的语法树"验证凸性，max/sum/quad_form 保凸，min 不保凸
  4. 存在性：Weierstrass 定理（紧集 + 连续 → 有解）和强制性（$\lim_{|x|\to\infty} f(x) = +\infty$ → 无约束问题有解）
  5. 实践口诀：算 Hessian → 判半正定 → 给结论。二阶条件是最快的凸性判定路径
