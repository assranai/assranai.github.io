第14章：交替方向乘子法（ADMM）

核心思想：将乘子法的联合极小化拆分为交替极小化——先 $\min_x$（固定 $z, \lambda$），再 $\min_z$（固定新 $x, \lambda$），最后更新乘子。既享受乘子法的加速收敛（二次惩罚项的光滑化效果），又保持子问题的可分解性。这是本课程最重要的算法之一，务必掌握每一步推导！

14.1 问题形式

14.1.1 ADMM的一般结构

ADMM求解具有以下可分离结构的凸优化问题：

$$\boxed{\min_{x \in \mathbb{R}^n, \; z \in \mathbb{R}^m} \; f(x) + g(z) \quad \text{s.t.} \quad Ax + Bz = c}$$

符号逐字解释：

  • $x \in \mathbb{R}^n$：第一组决策变量（$n$ 维列向量 $x = (x_1, \ldots, x_n)^T$）
  • $z \in \mathbb{R}^m$：第二组决策变量（$m$ 维列向量）
  • $f: \mathbb{R}^n \to \mathbb{R} \cup {+\infty}$：关于 $x$ 的闭凸函数（可以非光滑，但最好 $\operatorname{prox}_f$ 好算或 $\min_x$ 子问题容易求解）
  • $g: \mathbb{R}^m \to \mathbb{R} \cup {+\infty}$：关于 $z$ 的闭凸函数（同样可非光滑）
  • $A \in \mathbb{R}^{p \times n}, B \in \mathbb{R}^{p \times m}$：约束矩阵（$p$ 个线性等式约束）
  • $c \in \mathbb{R}^p$：约束的右端常数向量
  • 目标 $f(x) + g(z)$ 是完全可分离的——$x$ 和 $z$ 之间没有交叉项（如 $x^T z$ 这种），唯一的耦合来自线性约束 $Ax + Bz = c$

14.1.2 标准共识形式（$x = z$）

在考试和绝大多数实际应用中，约束取为最简单的形式：

$$\boxed{\min_{x, z} \; f(x) + g(z) \quad \text{s.t.} \quad x - z = 0}$$

即 $A = I$（$n \times n$ 单位矩阵），$B = -I$，$c = \mathbf{0}$。

为什么共识形式如此普遍？ 因为任何一个 $\min_x f(x) + g(x)$ 都可以通过**变量分裂（Variable Splitting）**转化为上面的可分离形式：

$$\min_x f(x) + g(x) \quad \longrightarrow \quad \min_{x, z} f(x) + g(z) \quad \text{s.t.} \quad x = z$$

变量分裂的技巧价值：原本 $f$ 和 $g$ 作用于同一个变量（耦合难以分离），引入辅助变量 $z$ 和共识约束 $x = z$ 后，$f$ 只管 $x$，$g$ 只管 $z$——两者在极小化步骤中完全解耦。约束 $x = z$ 通过乘子 $\lambda$ 的调解来"拉拢"二者趋同。

14.2 从增广Lagrange到ADMM的完整推导

14.2.1 增广Lagrange函数的构造

对一般约束问题，写出增广Lagrange函数（由Ch12乘子法推广而来）：

$$\boxed{L_\rho(x, z, \lambda) = f(x) + g(z) + \lambda^T(Ax + Bz - c) + \frac{\rho}{2}\|Ax + Bz - c\|^2}$$

逐项解释：

  • $f(x) + g(z)$：分离的目标函数（各自独立）
  • $\lambda^T(Ax + Bz - c)$：线性乘子项，$\lambda \in \mathbb{R}^p$ 是Lagrange乘子，衡量约束违反的边际代价
  • $\frac{\rho}{2}|Ax + Bz - c|^2 = \frac{\rho}{2}\sum_{i=1}^p (A_i x + B_i z - c_i)^2$：二次惩罚项，提供光滑性和额外凸性
  • $\rho > 0$：惩罚参数

14.2.2 为什么不直接联合极小化？（乘子法的困境）

乘子法（Ch12）的原始步要求：

$$(x^{k+1}, z^{k+1}) = \arg\min_{x, z} L_\rho(x, z, \lambda^k)$$

即联合极小化关于 $(x, z)$ 的增广Lagrange。困难来自二次惩罚项的展开：

$$\frac{\rho}{2}\|Ax + Bz - c\|^2 = \frac{\rho}{2}\left( \|Ax\|^2 + \|Bz\|^2 + 2(Ax)^T(Bz) - 2(Ax)^T c - 2(Bz)^T c + \|c\|^2 \right)$$

交叉项 $2(Ax)^T(Bz)$ 将 $x$ 和 $z$ 耦合在一起，使得 $\arg\min_{x,z}$ 不是两个独立极小化的简单拼接——必须联合求解，维数为 $n+m$，计算代价高。

14.2.3 ADMM的关键思想——交替极小化

ADMM的核心创新：不联合极小化，而是轮流极小化！

具体来说，在第 $k+1$ 步：

  1. 先固定 $(z^k, \lambda^k)$，仅极小化 $L_\rho$ 关于 $x$
  2. 用新得的 $x^{k+1}$，固定 $\lambda^k$，极小化 $L_\rho$ 关于 $z$
  3. 用新得的 $(x^{k+1}, z^{k+1})$，更新乘子 $\lambda$

为什么这样可行？ 因为每一步都是一个低维子问题（只优化一个变量块），且由于已固定了另一块，不存在交叉项的困扰。这就是"交替方向"的由来。

14.2.4 ADMM三步迭代的完整推导

ADMM标准迭代：

$$\boxed{\begin{aligned} x^{k+1} &= \arg\min_x \; L_\rho(x, z^k, \lambda^k) \quad \text{（$x$-子问题）} \\ z^{k+1} &= \arg\min_z \; L_\rho(x^{k+1}, z, \lambda^k) \quad \text{（$z$-子问题）} \\ \lambda^{k+1} &= \lambda^k + \rho(Ax^{k+1} + Bz^{k+1} - c) \quad \text{（乘子更新）} \end{aligned}}$$

推导细节：

第一步——$x$-子问题：

$$\begin{aligned} x^{k+1} &= \arg\min_x \left\{ f(x) + (\lambda^k)^T Ax + \frac{\rho}{2}\|Ax + Bz^k - c\|^2 \right\} \\ &= \arg\min_x \left\{ f(x) + \frac{\rho}{2}\left\|Ax + Bz^k - c + \frac{\lambda^k}{\rho}\right\|^2 \right\} \quad \text{（配方消去线性项）} \end{aligned}$$

配方推导：

$$(\lambda^k)^T(Ax + Bz^k - c) + \frac{\rho}{2}\|Ax + Bz^k - c\|^2 = \frac{\rho}{2}\left\|Ax + Bz^k - c + \frac{\lambda^k}{\rho}\right\|^2 - \frac{\|\lambda^k\|^2}{2\rho}$$

因为 $-\frac{|\lambda^k|^2}{2\rho}$ 与 $x$ 无关，极小化时可以忽略。

第二步——$z$-子问题（完全类似，对称处理）：

$$\begin{aligned} z^{k+1} &= \arg\min_z \left\{ g(z) + (\lambda^k)^T Bz + \frac{\rho}{2}\|Ax^{k+1} + Bz - c\|^2 \right\} \\ &= \arg\min_z \left\{ g(z) + \frac{\rho}{2}\left\|Ax^{k+1} + Bz - c + \frac{\lambda^k}{\rho}\right\|^2 \right\} \end{aligned}$$

第三步——乘子更新（与乘子法完全相同）：

$$\lambda^{k+1} = \lambda^k + \rho(Ax^{k+1} + Bz^{k+1} - c)$$

这一更新公式来自 $L_\rho$ 关于 $\lambda$ 的梯度上升（极大化对偶问题）。直观上：如果 $Ax^{k+1} + Bz^{k+1} > c$（“超额"了），就增大 $\lambda$ 来"惩罚”。

14.3 缩放形式（Scaled Form）

14.3.1 缩放对偶变量的引入

定义缩放对偶变量（也称缩放乘子）：

$$\boxed{u = \frac{\lambda}{\rho}}$$

则有 $u \in \mathbb{R}^p$，且 $\lambda = \rho u$。

动机：缩放后，ADMM迭代会变得更加对称和简洁。

14.3.2 缩放形式的推导

将 $\lambda = \rho u$ 代入增广Lagrange：

$$\begin{aligned} L_\rho(x, z, \rho u) &= f(x) + g(z) + \rho u^T(Ax + Bz - c) + \frac{\rho}{2}\|Ax + Bz - c\|^2 \\ &= f(x) + g(z) + \frac{\rho}{2}\left( 2u^T(Ax + Bz - c) + \|Ax + Bz - c\|^2 \right) \\ &= f(x) + g(z) + \frac{\rho}{2}\|Ax + Bz - c + u\|^2 - \frac{\rho}{2}\|u\|^2 \end{aligned}$$

忽略常数项 $-\frac{\rho}{2}|u|^2$（不影响极小化），得到缩放形式的增广Lagrange：

$$\boxed{\tilde{L}_\rho(x, z, u) = f(x) + g(z) + \frac{\rho}{2}\|Ax + Bz - c + u\|^2}$$

14.3.3 缩放形式的ADMM迭代

$$\boxed{\begin{aligned} x^{k+1} &= \arg\min_x \left\{ f(x) + \frac{\rho}{2}\|Ax + Bz^k - c + u^k\|^2 \right\} \\ z^{k+1} &= \arg\min_z \left\{ g(z) + \frac{\rho}{2}\|Ax^{k+1} + Bz - c + u^k\|^2 \right\} \\ u^{k+1} &= u^k + (Ax^{k+1} + Bz^{k+1} - c) \end{aligned}}$$

缩放形式的优势：

  1. 子问题中不再显式出现 $\lambda$——约束违反与 $u^k$ 直接相加
  2. 乘子更新不再需要 $\rho$ 因子（$u^{k+1} = u^k + \text{残差}$）
  3. 形式更对称——$x$ 和 $z$ 的子问题结构完全一致（只是 $f$ vs $g$ 不同）

14.3.4 共识形式下的缩放ADMM

当 $A = I, B = -I, c = 0$ 时，缩放ADMM简化为：

$$\boxed{\begin{aligned} x^{k+1} &= \arg\min_x \left\{ f(x) + \frac{\rho}{2}\|x - z^k + u^k\|^2 \right\} \\ z^{k+1} &= \arg\min_z \left\{ g(z) + \frac{\rho}{2}\|x^{k+1} - z + u^k\|^2 \right\} \\ u^{k+1} &= u^k + (x^{k+1} - z^{k+1}) \end{aligned}}$$

这是ADMM最常用的形式。注意 $u$ 的累积：$u^k = u^0 + \sum_{j=0}^{k-1} (x^{j+1} - z^{j+1})$，即 $u^k$ 是历史上所有 $x$ 和 $z$ 差异的"累积和"。

14.4 ADMM的收敛性

14.4.1 收敛性条件

定理（ADMM收敛性）：若满足以下条件：

  1. $f$ 和 $g$ 是闭真凸函数（closed proper convex functions）
  2. 增广Lagrange $L_\rho$ 存在鞍点（即原问题有解，强对偶成立）

则对任意 $\rho > 0$，ADMM迭代满足：

  • 残差收敛：$Ax^k + Bz^k - c \to 0$（约束渐趋满足）
  • 目标收敛：$f(x^k) + g(z^k) \to p^*$（目标值趋于最优）
  • 乘子收敛：$\lambda^k \to \lambda^*$（乘子趋于最优对偶解）

注意：ADMM的收敛不需要 $f$ 或 $g$ 强凸，不需要 $\rho \to \infty$，不需要步长衰减。只需要 $\rho > 0$ 固定即可。

14.4.2 收敛速度

ADMM的理论收敛速度一般不是线性的（次线性 $O(1/k)$），但在实践中：

  1. 若 $f$ 或 $g$ 强凸：可达到线性收敛
  2. 若两者都强凸：收敛极快
  3. $\rho$ 调节：正确的 $\rho$ 可使常数因子大幅缩减。实践中 $\rho$ 的选择是ADMM调参的核心。

14.4.3 收敛判据（实用停机准则）

原始残差（Primal Residual）：

$$r^{k+1} = Ax^{k+1} + Bz^{k+1} - c$$

对偶残差（Dual Residual）：

$$s^{k+1} = \rho A^T B(z^{k+1} - z^k)$$

停机条件：

$$\|r^{k+1}\|_2 \leq \epsilon^{\text{pri}}, \quad \|s^{k+1}\|_2 \leq \epsilon^{\text{dual}}$$

其中 $\epsilon^{\text{pri}}, \epsilon^{\text{dual}}$ 是根据绝对误差和相对误差共同定义的容差。

14.5 三大经典应用（完整推导每个子问题）

应用一：LASSO（$\ell_1$ 正则化最小二乘）

问题：$\min_\beta \frac{1}{2}|X\beta - y|^2 + \lambda|\beta|_1$

变量分裂：引入 $z = \beta$：

$$\min_{\beta, z} \; \frac{1}{2}\|X\beta - y\|^2 + \lambda\|z\|_1 \quad \text{s.t.} \quad \beta - z = 0$$

增广Lagrange（共识形式）：

$$L_\rho(\beta, z, u) = \frac{1}{2}\|X\beta - y\|^2 + \lambda\|z\|_1 + \frac{\rho}{2}\|\beta - z + u\|^2$$

$\beta$-子问题（光滑二次 + 二次正则）：

$$\min_\beta \frac{1}{2}\|X\beta - y\|^2 + \frac{\rho}{2}\|\beta - z^k + u^k\|^2$$

梯度为0：

$$\nabla f = X^T(X\beta - y) + \rho(\beta - z^k + u^k) = 0$$

$$(X^T X + \rho I)\beta = X^T y + \rho(z^k - u^k)$$

解得：

$$\boxed{\beta^{k+1} = (X^T X + \rho I)^{-1} \left( X^T y + \rho(z^k - u^k) \right)}$$

计算技巧：当 $n \gg p$（样本数 $\gg$ 特征数），直接用上式（$p \times p$ 矩阵求逆）。当 $p \gg n$，用Sherman-Morrison-Woodbury公式：

$$(X^T X + \rho I)^{-1} = \frac{1}{\rho}I - \frac{1}{\rho^2}X^T(I + \frac{1}{\rho}XX^T)^{-1}X$$

降为 $n \times n$ 矩阵求逆。

$z$-子问题（$\ell_1$ + 二次惩罚）：

$$\min_z \lambda\|z\|_1 + \frac{\rho}{2}\|z - (\beta^{k+1} + u^k)\|^2$$

这正是 $\ell_1$ 范数的邻近算子——软阈值：

$$\boxed{z^{k+1} = \operatorname{soft}\left( \beta^{k+1} + u^k, \; \frac{\lambda}{\rho} \right) = \operatorname{sign}(v_i) \max\left\{ |v_i| - \frac{\lambda}{\rho}, 0 \right\}}$$

乘子更新：

$$\boxed{u^{k+1} = u^k + (\beta^{k+1} - z^{k+1})}$$

每步计算量：$\beta$-子问题 $O(p^3)$（矩阵求逆，但只需一次Cholesky分解可预计算），$z$-子问题 $O(p)$（逐分量软阈值），$u$ 更新 $O(p)$。

应用二：鲁棒PCA（RPCA, Robust Principal Component Analysis）

问题背景：从被稀疏大噪声污染的数据矩阵 $M$ 中恢复低秩干净信号 $L$：

$$M = L + S, \quad L \text{ 低秩}, \; S \text{ 稀疏}$$

数学形式：

$$\boxed{\min_{L, S} \; \|L\|_* + \lambda\|S\|_1 \quad \text{s.t.} \quad L + S = M}$$

符号解释：

  • $|L|_* = \sum_i \sigma_i(L)$：核范数（nuclear norm），等于矩阵 $L$ 的奇异值之和。核范数是秩的凸松弛——最小化核范数 $\approx$ 最小化秩。
  • $|S|1 = \sum{i,j} |S_{ij}|$：矩阵的各元素绝对值之和（$\ell_1$ 范数），诱导 $S$ 的稀疏性。
  • $\lambda = 1/\sqrt{\max(n, m)}$ 是理论推荐的参数。

ADMM构造：

$$L_\rho(L, S, U) = \|L\|_* + \lambda\|S\|_1 + \frac{\rho}{2}\|L + S - M + U\|^2$$

$L$-子问题（核范数 + 二次惩罚）：

$$\min_L \|L\|_* + \frac{\rho}{2}\|L - (M - S^k - U^k)\|^2$$

核范数的邻近算子 = 奇异值软阈值（Singular Value Thresholding, SVT）：

$$\boxed{L^{k+1} = \mathcal{D}_{1/\rho}(M - S^k - U^k)}$$

其中 $\mathcal{D}_\tau(X) = U \cdot \operatorname{diag}(\operatorname{soft}(\sigma, \tau)) \cdot V^T$，即对 $X$ 做SVD分解 $X = U\Sigma V^T$，将每个奇异值 $\sigma_i$ 软阈值化 $\max{\sigma_i - \tau, 0}$，再乘回去。计算量：$O(n^3)$ 的SVD。

$S$-子问题（$\ell_1$ + 二次惩罚）：

$$\min_S \lambda\|S\|_1 + \frac{\rho}{2}\|S - (M - L^{k+1} - U^k)\|^2$$

$\ell_1$ 范数的邻近算子 = 逐元素软阈值：

$$\boxed{S^{k+1} = \operatorname{soft}\left( M - L^{k+1} - U^k, \; \frac{\lambda}{\rho} \right)}$$

乘子更新：

$$\boxed{U^{k+1} = U^k + (L^{k+1} + S^{k+1} - M)}$$

RPCA的ADMM总结：$L$ 步做SVD + 奇异值软阈值（保持低秩），$S$ 步做逐元素软阈值（保持稀疏），$U$ 步累积残差（使 $L+S$ 趋近于 $M$）。

应用三：图LASSO（Graphical LASSO）

问题：

$$\min_{\Theta \succ 0} \; -\log\det \Theta + \langle S, \Theta \rangle + \lambda\|\Theta\|_1$$

其中 $\Theta$ 是 $p \times p$ 精度矩阵，$S$ 是样本协方差。

变量分裂：引入 $Z = \Theta$：

$$\min_{\Theta, Z} \; -\log\det \Theta + \langle S, \Theta \rangle + \lambda\|Z\|_1 \quad \text{s.t.} \quad \Theta - Z = 0$$

（约束 $\Theta \succ 0$ 由 $-\log\det \Theta$ 的定义域自动处理。）

增广Lagrange：

$$L_\rho(\Theta, Z, U) = -\log\det \Theta + \langle S, \Theta \rangle + \lambda\|Z\|_1 + \frac{\rho}{2}\|\Theta - Z + U\|_F^2$$

其中 $|\cdot|_F$ 是Frobenius范数。

$\Theta$-子问题：

$$\min_\Theta \; -\log\det \Theta + \langle S, \Theta \rangle + \frac{\rho}{2}\|\Theta - (Z^k - U^k)\|_F^2$$

梯度为0：

$$-\Theta^{-1} + S + \rho(\Theta - Z^k + U^k) = 0$$

等价于求解矩阵方程 $\Theta^{-1} + \rho\Theta = S + \rho(Z^k - U^k)$。

技巧：对右端 $W = S + \rho(Z^k - U^k)$ 做特征值分解 $W = Q\Lambda Q^T$（$\Lambda = \operatorname{diag}(\lambda_1, \ldots, \lambda_p)$），则每个特征值满足标量方程：

$$\frac{1}{\theta_i} + \rho\theta_i = \lambda_i$$

解得 $\theta_i = \frac{\lambda_i + \sqrt{\lambda_i^2 + 4\rho}}{2\rho}$。故：

$$\boxed{\Theta^{k+1} = Q \cdot \operatorname{diag}\left( \frac{\lambda_i + \sqrt{\lambda_i^2 + 4\rho}}{2\rho} \right) \cdot Q^T}$$

$Z$-子问题：

$$\min_Z \lambda\|Z\|_1 + \frac{\rho}{2}\|Z - (\Theta^{k+1} + U^k)\|_F^2$$

同样是软阈值：

$$\boxed{Z^{k+1} = \operatorname{soft}\left( \Theta^{k+1} + U^k, \; \frac{\lambda}{\rho} \right)}$$

乘子更新：$U^{k+1} = U^k + (\Theta^{k+1} - Z^{k+1})$。

每步计算量：$\Theta$ 子问题 $O(p^3)$（特征值分解），$Z$ 子问题 $O(p^2)$（元素级软阈值）。

14.6 ADMM = 对偶DR分裂法的统一视角

14.6.1 理论统一

这是ADMM最深层的理论联系（回顾Ch13）。考虑共识形式：

$$\min_{x,z} f(x) + g(z) \quad \text{s.t.} \quad x = z$$

对偶问题（极小化形式）：

$$\min_\lambda \; f^*(-\lambda) + g^*(\lambda)$$

在 $f^(-\lambda) + g^(\lambda)$ 上应用DR分裂法：

$$y_{k+1} = \operatorname{prox}_{g^*}(\lambda_k)$$

$$w_{k+1} = \operatorname{prox}_{f^*(-\cdot)}(2y_{k+1} - \lambda_k)$$

$$\lambda_{k+1} = \lambda_k + w_{k+1} - y_{k+1}$$

利用Moreau分解和邻近算子的性质，可以证明这恰恰等价于ADMM在原空间的迭代。

14.6.2 收敛性的继承

因为ADMM = 对偶DR，而DR分裂法是稳定非扩张不动点迭代（$T_{DR} = \frac{R_f \circ R_g + I}{2}$），所以ADMM的收敛性直接从DR的收敛性理论继承而来——无需另证！

直观理解：ADMM的"交替"不是随意的——它根植于邻近算子和反射算子的不动点理论。三个步骤（$x$ 更新、$z$ 更新、$\lambda$ 更新）精确对应了对偶空间中DR的一次完整迭代。

14.7 典型例题

例题14.1（ADMM基础推导——LASSO的子问题）

题目：写出用ADMM求解 $\min_\beta \frac{1}{2}|X\beta - y|^2 + \lambda|\beta|_1$ 的 $\beta$ 和 $z$ 子问题的闭式解方法。

解答：已在14.5节应用一中完整呈现。

  • $\beta^{k+1} = (X^T X + \rho I)^{-1}(X^T y + \rho(z^k - u^k))$
  • $z^{k+1} = \operatorname{soft}(\beta^{k+1} + u^k, \lambda/\rho)$
  • $u^{k+1} = u^k + \beta^{k+1} - z^{k+1}$

例题14.2（弹性网Elastic Net的ADMM）

题目：用ADMM求解弹性网 $\min_\beta \frac{1}{2}|X\beta - y|^2 + \lambda_1|\beta|_1 + \frac{\lambda_2}{2}|\beta|^2$。

解答：

弹性网可以看作LASSO + $\ell_2$ 范数的组合。令 $f(\beta) = \frac{1}{2}|X\beta - y|^2 + \frac{\lambda_2}{2}|\beta|^2$，$g(z) = \lambda_1|z|_1$，引入 $z = \beta$。

$\beta$-子问题：

$$\min_\beta \frac{1}{2}\|X\beta - y\|^2 + \frac{\lambda_2}{2}\|\beta\|^2 + \frac{\rho}{2}\|\beta - z^k + u^k\|^2$$

梯度条件：

$$X^T(X\beta - y) + \lambda_2\beta + \rho(\beta - z^k + u^k) = 0$$

解得：

$$\boxed{\beta^{k+1} = (X^T X + (\lambda_2 + \rho)I)^{-1} \left( X^T y + \rho(z^k - u^k) \right)}$$

与LASSO完全相同的结构——只是多了一个 $\lambda_2 I$ 在正则化矩阵中。这额外的 $\ell_2$ 正则化使矩阵求逆更加稳定（条件数更小）。

$z$-子问题：与标准LASSO完全相同——软阈值。 乘子更新：完全相同。

弹性网 vs LASSO 的ADMM差异：只是 $\beta$ 子问题的矩阵多了一个 $\lambda_2 I$，这在计算上没有额外负担。

例题14.3（RPCA的完整ADMM算法伪代码）

题目：写出RPCA的完整ADMM伪代码，并说明何时判定收敛。

解答：

$$\boxed{\begin{aligned} &\textbf{输入：} M \in \mathbb{R}^{n \times m}, \; \lambda > 0, \; \rho > 0 \\ &\textbf{初始化：} L^0 = 0, \; S^0 = 0, \; U^0 = 0, \; k = 0 \\ &\textbf{重复：} \\ &\quad L^{k+1} = \mathcal{D}_{1/\rho}(M - S^k - U^k) \quad \text{（SVD + 奇异值软阈值）} \\ &\quad S^{k+1} = \operatorname{soft}(M - L^{k+1} - U^k, \; \lambda/\rho) \quad \text{（逐元素软阈值）} \\ &\quad U^{k+1} = U^k + (L^{k+1} + S^{k+1} - M) \\ &\quad r^k = \|L^{k+1} + S^{k+1} - M\|_F \quad \text{（原始残差）} \\ &\quad s^k = \rho\|S^{k+1} - S^k\|_F \quad \text{（对偶残差）} \\ &\textbf{直到 } r^k < \epsilon^{\text{pri}} \text{ 且 } s^k < \epsilon^{\text{dual}} \\ &\textbf{输出：} L = L^{k+1} \text{（低秩恢复矩阵）}, \; S = S^{k+1} \text{（稀疏噪声矩阵）} \end{aligned}}$$

例题14.4（ADMM参数 $\rho$ 的影响分析）

题目：分析ADMM中参数 $\rho$ 的大小对收敛行为的影响。

解答：

从缩放形式看：

$$x^{k+1} = \arg\min_x \left\{ f(x) + \frac{\rho}{2}\|Ax + Bz^k - c + u^k\|^2 \right\}$$
  • $\rho$ 小：二次惩罚项权重轻 → $x$ 和 $z$ 的迭代更自由 → 约束满足慢 → 原始残差大 → 但子问题的Hessian条件数好（矩阵求逆稳定）。
  • $\rho$ 大：二次惩罚项权重重 → $x$ 和 $z$ 被强力拉向满足约束 → 约束满足快 → 但子问题可能病态 → 矩阵求逆数值不稳定。
  • 最优 $\rho$：在"快速满足约束"和"子问题数值稳定"之间取得平衡。

实用策略：

  1. 固定 $\rho$：大多数情况 $\rho = 1$ 即可，然后根据收敛速度手动调整。
  2. 自适应 $\rho$：根据原始残差和对偶残差的比值动态调整：
    • 若 $|r^k| \gg |s^k|$：增大 $\rho$（加强约束满足）
    • 若 $|s^k| \gg |r^k|$：减小 $\rho$（放松约束，改善数值条件）
    • 典型的更新规则：$\rho^{k+1} = \tau \rho^k$（$\tau > 1$）或 $\rho^{k+1} = \rho^k / \tau$（$\tau > 1$）。

例题14.5（共识ADMM的收敛验证——数值实验设计）

题目：设计一个简单的数值实验来验证LASSO的ADMM求解正确性。

解答：

实验设置：

  1. 生成测试数据：$n = 100$ 个样本，$p = 20$ 个特征。真实系数 $\beta_{\text{true}}$ 只有 $k = 5$ 个非零（稀疏真值）。
  2. 生成 $X \in \mathbb{R}^{100 \times 20}$，$X_{ij} \sim \mathcal{N}(0, 1)$。生成噪声 $\epsilon \sim \mathcal{N}(0, 0.1)$。
  3. 计算 $y = X\beta_{\text{true}} + \epsilon$。
  4. 取 $\lambda = 0.5$，$\rho = 1$。

验证指标：

  • 原始残差：$|\beta^k - z^k|_2$（应趋于0）
  • 目标值：$F(\beta^k) = \frac{1}{2}|X\beta^k - y|^2 + \lambda|\beta^k|_1$（应单调递减趋于最优）
  • 恢复精度：$|\beta^k - \beta_{\text{true}}|_2$（看是否恢复真实稀疏模式）
  • 支撑恢复：$\operatorname{supp}(\beta^k) = {i : \beta_i^k \neq 0}$（看是否选中正确的非零分量）

预期结果：经过约50-100次ADMM迭代，$|\beta^k - z^k|_2$ 降至 $10^{-6}$ 以下，目标值稳定，支撑恢复准确率 > 90%。

核心要点

  1. ADMM的核心三步骤：$x$ 更新（固定 $z, u$）→ $z$ 更新（固定新 $x, u$）→ $u$ 更新（梯度上升）。交替方向打破了乘子法的联合极小化瓶颈，恢复了子问题的可分解性。

  2. 缩放形式：$u = \lambda / \rho$ 使ADMM更对称优雅——子问题只需加二次范数惩罚，乘子更新简化为 $u^{k+1} = u^k + \text{残差}$。

  3. 变量分裂技巧：$\min_x f(x) + g(x) \to \min_{x,z} f(x) + g(z)$ s.t. $x = z$——这是将任意两项和问题转化为ADMM适用形式的万能公式。

  4. 三大经典应用的子问题核心：

    • LASSO：$\beta$ 步 = 岭回归（矩阵求逆），$z$ 步 = 软阈值
    • RPCA：$L$ 步 = SVD + 奇异值软阈值，$S$ 步 = 逐元素软阈值
    • 图LASSO：$\Theta$ 步 = 特征值分解 + 标量二次方程，$Z$ 步 = 软阈值

  5. ADMM = 对偶DR：ADMM的交替迭代是DR分裂法在对偶空间的表现——收敛性直接继承自DR的不动点理论。

  6. 收敛条件简单：$\rho > 0$ 固定即可保证收敛，无需 $f$ 或 $g$ 强凸，无需 $\rho \to \infty$。

  7. $\rho$ 的调参艺术：$\rho$ 小 → 稳定但慢；$\rho$ 大 → 快速满足约束但子问题可能病态。自适应策略（残差比动态调节）在实践中效果良好。

一句话总结：ADMM = 乘子法的速度 + 对偶分解的可分离性 + DR分裂法的理论根基——它通过"交替方向"的巧思，在大规模凸优化中实现了"快"与"可分解"的完美融合，是本课程最璀璨的算法明珠。

14.8 补充例题

例题14.6（ADMM求解总变分去噪——TV-L2）

题目：$\min_x \frac{1}{2}|x - b|^2 + \lambda|\nabla x|_{2,1}$，写出ADMM迭代。

解答：

引入 $z = \nabla x$（$z = (z_h, z_v)$ 为二维梯度场）：

$$\min_{x, z} \frac{1}{2}\|x - b\|^2 + \lambda\|z\|_{2,1} \quad \text{s.t.} \quad z = \nabla x$$

缩放ADMM（$\rho > 0$）：

$$L_\rho(x, z, u) = \frac{1}{2}\|x - b\|^2 + \lambda\|z\|_{2,1} + \frac{\rho}{2}\|\nabla x - z + u\|^2$$

$x$-子问题（二次 + 二次正则）：

$$\min_x \frac{1}{2}\|x - b\|^2 + \frac{\rho}{2}\|\nabla x - z^k + u^k\|^2$$

梯度为零：$(x - b) + \rho \nabla^T(\nabla x - z^k + u^k) = 0$。

使用FFT对角化：$\nabla^T \nabla$ 在频域为标量乘子。解得：

$$\boxed{x^{k+1} = \mathcal{F}^{-1}\left( \frac{\mathcal{F}(b) + \rho \mathcal{F}(\nabla^T(z^k - u^k))}{1 + \rho |\mathcal{F}(\nabla)|^2} \right)}$$

其中 $\mathcal{F}$ 是傅里叶变换，$|\mathcal{F}(\nabla)|^2$ 是梯度的频域增益。

$z$-子问题（TV范数 + 二次惩罚）：

$$\min_z \lambda\|z\|_{2,1} + \frac{\rho}{2}\|z - (\nabla x^{k+1} + u^k)\|^2$$

对每个像素 $i$：

$$\boxed{z_i^{k+1} = \max\left\{ 1 - \frac{\lambda}{\rho\|\nabla x_i^{k+1} + u_i^k\|_2}, 0 \right\} \cdot (\nabla x_i^{k+1} + u_i^k)}$$

乘子更新：$u^{k+1} = u^k + \nabla x^{k+1} - z^{k+1}$。

每步计算量：$O(N \log N)$（FFT），极其高效！

例题14.7（ADMM求解稀疏逻辑回归）

题目：$\min_\beta \sum_{i=1}^n \log(1 + e^{-y_i x_i^T \beta}) + \lambda|\beta|_1$，写出ADMM框架。

解答：

引入 $z = \beta$，令 $f(\beta) = \sum_i \log(1 + e^{-y_i x_i^T \beta})$（逻辑损失的负对数似然），$g(z) = \lambda|z|_1$。

$\beta$-子问题（光滑凸 + 二次惩罚）：

$$\min_\beta \sum_{i=1}^n \log(1 + e^{-y_i x_i^T \beta}) + \frac{\rho}{2}\|\beta - z^k + u^k\|^2$$

无闭式解，但可用L-BFGS或牛顿法内层求解（因逻辑损失光滑，内层很快）。或者线性化——在当前点 $\beta^k$ 对逻辑损失做二次近似后直接求解。

$z$-子问题（$\ell_1$ 软阈值）：

$$z^{k+1} = \operatorname{soft}(\beta^{k+1} + u^k, \lambda/\rho)$$

乘子更新：$u^{k+1} = u^k + \beta^{k+1} - z^{k+1}$。

例题14.8（分布式ADMM——共识优化）

题目：描述如何在分布式场景下用ADMM求解 $\min_x \sum_{i=1}^N f_i(x)$（各节点有相同的变量 $x$ 但不同的目标函数 $f_i$）。

解答：

共识ADMM形式：引入每个节点的局部变量 $x_i$ 和全局共识变量 $z$：

$$\min_{\{x_i\}, z} \sum_{i=1}^N f_i(x_i) \quad \text{s.t.} \quad x_i = z \quad (i = 1, \ldots, N)$$

增广Lagrange（缩放形式）：

$$L_\rho = \sum_{i=1}^N \left[ f_i(x_i) + \frac{\rho}{2}\|x_i - z + u_i\|^2 \right]$$

迭代流程：

  1. 并行局部步：各节点 $i$ 独立求解 $x_i^{k+1} = \arg\min_{x_i} { f_i(x_i) + \frac{\rho}{2}|x_i - z^k + u_i^k|^2 }$（完全并行！）
  2. 中心聚合步：$z^{k+1} = \frac{1}{N}\sum_{i=1}^N (x_i^{k+1} + u_i^k)$（求平均）
  3. 局部乘子更新：$u_i^{k+1} = u_i^k + x_i^{k+1} - z^{k+1}$（各节点独立更新）

通信模式：每轮只需一次聚合（AllReduce求平均）——与对偶分解（Ch11）相同的通信复杂度，但收敛快得多。

例题14.9（ADMM的非凸扩展简介）

题目：讨论ADMM在非凸优化中的使用情况。

解答：

虽然ADMM的经典理论基于凸性，但近年大量实践表明它也能有效处理非凸问题：

  1. 非凸正则化：如 $\ell_{1/2}$ 正则化（非凸$\ell_p$“伪范数”）、SCAD、MCP等——$z$ 子问题使用非凸阈值算子（如 hard thresholding）。

  2. 矩阵分解：$\min_{U,V} |UV^T - M|_F^2$（非凸，因为 $U$ 和 $V$ 的乘积）。ADMM将 $UV^T$ 作为独立变量，施加"低秩"约束，交替更新 $U, V$ 和辅助变量。

  3. 深度学习：ADMM可替代SGD训练某些特定结构的神经网络，每层作为一个子问题。

非凸ADMM的收敛性：在有界的假设下，非凸ADMM能保证收敛到平稳点（不是全局最优）。收敛速度依赖问题的"凸性程度"（如 restricted strong convexity）。

例题14.10（ADMM实现检查清单）

题目：列出使用ADMM解决实际问题时的完整检查清单。

解答：

问题建模检查：

  1. 能否写成 $\min f(x) + g(z)$ s.t. $Ax + Bz = c$ 的形式？
  2. $f$ 和 $g$ 是否各有"容易的"子问题？（光谱 $f$ 是光滑二次 → 岭回归；$g$ 是 $\ell_1$ → 软阈值）
  3. 如果不行，考虑引入更多辅助变量或使用变量分裂。

子问题求解检查： 4. $x$ 子问题：能否写成 $\operatorname{prox}$ 或 $\min_x {f(x) + \frac{\rho}{2}|Ax - v|^2}$ 的形式？ 5. $z$ 子问题：$\operatorname{prox}_{g/\rho}$ 是否有闭式？ 6. 矩阵求逆 $A^T A + \rho I$ 是否可预计算（Cholesky）或利用结构加速（FFT、稀疏性）？

参数调优检查： 7. $\rho$ 是否适中（不太小 → 慢；不太大 → 病态）？ 8. 是否需要自适应 $\rho$（$|r^k|/|s^k|$ 比例偏离1时调整）？ 9. 是否设置了合理的迭代上限和收敛容差？

正确性验证检查： 10. 原始残差 $|Ax^k + Bz^k - c|$ 是否单调递减趋于0？ 11. 对偶残差 $|\rho A^T B(z^k - z^{k-1})|$ 是否趋于0？ 12. 目标值 $f(x^k) + g(z^k)$ 是否单调或接近单调趋于最优值？ 13. 输出解是否满足KKT条件（精度在容差内）？
