第13章：Douglas-Rachford分裂法

核心思想：对于 $\min_x f(x) + g(x)$（$f, g$ 都可能非光滑，但各自的邻近算子容易计算），DR分裂法通过交替使用两个邻近算子和反射-平均操作，将原问题转化为一个不动点迭代——无需任何函数光滑，仅需 $\operatorname{prox}_f$ 和 $\operatorname{prox}_g$ 可计算即可。

前置知识回顾

概念 定义（简要） 首次出现
邻近算子 $\operatorname{prox}$ $\operatorname{prox}_f(v) = \arg\min_x { f(x) + \frac{1}{2}|x - v|^2 }$——找离 $v$ 近且使 $f$ 小的点 Ch7
邻近梯度法（ISTA） $x_{k+1} = \operatorname{prox}_{\alpha g}(x_k - \alpha \nabla f(x_k))$，要求 $f$ 光滑 Ch7
Moreau分解 $v = \operatorname{prox}f(v) + \operatorname{prox}{f^*}(v)$——原空间和对偶空间的互补分解 Ch9
乘子法 $\lambda^{k+1} = \lambda^k + \rho(Ax^{k+1} - b)$，等价于对偶邻近点法 Ch12
极大单调算子 $T$ 满足 $\langle u - v, x - y \rangle \geq 0$（“决不反向"的映射），$\partial f$ 是最常见的例子 Ch9
不动点迭代 若 $T$ 非扩张（$|Tx - Ty| \leq |x - y|$）且 $\text{Fix}(T) \neq \varnothing$，则 $z_{k+1} = T(z_k)$ 收敛 本章详述
指示函数 $\delta_C$ $\delta_C(x) = \begin{cases} 0, & x \in C \ +\infty, & x \notin C \end{cases}$——进入 $C$ 外就"惩罚到无穷” Ch1

13.1 I型复合优化问题

13.1.1 问题形式

DR分裂法专攻以下结构（I型复合凸优化）：

$$\boxed{\min_{x \in \mathbb{R}^n} \; f(x) + g(x)}$$

符号逐字解释：

  • $x \in \mathbb{R}^n$：决策变量，$n$ 维列向量 $x = (x_1, \ldots, x_n)^T$。
  • $f: \mathbb{R}^n \to \mathbb{R} \cup {+\infty}$：闭凸函数。可以任意非光滑——可以有折角、可以不可微！唯一要求：$\operatorname{prox}_f$ 有闭式解或容易计算。
  • $g: \mathbb{R}^n \to \mathbb{R} \cup {+\infty}$：闭凸函数。同样可以任意非光滑，只要求 $\operatorname{prox}_g$ 好算。
  • 称为"I型"是因为 $f$ 和 $g$ 直接作用于同一个变量 $x$，没有线性变换的嵌套。

核心假设：问题有解（$\arg\min_x {f(x) + g(x)} \neq \varnothing$）。

13.1.2 与邻近梯度法（ISTA, Ch7）的本质区别

维度 邻近梯度法（ISTA, Ch7） DR分裂法（Ch13）
适用问题 $\min_x f(x) + g(x)$ $\min_x f(x) + g(x)$
对 $f$ 的要求 必须光滑（$\nabla f$ 存在且Lipschitz连续） 不需要光滑，仅需 $\operatorname{prox}_f$ 好算
对 $g$ 的要求 $\operatorname{prox}_g$ 好算 $\operatorname{prox}_g$ 好算
每次迭代使用 $\nabla f(x_k)$ + $\operatorname{prox}_{\alpha g}$ $\operatorname{prox}_f$ + $\operatorname{prox}_g$
理论框架 前向-后向分裂（Forward-Backward） 反射-平均不动点迭代
特例包含 LASSO（$f$ 光滑平方损失，$g = \lambda|\cdot|_1$） 两个凸集交集的投影（$f = \delta_{C_1}$，$g = \delta_{C_2}$）

🔑 DR分裂法是ISTA的重大推广：ISTA要求"$f$ 光滑, $g$ 非光滑"；DR分裂法只要求"两个函数的邻近算子都便宜"——这在很多实际问题中更容易满足。

13.1.3 重要特例：两个凸集交集的投影

当 $f = \delta_{C_1}$（集合 $C_1$ 的指示函数）且 $g = \delta_{C_2}$ 时：

$$\min_x \delta_{C_1}(x) + \delta_{C_2}(x) \quad \Longleftrightarrow \quad \text{找一点 } x \text{ 同时属于 } C_1 \text{ 和 } C_2$$

此时 $\operatorname{prox}_{\delta_C} = P_C$（投影到凸集 $C$ 上）。DR分裂法退化为寻找两个凸集交集的经典算法，比最朴素的交替投影法（Von Neumann交替投影）收敛更快、更稳定。

13.2 不动点迭代视角

13.2.1 反射算子（Reflection Operator）

定义：对于闭凸函数 $f$，其邻近反射算子 $R_f$ 定义为：

$$\boxed{R_f = 2\,\operatorname{prox}_f - I}$$

即对任意点 $z \in \mathbb{R}^n$：$R_f(z) = 2 \cdot \operatorname{prox}_f(z) - z$。

几何解释（以 $f = \delta_C$ 为例）：

  • $\operatorname{prox}_f(z) = P_C(z)$：将 $z$ 投影到集合 $C$ 上
  • $R_f(z) = 2P_C(z) - z = P_C(z) + (P_C(z) - z)$：从 $z$ 出发，穿过投影点 $P_C(z)$，再走同样距离，落到 $C$ 的另一侧——就像以 $P_C(z)$ 为镜面，$R_f(z)$ 是 $z$ 的"镜像"（反射）。
  • 形象比喻：$P_C(z)$ 是镜子上的点，$z$ 是你自己，$R_f(z)$ 是你在镜子里的像。

反射算子的关键性质：

  1. 非扩张性（Nonexpansiveness）：$|R_f(x) - R_f(y)| \leq |x - y|$（反射不拉伸距离）。
  2. 不动点：$z = R_f(z) \iff z = \operatorname{prox}_f(z) \iff 0 \in \partial f(z)$——即 $z$ 是 $f$ 的极小点。
  3. 对合性：$R_f \circ R_f = I$（反射两次回到原位置）。

13.2.2 DR分裂法的不动点形式

考虑 $\min_x f(x) + g(x)$ 的最优性条件：

$$0 \in \partial f(x^*) + \partial g(x^*)$$

引入次梯度的预解式（resolvent）——它恰好就是邻近算子：$J_{\partial f} = (I + \partial f)^{-1} = \operatorname{prox}_f$。

DR分裂法的核心迭代作用在一个辅助变量 $z$ 上：

$$\boxed{z_{k+1} = \left( \frac{R_f \circ R_g + I}{2} \right)(z_k) = \frac{1}{2}(R_f(R_g(z_k)) + z_k)}$$

这个算子 $T_{DR} = \frac{R_f \circ R_g + I}{2}$ 是两个反射的"平均"——先将两个反射复合（$R_f \circ R_g$），再与恒等映射平均（取中点），从而保证不动点迭代的稳定收敛。

13.2.3 为什么需要"平均"？

如果只用反射复合 $z_{k+1} = R_f(R_g(z_k))$：

  • 算子 $R_f \circ R_g$ 是非扩张的，但不动点迭代可能不收敛（环绕着不动点转圈而不靠近）。
  • 例子：$C_1 = {x \mid x_1 \geq 0}$，$C_2 = {x \mid x_2 \geq 0}$，它们的反射交替会在远离交点处无限循环。

平均操作 $\frac{T + I}{2}$ 将非扩张算子转化为稳定非扩张（firmly nonexpansive），保证不动点迭代 $z_{k+1} = T_{DR}(z_k)$ 的收敛。

13.3 DR迭代的完整推导

13.3.1 从最优性条件到不动点方程

步骤1——写出最优性条件。$x^*$ 是 $\min_x f(x) + g(x)$ 的解 $\iff$：

$$0 \in \partial f(x^*) + \partial g(x^*)$$

步骤2——引入"分裂"变量。上式等价于：存在一个辅助变量 $y$，使得：

$$y \in \partial g(x^*), \quad -y \in \partial f(x^*)$$

步骤3——用邻近算子重写。$y \in \partial g(x^) \iff x^ = \operatorname{prox}_g(x^* + y)$（因为邻近算子是次梯度预解式）。 类似地，$-y \in \partial f(x^) \iff x^ = \operatorname{prox}_f(x^* - y)$。

步骤4——引入反射算子。令 $z = x^* + y$，则：

$$\begin{aligned} x^* &= \operatorname{prox}_g(z) \\ R_g(z) &= 2\operatorname{prox}_g(z) - z = 2x^* - (x^* + y) = x^* - y \end{aligned}$$

进一步：$R_f(R_g(z)) = R_f(x^* - y)$。由于 $-y \in \partial f(x^)$，有 $\operatorname{prox}_f(x^ - y) = x^$，因此 $R_f(x^ - y) = 2x^* - (x^* - y) = x^* + y = z$。

步骤5——不动点方程。因此：

$$\boxed{R_f(R_g(z)) = z}$$

即 $z$ 是 $R_f \circ R_g$ 的不动点。

步骤6——平均化保证收敛。使用稳定平均：

$$\boxed{z_{k+1} = \frac{1}{2}\left( R_f(R_g(z_k)) + z_k \right)}$$

这正是DR分裂法的核心不动点迭代。收敛后，从辅助变量恢复原始解：

$$\boxed{x^* = \operatorname{prox}_g(z^*)}$$

13.3.2 算法流程（原生形式）

$$\boxed{\begin{aligned} &\textbf{初始化：} z_0 \in \mathbb{R}^n, \; k = 0 \\ &\textbf{重复：} \\ &\quad \text{① 在 } g \text{ 上做邻近步：} x_{k+1} = \operatorname{prox}_g(z_k) \\ &\quad \text{② 反射：} y_{k+1} = 2x_{k+1} - z_k \quad \text{（即 } R_g(z_k)\text{）} \\ &\quad \text{③ 在 } f \text{ 上做邻近步：} w_{k+1} = \operatorname{prox}_f(y_{k+1}) \\ &\quad \text{④ 反射：} v_{k+1} = 2w_{k+1} - y_{k+1} \quad \text{（即 } R_f(R_g(z_k))\text{）} \\ &\quad \text{⑤ 平均：} z_{k+1} = \frac{1}{2}(v_{k+1} + z_k) \\ &\textbf{直到收敛} \end{aligned}}$$

每次迭代的计算量：计算 $\operatorname{prox}_g$ 一次 + $\operatorname{prox}_f$ 一次。无需任何梯度计算。

13.3.3 简化形式的推导

将DR迭代的三个步骤合并，可以得到更紧凑的形式。

从 $z_{k+1}$ 的定义出发：

$$z_{k+1} = z_k + \frac{1}{2}(v_{k+1} - z_k) = z_k + \frac{1}{2}(R_f(R_g(z_k)) - z_k)$$

展开 $R_f(R_g(z_k))$：

$$R_f(R_g(z_k)) = 2\operatorname{prox}_f(2\operatorname{prox}_g(z_k) - z_k) - (2\operatorname{prox}_g(z_k) - z_k)$$

代回并化简得：

$$z_{k+1} = z_k + \operatorname{prox}_f(2\operatorname{prox}_g(z_k) - z_k) - \operatorname{prox}_g(z_k)$$

常见简化形式：

$$\boxed{\begin{aligned} x_{k+1} &= \operatorname{prox}_g(z_k) \\ y_{k+1} &= \operatorname{prox}_f(2x_{k+1} - z_k) \\ z_{k+1} &= z_k + y_{k+1} - x_{k+1} \end{aligned}}$$

这是DR分裂法最常用的三行实现形式，简洁而优雅。

13.4 松弛DR分裂法

13.4.1 引入松弛参数

在标准DR的平均步骤中引入松弛参数 $\gamma \in (0, 2)$：

$$\boxed{z_{k+1} = z_k + \gamma \left( \operatorname{prox}_f(2\operatorname{prox}_g(z_k) - z_k) - \operatorname{prox}_g(z_k) \right)}$$

当 $\gamma = 1$ 时退化为标准DR分裂法。

$\gamma$ 的作用：

  • $\gamma = 1$：标准DR（平衡速度与稳定性）
  • $\gamma < 1$：更保守，更稳定但较慢
  • $\gamma \in (1, 2)$：加速收敛（松弛/超松弛）
  • $\gamma = 2$：退化回无平均的反射复合（可能不收敛）
  • $\gamma \notin [0, 2]$：算法发散

收敛条件：对于任意 $\gamma \in (0, 2)$，松弛DR分裂法保证收敛。常取 $\gamma = 1.5 \sim 1.9$ 以获得加速效果。

13.4.2 松弛DR的等价形式

等价于对辅助变量做外推：

$$z_{k+1} = (1 - \gamma) z_k + \gamma \cdot R_f(R_g(z_k))$$

当 $\gamma = 1$ 就是半平均 $z_{k+1} = \frac{1}{2}(R_f(R_g(z_k)) + z_k)$。

13.5 图LASSO应用（Graph LASSO / Graphical LASSO）

13.5.1 问题背景

图LASSO用于从高维数据中学习稀疏精度矩阵（协方差矩阵的逆 $\Theta = \Sigma^{-1}$）。若 $\Theta_{ij} = 0$，则变量 $i$ 和 $j$ 在给定其他变量下条件独立——这在基因调控网络、金融风险建模中至关重要。

13.5.2 数学形式

$$\boxed{\min_{\Theta \succ 0} \; -\log\det \Theta + \langle S, \Theta \rangle + \lambda \|\Theta\|_{1, \text{off}}}$$

符号解释：

  • $\Theta \in \mathbb{R}^{p \times p}$：精度矩阵（precision matrix），必须是正定的（$\Theta \succ 0$）。
  • $S \in \mathbb{R}^{p \times p}$：样本协方差矩阵（已知数据计算）。
  • $-\log\det \Theta$：多元高斯的负对数似然（光滑凸函数）。
  • $\langle S, \Theta \rangle = \operatorname{tr}(S^T \Theta)$：Frobenius内积。
  • $|\Theta|{1, \text{off}} = \sum{i \neq j} |\Theta_{ij}|$：非对角元素的 $\ell_1$ 范数（诱导稀疏性）。

13.5.3 转化为DR分裂法可处理的形式

令：

$$f(\Theta) = -\log\det \Theta + \langle S, \Theta \rangle \quad \text{（光滑凸，有解析邻近算子）}$$

$$g(\Theta) = \lambda \|\Theta\|_{1, \text{off}} + \delta_{\{\Theta \succ 0\}}(\Theta) \quad \text{（非光滑，但在修改形式后邻近算子简单）}$$

实际常用DR分裂法的图LASSO解法：

  • $\operatorname{prox}_f$：对光滑的 $- \log\det \Theta$ 部分的邻近算子 = 求解一个特征值分解（对角化后做标量邻近）
  • $\operatorname{prox}_g$：$\ell_1$ 范数 + 正定锥约束 = 软阈值 + 谱投影

每次迭代计算 $\operatorname{prox}_{\ell_1}$（分量级软阈值）和对正定锥的投影（把负特征值clip到0），$O(p^3)$ 来自特征值分解。

13.6 DR分裂法与ADMM的内在关系

13.6.1 从DR到ADMM的变换

关键定理：ADMM（Ch14）是DR分裂法应用在对偶问题上的等价形式。

具体来说，考虑约束问题 $\min_{x,z} f(x) + g(z)$ s.t. $x = z$。其对偶问题为：

$$\max_\lambda \; -f^*(-\lambda) - g^*(\lambda)$$

即对偶问题是求 $\min_\lambda f^(-\lambda) + g^(\lambda)$——这正是I型复合优化！将DR分裂法应用于此对偶问题，得到的迭代恰好就是ADMM的迭代。

统一视角：

$$\boxed{\begin{array}{ccc} \text{DR分裂法（原空间）} & \longleftrightarrow & \text{ADMM（原空间）} \\ \min_x f(x) + g(x) & & \min_{x,z} f(x)+g(z) \text{ s.t. } x=z \\ \updownarrow \text{Moreau/共轭} & & \updownarrow \text{对偶} \\ \text{ADMM（对偶空间）} & \longleftrightarrow & \text{DR分裂法（对偶空间）} \\ \min_\lambda f^*(-\lambda) + g^*(\lambda) & & \min_\lambda f^*(-\lambda) + g^*(\lambda) + \text{约束} \end{array}}$$

这意味着ADMM和DR分裂法本质上是同一种算法在不同空间（原空间 vs 对偶空间）的表现。理解了DR不动点迭代的收敛性，就理解了ADMM的收敛性。

13.7 典型例题

例题13.1（DR基础推导——两个一维函数的复合）

题目：用DR分裂法求解 $\min_x |x| + \frac{1}{2}(x - 2)^2$。

解答：

令 $f(x) = \frac{1}{2}(x - 2)^2$（光滑），$g(x) = |x|$（非光滑），$\operatorname{prox}$ 均已知。

$\operatorname{prox}_f(v)$：解 $\min_x \frac{1}{2}(x-2)^2 + \frac{1}{2}(x-v)^2 \implies x = \frac{v+2}{2}$。

$\operatorname{prox}_g(v)$：软阈值 $\operatorname{soft}(v, 1) = \operatorname{sign}(v) \max{|v|-1, 0}$。

DR迭代（$\gamma = 1$）：

取 $z_0 = 0$：

  • $x_1 = \operatorname{prox}_g(z_0) = \operatorname{soft}(0, 1) = 0$

  • $y_1 = \operatorname{prox}_f(2x_1 - z_0) = \operatorname{prox}_f(0) = \frac{0+2}{2} = 1$

  • $z_1 = z_0 + y_1 - x_1 = 0 + 1 - 0 = 1$

  • $x_2 = \operatorname{prox}_g(z_1) = \operatorname{soft}(1, 1) = 0$

  • $y_2 = \operatorname{prox}_f(2x_2 - z_1) = \operatorname{prox}_f(-1) = \frac{-1+2}{2} = 0.5$

  • $z_2 = 1 + 0.5 - 0 = 1.5$

  • $x_3 = \operatorname{prox}_g(z_2) = \operatorname{soft}(1.5, 1) = 0.5$

  • $y_3 = \operatorname{prox}_f(2 \cdot 0.5 - 1.5) = \operatorname{prox}_f(-0.5) = \frac{-0.5+2}{2} = 0.75$

  • $z_3 = 1.5 + 0.75 - 0.5 = 1.75$

解析验证：原问题 $\min_x \frac{1}{2}(x-2)^2 + |x|$。分析 $x=0$ 处次梯度：$x < 0$ 时导数为 $x-2-1 = x-3$；$x \geq 0$ 时导数为 $x-2+1 = x-1$。令 $x-1 = 0 \implies x=1$（此时 $x \geq 0$，在定义域内）。故 $x^* = 1$。

DR迭代的 $x_k$ 序列：$0 \to 0 \to 0.5 \to 0.75 \to 0.875 \to \cdots \to 1$，向最优解单调递增收敛。

例题13.2（两个凸集交集的DR分裂法）

题目：用DR分裂法求点 $a = (3, 3)^T$ 到集合 $C_1 = {x \mid |x|_2 \leq 2}$（圆盘）与 $C_2 = {x \mid x_1 \geq 0, x_2 \geq 0}$（第一象限）交集的投影。

解答：

问题形式：$\min_x \frac{1}{2}|x - a|^2 + \delta_{C_1 \cap C_2}(x)$。

转化为I型复合：$f(x) = \delta_{C_1}(x)$，$g(x) = \delta_{C_2}(x) + \frac{1}{2}|x - a|^2$。

$\operatorname{prox}f = P{C_1}$（投影到圆盘）：$P_{C_1}(x) = \begin{cases} x, & |x|_2 \leq 2 \ 2\cdot \frac{x}{|x|_2}, & |x|_2 > 2 \end{cases}$

$\operatorname{prox}g(v)$：解 $\min{x \in C_2} \frac{1}{2}|x - v|^2 + \frac{1}{2}|x - a|^2 = \min_{x \in C_2} |x - \frac{v+a}{2}|^2$。即 $\operatorname{prox}g(v) = P{C_2}\left(\frac{v + a}{2}\right)$（投影到第一象限，取各分量与0的最大值）。

DR迭代：$x_{k+1} = P_{C_2}(\frac{z_k + a}{2})$，$y_{k+1} = P_{C_1}(2x_{k+1} - z_k)$，$z_{k+1} = z_k + y_{k+1} - x_{k+1}$。

取 $z_0 = a = (3, 3)^T$：

  • $x_1 = P_{C_2}(\frac{(3,3)+(3,3)}{2}) = P_{C_2}((3,3)) = (3,3)$
  • $y_1 = P_{C_1}(2(3,3) - (3,3)) = P_{C_1}((3,3)) = 2\cdot \frac{(3,3)}{\sqrt{18}} = (\frac{6}{\sqrt{18}}, \frac{6}{\sqrt{18}}) \approx (1.414, 1.414)$
  • $z_1 = (3,3) + (1.414,1.414) - (3,3) = (1.414, 1.414)$

DR迭代逐步将 $z_k$ 和 $x_k$ 推向交集的最优点 $(1.414, 1.414)^T$——这恰好是距离 $(3,3)$ 最近的、在半径2的圆内、且在第一象限的点。

例题13.3（DR vs ISTA的适用性对比）

题目：说明下列问题分别适用ISTA还是DR分裂法，并写出各自迭代的第一步。

(a) $\min_x \frac{1}{2}|Ax - b|^2 + \lambda|x|_1$（LASSO，$A$ 任意）

(b) $\min_x |x|_1 + \lambda|x|_2$（弹性网的无平方项版本）

(c) $\min_x |Ax - b|_1 + \lambda|x|_1$

解答：

(a) LASSO：$f(x) = \frac{1}{2}|Ax - b|^2$ 光滑（$\nabla f = A^T(Ax - b)$，Lipschitz常数 $L = |A^T A|$），$g = \lambda|\cdot|_1$ 非光滑但 $\operatorname{prox}$ 为软阈值。

ISTA适用：$x_{k+1} = \operatorname{soft}(x_k - \alpha A^T(Ax_k - b), \alpha\lambda)$。

DR也可用但不必要（ISTA更简单高效）。

(b) 各项范数之和：$f = |\cdot|_1$，$g = \lambda|\cdot|_2$，两者都非光滑！

ISTA不适用（缺少光滑项），DR适用：$\operatorname{prox}{\ell_1}$ = 软阈值，$\operatorname{prox}{\ell_2}$ = 群软阈值（group soft-thresholding）。

(c) 双$\ell_1$：$f(x) = |Ax - b|_1$（非光滑！），$g = \lambda|x|_1$（非光滑）。

ISTA不适用（$f$ 非光滑），DR适用，但需要计算 $\operatorname{prox}f$。而 $\operatorname{prox}{|A\cdot - b|_1}$ 通常没有闭式——这时需要内层迭代或转化为ADMM形式。

结论：DR的适用范围比ISTA广得多，代价是每次迭代可能需要更复杂的邻近算子计算。

核心要点

  1. DR分裂法的核心算子：$T_{DR} = \frac{R_f \circ R_g + I}{2}$（两个反射的平均），其不动点 $z^* = T_{DR}(z^*)$ 提供了一种通过邻近算子间接求解 $\min f + g$ 的途径。

  2. 反射算子的定义：$R_f = 2\operatorname{prox}_f - I$，几何上是以 $\operatorname{prox}_f(z)$ 为镜面，$R_f(z)$ 是 $z$ 的"镜像"。

  3. 平均操作的必须性：纯反射复合 $R_f \circ R_g$ 是非扩张的但可能不收敛；加上与 $I$ 的半平均（稳定非扩张）才保证不动点迭代的收敛。

  4. DR分裂法 = 无需梯度的邻近梯度法：ISTA要求 $f$ 光滑 → DR只需 $\operatorname{prox}_f$ 好算，对 $f$ 的微分性无要求。

  5. 松弛参数：$\gamma \in (0, 2)$ 调节收敛速度，$\gamma > 1$ 时加速，$\gamma = 1$ 是标准形式。

  6. DR → ADMM的统一桥梁：ADMM是DR分裂法应用在对偶问题上的等价形式。理解DR的不动点收敛 = 理解ADMM的收敛。

  7. 适用场景：$\ell_1$ 范数 + 核范数（RPCA）、$\ell_1$ + 指示函数（$\ell_1$ 约束去噪）、图LASSO（$\ell_1$ + $-\log\det$）、全变分去噪（TV + $\ell_2$ 拟合）等任意 $\operatorname{prox}$ 好算的两项和问题。

一句话总结：DR分裂法用"反射 + 平均"的不动点迭代，将两个非光滑函数的邻近算子编织在一起，优雅地求解 $\min f + g$ 而无需求导——它是ISTA从"光滑+非光滑"到"全非光滑"的飞跃，也是理解ADMM收敛性的理论基石。

13.8 补充例题

例题13.4（DR分裂法的最大单调算子推导）

题目：用极大单调算子理论重新推导DR分裂法的不动点形式。

解答：

求解 $\min_x f(x) + g(x)$ 等价于求 $0 \in \partial f(x) + \partial g(x)$。

令 $A = \partial f$，$B = \partial g$（两者都是极大单调算子）。问题化为 $0 \in (A + B)(x)$。

引入辅助变量 $z$，令 $x = J_B(z) = (I + B)^{-1}(z) = \operatorname{prox}_g(z)$。

等价条件：$z - x \in B(x)$ 且 $x - z \in A(x)$。这给出不动点条件：

$$z = R_A(R_B(z))$$

其中 $R_A = 2J_A - I = 2\operatorname{prox}_f - I$。

由于 $R_A \circ R_B$ 是非扩张的但可能不稳定，使用Krasnoselskii-Mann平均：

$$T_{DR} = (1 - \gamma)I + \gamma(R_A \circ R_B), \quad \gamma \in (0, 1)$$

取 $\gamma = 1/2$ 就是标准DR。这就从单调算子理论完整解释了DR迭代的由来和收敛性。

例题13.5（非负最小二乘的DR解法）

题目：$\min_{x \geq 0} \frac{1}{2}|Ax - b|^2$（非负最小二乘）。写出DR分裂法的迭代。

解答：

令 $f(x) = \frac{1}{2}|Ax - b|^2$，$g(x) = \delta_{\mathbb{R}^n_+}(x)$（非负锥的指示函数）。

$\operatorname{prox}_f(v)$：解 $\min_x \frac{1}{2}|Ax - b|^2 + \frac{1}{2}|x - v|^2$。 梯度：$A^T(Ax - b) + (x - v) = 0 \implies (A^T A + I)x = A^T b + v$。

$$\operatorname{prox}_f(v) = (A^T A + I)^{-1}(A^T b + v)$$

$\operatorname{prox}g(v) = P{\mathbb{R}^n_+}(v) = \max{v, 0}$（逐分量取正部）。

DR迭代：

$$\boxed{\begin{aligned} x_{k+1} &= \max\{z_k, 0\} \\ y_{k+1} &= (A^T A + I)^{-1}(A^T b + 2x_{k+1} - z_k) \\ z_{k+1} &= z_k + y_{k+1} - x_{k+1} \end{aligned}}$$

计算特点：$(A^T A + I)^{-1}$ 可预计算（Cholesky分解一次），每次迭代只需矩阵向量乘 + 逐分量max。记忆点：$x$ 步 = 投影到非负锥（简单），$y$ 步 = 岭回归求解（但可利用预计算加速）。

例题13.6（DR分裂法的松弛参数调优实验设计）

题目：设计实验说明松弛参数 $\gamma$ 对DR分裂法收敛的影响。

解答：

实验设置：$\min_x \frac{1}{2}|Ax - b|^2 + \lambda|x|_1$，取 $n = 200, p = 50$，$A$ 随机生成。

测试 $\gamma \in {0.5, 1.0, 1.5, 1.8, 1.9, 1.99}$。

预期结果：

  • $\gamma = 0.5$：保守，收敛慢但单调稳定
  • $\gamma = 1.0$：标准DR，稳定收敛
  • $\gamma = 1.5$：加速效果明显（~30% 更快达到相同精度）
  • $\gamma = 1.8, 1.9$：进一步加速，但出现轻微振荡
  • $\gamma = 1.99$：极快的前几个迭代，但后期可能振荡（$\gamma$ 太接近发散边界2）

实践建议：$\gamma = 1.5 \sim 1.8$ 通常是"加速不振荡"的最优区间。

例题13.7（DR与邻近梯度法的混合策略）

题目：若 $f$ 光滑且 $\operatorname{prox}_g$ 好算，应该用ISTA还是DR？给出决策准则。

解答：

场景 推荐算法 理由
$\nabla f$ 计算代价 « $\operatorname{prox}_f$ ISTA 梯度步比邻近步便宜
$\operatorname{prox}_f$ 有闭式解但 $\nabla f$ 昂贵 DR 避免梯度计算
$f$ 和 $g$ 的维数都很高 看 $\operatorname{prox}$ 复杂度 两者中的便宜者优先
$f$ 非光滑 只能用DR ISTA要求光滑
需调步长 DR优势（无需调步长） DR仅需 $\gamma \in (0,2)$

例题13.8（DR分裂法求解稀疏逆协方差——图LASSO的DR实现）

题目：将图LASSO $\min_{\Theta \succ 0} -\log\det\Theta + \langle S, \Theta \rangle + \lambda|\Theta|_{1,\text{off}}$ 转化适合DR分裂法的形式。

解答：

令 $f(\Theta) = -\log\det\Theta + \frac{\mu}{2}|\Theta|F^2$（强凸化），$g(\Theta) = \langle S, \Theta \rangle + \lambda|\Theta|{1,\text{off}} - \frac{\mu}{2}|\Theta|F^2 + \delta{{\Theta \succ 0}}(\Theta)$。

$\operatorname{prox}_f$：求解 $\min_\Theta -\log\det\Theta + \frac{\mu}{2}|\Theta|_F^2 + \frac{1}{2}|\Theta - V|_F^2$。

梯度条件：$-\Theta^{-1} + \mu\Theta + (\Theta - V) = 0 \implies -\Theta^{-1} + (\mu + 1)\Theta = V$。

对 $V$ 做特征分解 $V = Q\Lambda Q^T$，各特征值 $\lambda_i$ 对应解 $\theta_i$ 满足：

$$-\frac{1}{\theta_i} + (\mu+1)\theta_i = \lambda_i \implies \theta_i = \frac{\lambda_i + \sqrt{\lambda_i^2 + 4(\mu+1)}}{2(\mu+1)}$$

$\operatorname{prox}_f(V) = Q \operatorname{diag}(\theta_1, \ldots, \theta_p) Q^T$。

$\operatorname{prox}_g$：$\ell_1$ 软阈值（非对角元素）+ 对角元素直接传递 + 投影到正定锥（clip 负特征值到 $\epsilon$）。

DR迭代：每次做一次特征值分解（$O(p^3)$）和一次软阈值（$O(p^2)$），迭代次数通常为几十到几百次。

13.9 DR分裂法的几何直觉深化

13.9.1 反射-平均的"折返跑"比喻

想象你在一根绳子（可行集）的两端之间来回跑：

  1. 从当前位置 $z_k$ 出发，跑到 $g$-镜面，记下镜中像 $R_g(z_k)$
  2. 从 $R_g(z_k)$ 出发，跑到 $f$-镜面，记下第二次反射 $R_f(R_g(z_k))$
  3. 将这次"折返跑"的终点与原位置平均：$z_{k+1} = \frac{1}{2}(R_f(R_g(z_k)) + z_k)$

13.9.2 为什么Krasnoselskii-Mann平均保证收敛

非扩张算子 $T$（满足 $|Tx - Ty| \leq |x - y|$）的不动点迭代 $z_{k+1} = T(z_k)$ 可能不收敛——旋转映射就是反例（绕不动点转圈）。但松弛平均算子 $T_\gamma = (1-\gamma)I + \gamma T$（$\gamma \in (0,1)$）是稳定非扩张（firmly nonexpansive）的。对于稳定非扩张算子，只要存在不动点，平凡迭代必然收敛。这就是DR取 $\gamma = 1/2$ 的数学根基。

13.9.3 反射算子的深层数学结构

反射算子 $R_f = 2\operatorname{prox}_f - I$ 不只是邻近算子的简单代数变换。它与次梯度有深刻的联系：

$$R_f(x) = x - 2\operatorname{prox}_{f^*}(x) = (I + \partial f) \circ (I - \partial f)^{-1}(x)$$

这表明 $R_f$ 是将 $\partial f$ 通过 Cayley 变换映射到反射算子——建立了邻近算子与极大单调算子反射表示之间的桥梁。

13.10 DR分裂法的工程实践经验

13.10.1 计算邻近算子的数值技巧

  1. 利用结构：$\operatorname{prox}{\lambda|\cdot|1} = \operatorname{soft}$（$O(n)$ 时间），$\operatorname{prox}{|\cdot|*} = \operatorname{SVT}$（$O(n^3)$ 的SVD，但对稀疏矩阵可用随机算法加速）。
  2. 预计算：$\operatorname{prox}_{\frac{1}{2}|A\cdot - b|^2} = (A^T A + I)^{-1}(A^T b + v)$ 中的矩阵逆可预计算并缓存。
  3. 近似邻近：当精确邻近算子昂贵时，可用迭代法近似（如用几步共轭梯度近似岭回归的邻近算子）。

13.10.2 收敛监测与停机准则

原始残差：$r^k = |x_{k+1} - x_k|$（相邻迭代的变化） 不动点残差：$d^k = |z_k - R_f(R_g(z_k))|$（距不动点的距离） 目标下降：$\Delta F^k = |f(x_{k+1}) + g(x_{k+1}) - f(x_k) - g(x_k)|$

停机条件：$r^k < 10^{-6}$ 和 $d^k < 10^{-6}$ 同时满足。

13.10.3 常见陷阱与解决方案

陷阱 症状 解决
$\operatorname{prox}_f$ 无闭式 子问题无法精确求解 换用ADMM或使用内层迭代近似
收敛极慢 残差下降缓慢 调大 $\gamma \to 1.8$ 或检查问题是否病态
数值振荡 目标值上下波动 减小 $\gamma$ 或检查邻近算子的数值精度
不动点不存在 算法发散 检查 $f$ 和 $g$ 是否都是闭凸函数

例题13.7（DR与邻近梯度法的混合策略）

题目：若 $f$ 光滑且 $\operatorname{prox}_g$ 好算，应该用ISTA还是DR？给出决策准则。

解答：

场景 推荐算法 理由
$\nabla f$ 计算代价 « $\operatorname{prox}_f$ ISTA 梯度步比邻近步便宜
$\operatorname{prox}_f$ 有闭式解但 $\nabla f$ 昂贵 DR 避免梯度计算
$f$ 和 $g$ 的维数都很高 看 $\operatorname{prox}$ 复杂度 两者中的便宜者优先
$f$ 非光滑 只能用DR ISTA要求光滑
需调步长 DR优势（无步长） DR仅需 $\gamma \in (0,2)$

混合策略：若 $f$ 的光滑程度随时间变化（如前几个迭代高度非光滑，后面趋于光滑），可先用DR分裂法的稳健性度过初始阶段，再切换到ISTA以利用其较低的每步代价。

13.9 DR分裂法的几何直觉深化

13.9.1 反射-平均的"折返跑"比喻

想象你在一根绳子（可行集）的两端之间来回跑：

  1. 从当前位置 $z_k$ 出发，跑到 $g$-镜面，记下镜中像 $R_g(z_k)$
  2. 从 $R_g(z_k)$ 出发，跑到 $f$-镜面，记下第二次反射 $R_f(R_g(z_k))$
  3. 将这次"折返跑"的终点与原位置平均：$z_{k+1} = \frac{1}{2}(R_f(R_g(z_k)) + z_k)$

随着迭代，$z_k$ 逐渐接近两个镜面的交点（即不动点），同时 $x_k = \operatorname{prox}_g(z_k)$ 则接近 $\min(f+g)$ 的最优解。

13.9.2 为什么Krasnoselskii-Mann平均保证收敛

非扩张算子 $T$（满足 $|Tx - Ty| \leq |x - y|$）的不动点迭代 $z_{k+1} = T(z_k)$ 可能不收敛。但"松弛平均"算子 $T_\gamma = (1-\gamma)I + \gamma T$（$\gamma \in (0,1)$）是稳定非扩张（firmly nonexpansive）的，对于稳定非扩张算子，只要存在不动点，迭代必然收敛。这就是DR分裂法取半平均（$\gamma = 1/2$）的深层数学原因。
