第6章：投影梯度法

核心思想：将无约束优化的负梯度方向迈步与向可行凸集"投影"修正相结合——先迈出梯度步，若走出可行域则用投影弹回最近的可行点。当投影本身计算昂贵时，Frank-Wolfe（条件梯度法）以廉价的线性极小化取代投影，在同等 $O(1/k)$ 收敛率下大幅降低每步开销。

前置知识回顾

从第2章（梯度下降 GD）回顾

GD 迭代：$x_{k+1} = x_k - \alpha_k \nabla f(x_k)$。$\nabla f(x_k)$ 是 $f$ 在 $x_k$ 处的梯度（$n$ 维偏导数向量），指向上升最快的方向。

$L$-光滑（$L$-smooth）：存在 $L > 0$（光滑常数），使得对任意 $x, y \in \mathbb{R}^n$：

$$\|\nabla f(x) - \nabla f(y)\| \le L\|x - y\|$$

其中 $|z| = \sqrt{\sum_{i=1}^n z_i^2}$ 为欧几里得范数。光滑性意味着梯度不会"突变"——梯度的变化速度被 $L$ 约束。

二次上界（Descent Lemma）：对 $L$-光滑的 $f$，以下不等式对一切 $x, y$ 成立：

$$\boxed{f(y) \le f(x) + \nabla f(x)^T(y - x) + \frac{L}{2}\|y - x\|^2}$$

含义是函数值在任意点不超过以 $x$ 处一阶展开为中心的二次函数。

光滑凸 GD 收敛率（取步长 $\alpha = 1/L$）：

$$\boxed{f(x_k) - f^* \le \frac{L\|x_0 - x^*\|^2}{2k} = O(1/k)}$$

从第4章（次梯度法）回顾

  • 次梯度迭代：$x_{k+1} = x_k - \alpha_k g_k$，$g_k \in \partial f(x_k)$（从次微分集合中任选）。
  • $G$-Lipschitz：$|g| \le G$ 对所有次梯度成立（等价于 $|f(x)-f(y)| \le G|x-y|$）。
  • 收敛率：$f_{\text{best}}^K - f^* \le \frac{R^2 + G^2 \sum \alpha_k^2}{2\sum \alpha_k} = O(1/\sqrt{K})$。
  • 关键区别：GD 复杂度 $O(1/\epsilon)$，次梯度 $O(1/\epsilon^2)$——差一个量级。

6.1 投影算子

6.1.1 投影的严格定义

设 $C \subset \mathbb{R}^n$ 是一个非空闭凸集。逐一定义这三个性质：

  • 非空（nonempty）：$C$ 中至少含有一个点。空集的投影没有意义。
  • 闭（closed）：$C$ 包含其所有的极限点（边界点）。这保证了"最小化距离"这个极小值可以取到。
  • 凸（convex）：对任意 $x, y \in C$ 和 $\lambda \in [0, 1]$，凸组合 $\lambda x + (1-\lambda) y \in C$。凸性保证了投影的唯一性。

对任意点 $y \in \mathbb{R}^n$，$y$ 到集合 $C$ 的投影（projection）定义为 $C$ 中使欧几里得距离平方最小的那个点：

$$\boxed{P_C(y) = \arg\min_{x \in C} \|x - y\|^2 = \arg\min_{x \in C} \sum_{i=1}^n (x_i - y_i)^2}$$

$\arg\min$ 意为"令下列表达式取最小值的那个参数值"。为什么最小化的是距离的平方而非距离本身？因为平方函数是光滑且严格凸的（Hessian 恒等于单位矩阵 $I_n \succ 0$），分析起来方便很多，且平方和距离在同一处取最小值（因为是单调变换）。

6.1.2 存在性与唯一性：投影定理

投影定理（必背的核心结论）：

设 $C \subset \mathbb{R}^n$ 为非空闭凸集。对任意 $y \in \mathbb{R}^n$，存在唯一的 $P_C(y) \in C$ 满足：

$$\boxed{\|P_C(y) - y\| = \min_{x \in C} \|x - y\|}$$

且 $x^* = P_C(y)$ 等价于以下投影不等式（也是最优化的一阶充要条件）：

$$\boxed{\langle y - x^*, z - x^* \rangle \le 0, \quad \forall z \in C}$$

其中 $\langle a, b \rangle = a^T b = \sum_{i=1}^n a_i b_i$ 是两个向量的内积（dot product）。

投影不等式的几何直觉：向量 $y - x^$ 是从投影点指向原始点的方向；向量 $z - x^$ 是从投影点指向 $C$ 内任意其他点的方向。这两个向量的夹角 $\ge 90^\circ$（因为内积 $\le 0$）。换句话说——整个凸集 $C$ 完全坐落在以 $x^$ 为顶点、以外法向 $y - x^$ 为方向的某个闭合半空间（half-space）之内，而点 $y$ 位于这个半空间的外部。想象用一个"直角挡板"把整个集合和点 $y$ 隔开，$x^*$ 正好在挡板的顶点处。

存在性的证明思路：由于目标函数 $|x - y|^2$ 是强制的（当 $|x| \to \infty$，$|x - y|^2 \to \infty$），极小化这个问题等价于在其有界子集上极小化。Weierstrass 定理保证闭集上的连续函数在有界闭子集上取到最小值。

唯一性的证明思路：$|x - y|^2$ 是严格凸函数（其二阶导 = $2I_n$ 恒正定）。严格凸函数在凸集上如果有两个不同的极小点 $x_1 \neq x_2$，取中点 $(x_1+x_2)/2$ 的函数值严格小于 $x_1$ 和 $x_2$ 的函数值（由严格凸性的定义），但这与它们都是极小点矛盾。因此极小点唯一。

6.1.3 投影不等式的完整推导

从优化问题的最优性条件出发，逐行推导投影不等式。设 $x^* = P_C(y)$。

对任意 $z \in C$ 和 $\theta \in (0, 1]$，由 $C$ 的凸性，点 $x_\theta = (1-\theta) x^* + \theta z = x^* + \theta(z - x^*)$ 也属于 $C$。

由 $x^*$ 是极小点：

$$\|y - x^*\|^2 \le \|y - x_\theta\|^2 = \|y - x^* - \theta(z - x^*)\|^2$$

展开右边的范数平方：

$$\|y - x^*\|^2 \le \|y - x^*\|^2 - 2\theta \langle y - x^*, z - x^* \rangle + \theta^2 \|z - x^*\|^2$$

两边的 $|y - x^*|^2$ 抵销后，两边同除以正数 $\theta$：

$$0 \le -2\langle y - x^*, z - x^* \rangle + \theta \|z - x^*\|^2$$

令 $\theta \to 0^+$（趋近于 0 但不等于 0），含 $\theta$ 的项 $\theta |z - x^*|^2 \to 0$，取极限得：

$$\langle y - x^*, z - x^* \rangle \le 0, \quad \forall z \in C$$

推导完成。全过程中每一步的代数操作都有明确依据。

6.1.4 非扩张性（Nonexpansiveness）——PGD 的理论基石

定理：投影算子 $P_C$ 是非扩张的——即 1-Lipschitz：

$$\boxed{\|P_C(x) - P_C(y)\| \le \|x - y\|, \quad \forall x, y \in \mathbb{R}^n}$$

这个性质的含义是：两点的投影之间的距离绝不超过两点原距离。投影操作"不会放大误差"——这是 PGD 保持 GD 收敛率不衰减的终极原因。

完整证明：

设 $u = P_C(x)$，$v = P_C(y)$。

分别写出投影不等式。对于 $u$，取 $z = v \in C$：

$$\langle x - u, v - u \rangle \le 0 \tag{1}$$

对于 $v$，取 $z = u \in C$：

$$\langle y - v, u - v \rangle \le 0 \tag{2}$$

改写 (2)：将 $y - v$ 写为 $-(v - y)$，将 $u - v$ 写为 $-(v - u)$，两个负号相乘得正号：

$$\langle y - v, u - v \rangle = \langle v - y, v - u \rangle \le 0$$

将 (1) 和改写后的 (2) 相加：

$$\langle x - u, v - u \rangle + \langle v - y, v - u \rangle \le 0$$

利用内积对第一参数的双线性性，提取公因式 $(v - u)$：

$$\langle (x - u) + (v - y), v - u \rangle \le 0$$

即：

$$\langle (x - y) + (v - u), v - u \rangle \le 0$$

展开得含两项的内积和：

$$\langle x - y, v - u \rangle + \langle v - u, v - u \rangle \le 0$$

注意到 $\langle v - u, v - u \rangle = |v - u|^2$。移项：

$$\|v - u\|^2 \le -\langle x - y, v - u \rangle = \langle x - y, u - v \rangle$$

由 Cauchy-Schwarz 不等式（$|\langle a, b \rangle| \le |a| \cdot |b|$）：

$$\|u - v\|^2 \le \langle x - y, u - v \rangle \le \|x - y\| \cdot \|u - v\|$$

若 $|u - v| > 0$，两边除以 $|u - v|$ 即得 $|u - v| \le |x - y|$。若 $|u - v| = 0$，不等式平凡成立。证毕。

6.1.5 常见凸集投影的闭式解公式

闭式解（closed-form）指仅需有限次基本运算（加、减、乘、除、取最大/最小）即可直接算出，无需迭代求解子问题。

集合 数学描述 投影 $P_C(y)$ 的闭式公式 计算复杂度
非负象限 ${x \mid x_i \ge 0}$ $\max(y_i, 0)$（逐分量截断负数） $O(n)$
箱子约束 $[l, u] = {x \mid l_i \le x_i \le u_i}$ $\max(l_i, \min(y_i, u_i))$ $O(n)$
$\ell_2$ 球 ${x \mid |x|_2 \le r}$ $\frac{r}{\max(r, |y|_2)} \cdot y$ $O(n)$
仿射空间 ${x \mid Ax = b}$，$A$ 行满秩 $y - A^T(AA^T)^{-1}(Ay - b)$ $O(n^2 m)$
$\ell_1$ 球 ${x \mid |x|_1 \le 1}$ 需排序 + 二分搜索 $O(n \log n)$
核范数球 ${X \mid |X|_* \le \tau}$（奇异值和 ≤ τ） 需全量 SVD $O(n^3)$ — 贵
概率单纯形 ${x \mid x \ge 0, \sum_i x_i = 1}$ 需排序 + 累加搜索 $O(n \log n)$
半空间 ${x \mid a^T x \le b}$ ($a \neq 0$) $y - \frac{\max(0, a^T y - b)}{|a|^2}a$ $O(n)$

$\ell_2$ 球投影的详细推导

问题：$\min_{|x|_2 \le r} \frac{1}{2}|x - y|_2^2$（乘 $1/2$ 方便求导，不影响最优解位置）。

构造 Lagrange 函数：$\mathcal{L}(x, \lambda) = \frac{1}{2}|x-y|^2 + \lambda(|x| - r)$，其中 $\lambda \ge 0$ 是不等式约束 $|x| \le r$ 对应的 Lagrange 乘子。

对 $x$ 求梯度并令为零（设 $x \neq 0$）：

$$\nabla_x \mathcal{L} = x - y + \lambda \cdot \frac{x}{\|x\|} = \mathbf{0}$$

整理：$x(1 + \frac{\lambda}{|x|}) = y$。这说明 $x$ 和 $y$ 共线——存在标量 $\gamma \in (0, 1]$ 使得 $x = \gamma y$。

分两种情况：

  • $|y| \le r$（$y$ 已在球内）：取 $\gamma = 1$，$x = y$，不移动。
  • $|y| > r$（$y$ 在球外）：约束是紧的，$|x| = \gamma |y| = r$ → $\gamma = r / |y|$。

合并公式：

$$\boxed{P_C(y) = \frac{r}{\max(r, \|y\|_2)} \cdot y}$$

直觉：沿从原点到 $y$ 的射线方向缩放——在球外则缩到球面，在球内则保持不动。

6.2 投影梯度法 (Projected Gradient Descent, PGD)

6.2.1 问题与迭代格式

考虑带凸约束的凸优化问题：

$$\boxed{\min_{x \in C} \; f(x)}$$

其中 $f$ 为可微凸函数，$C$ 为非空闭凸集且其投影 $P_C$ 计算代价可接受。

PGD 的迭代格式：

$$\boxed{x_{k+1} = P_C\!\big(x_k - \alpha_k \nabla f(x_k)\big)}$$

分解为两步理解：

  1. 无约束梯度步：$\tilde{x}_{k+1} = x_k - \alpha_k \nabla f(x_k)$（同 GD）。
  2. 投影修正：$x_{k+1} = P_C(\tilde{x}_{k+1})$（若走出 $C$ 则弹回最近的可行点）。

物理类比：山坡上有限制区域（围栏）——第一步沿最陡方向迈出，若踩到围栏外，就反弹到最近的围栏内位置。

6.2.2 收敛性（光滑凸 + 闭凸约束）

假设：$f$ 是 $L$-光滑凸；$C$ 非空闭凸；最优解 $x^* \in C$ 存在；取步长 $\alpha_k = 1/L$。

结论：PGD 与无约束 GD 的收敛率完全相同：

$$\boxed{f(x_k) - f(x^*) \le \frac{L\|x_0 - x^*\|^2}{2k} = O(1/k)}$$

投影的非扩张性（不放大误差）是这一结论的理论保障。

6.2.3 收敛性推导要点

核心技巧：利用非扩张性，$|x_{k+1} - x^| \le |\tilde{x}_{k+1} - x^|$。将 $\tilde{x}_{k+1} = x_k - \frac{1}{L}\nabla f(x_k)$ 代入并展开范数平方，结合 $L$-光滑的二次上界和凸性的一阶条件，经代数整理得核心递推：

$$f(x_{k+1}) - f^* \le \frac{L}{2}(\|x_k - x^*\|^2 - \|x_{k+1} - x^*\|^2)$$

对 $i = 0, \dots, k-1$ 累加（Telescoping），利用 $f(x_{i+1}) \le f(x_i)$（光滑凸 PGD 下的单调递减），得 $k(f(x_k) - f^) \le \frac{L}{2}|x_0 - x^|^2$。移项即得结果。

6.2.4 投影次梯度法（非光滑情形）

当 $f$ 不可微但 $G$-Lipschitz 凸时，用次梯度 $g_k \in \partial f(x_k)$ 替代：

$$\boxed{x_{k+1} = P_C(x_k - \alpha_k g_k)}$$

收敛率退化到与无约束次梯度法同阶：

$$f_{\text{best}}^K - f^* \le \frac{R^2 + G^2 \sum \alpha_k^2}{2\sum \alpha_k} = O(1/\sqrt{K})$$

6.3 Frank-Wolfe（FW / 条件梯度法）

6.3.1 动机：当投影变得昂贵

PGD 每步需要 $P_C(y)$。当 $C$ 的投影有便宜闭式（box、$\ell_2$ 球）时 PGD 是高效的。但很多重要的凸约束其投影没有便宜闭式：

  • $\ell_1$ 球：投影需 $O(n \log n)$ 排序——高维时瓶颈显著。
  • 核范数球：投影需全量 SVD → $O(n^3)$——对大型矩阵不可接受。
  • 一般多面体 ${x: Ax \le b}$：投影本身是一轮二次规划。

FW 的核心创意：用线性极小化（LMO）取代投影——每步只需最小化一个线性函数在凸集 $C$ 上。

6.3.2 FW 的迭代格式

$$\boxed{\begin{aligned} s_k &= \arg\min_{s \in C} \; \nabla f(x_k)^T s \quad \text{(LMO：线性极小化)} \\ x_{k+1} &= (1 - \gamma_k) x_k + \gamma_k s_k \quad \text{(凸组合更新)} \end{aligned}}$$

符号逐一定义：

  • $s_k$ 是使线性函数 $\nabla f(x_k)^T s$（$s$ 的线性函数，因 $\nabla f(x_k)$ 在本步是常数向量）在 $C$ 上取最小的那个点。由于线性函数在紧凸集上的最小值必定在极点（extreme point / vertex，集合的"角"）处取到，因此 $s_k$ 是 $C$ 的一个顶点。
  • $\gamma_k \in [0, 1]$：步长（权重参数）。标准取法为 $\gamma_k = \frac{2}{k+2}$。
  • $x_{k+1}$ 是 $x_k$ 和 $s_k$ 的凸组合——由于两者都在 $C$ 内且 $\gamma_k \in [0, 1]$，$x_{k+1}$ 自动落在 $C$ 内——完全不需要投影来修正可行性！

$k$ 步后迭代点的结构：$x_k$ 是初始点 $x_0$ 和 $k$ 个顶点 $s_0, \dots, s_{k-1}$ 的凸组合。这意味着 FW 天然产生稀疏/低秩表示——在大量应用中这是无价的附加值。

以 $\ell_1$ 球为例：LMO 为何比投影便宜得多

对于 $C = {x: |x|1 \le 1}$： $$\min_{\|s\|_1 \le 1} \nabla f(x)^T s = -\max_{\|s\|_1 \le 1} (-\nabla f(x))^T s = -\|\nabla f(x)\|_\infty$$ 其中 $|v|\infty = \max_i |v_i|$ 是无穷范数。这只需扫描 $\nabla f(x)$ 的 $n$ 个分量找到绝对值最大的那个 → $O(n)$ 时间。对比投影的 $O(n \log n)$。

6.3.3 收敛性分析：$O(1/k)$ 的数学归纳法完整证明

假设：$f$ 是 $L$-光滑凸；$C$ 为紧凸集，直径 $D = \max_{x,y \in C}|x-y| < \infty$；$x^* \in C$；步长 $\gamma_k = 2/(k+2)$；定义最优性间隙 $\Delta_k = f(x_k) - f^*$。

Step 1：利用 $L$-光滑二次上界

$$f(x_{k+1}) \le f(x_k) + \nabla f(x_k)^T(x_{k+1} - x_k) + \frac{L}{2}\|x_{k+1} - x_k\|^2$$

代入 $x_{k+1} - x_k = \gamma_k(s_k - x_k)$ 并利用 $|s_k - x_k| \le D$：

$$f(x_{k+1}) \le f(x_k) + \gamma_k \nabla f(x_k)^T(s_k - x_k) + \frac{L}{2}\gamma_k^2 D^2 \tag{1}$$

Step 2：LMO 的最优性导出核心不等式

$s_k$ 使 $\nabla f(x_k)^T s$ 在 $C$ 上取最小值，因此对任意 $y \in C$（特别取 $y = x^*$）：

$$\nabla f(x_k)^T s_k \le \nabla f(x_k)^T x^*$$

所以：

$$\nabla f(x_k)^T(s_k - x_k) \le \nabla f(x_k)^T(x^* - x_k)$$

由 $f$ 的凸性（$f(x^) \ge f(x_k) + \nabla f(x_k)^T(x^ - x_k)$）移项：

$$\nabla f(x_k)^T(x^* - x_k) \le -\Delta_k$$

合并得 FW 核心不等式：

$$\boxed{\nabla f(x_k)^T(s_k - x_k) \le -\Delta_k} \tag{2}$$

含义：LMO 给出的方向 $s_k - x_k$ 的线性近似，至少和直接指向 $x^*$ 的方向一样好。

Step 3：代入得核心递推

将 (2) 代入 (1) 并两边减去 $f^*$：

$$\Delta_{k+1} \le \Delta_k - \gamma_k \Delta_k + \frac{L}{2}\gamma_k^2 D^2$$

即：

$$\boxed{\Delta_{k+1} \le (1 - \gamma_k)\Delta_k + \frac{L}{2}\gamma_k^2 D^2} \tag{★}$$

这是 FW 收敛的核心递推不等式。

Step 4：数学归纳法

取 $\gamma_k = 2/(k+2)$。归纳假设：$\Delta_k \le \frac{2LD^2}{k+2}$。

归纳奠基（$k=0$）：由光滑性可证 $\Delta_0 \le LD^2 \le \frac{2LD^2}{2}$。✓

归纳递推（设归纳假设对 $k$ 成立，证对 $k+1$ 成立）：

将 $\gamma_k = 2/(k+2)$ 和归纳假设代入 (★)：

$$\begin{aligned} \Delta_{k+1} &\le \left(1 - \frac{2}{k+2}\right) \cdot \frac{2LD^2}{k+2} + \frac{L}{2} \cdot \left(\frac{2}{k+2}\right)^2 \cdot D^2 \\ &= \frac{k}{k+2} \cdot \frac{2LD^2}{k+2} + \frac{L}{2} \cdot \frac{4}{(k+2)^2} \cdot D^2 \\ &= \frac{2LD^2 k}{(k+2)^2} + \frac{2LD^2}{(k+2)^2} \\ &= \frac{2LD^2 (k+1)}{(k+2)^2} \end{aligned}$$

需要验证 $\frac{2LD^2(k+1)}{(k+2)^2} \le \frac{2LD^2}{k+3}$。约去 $2LD^2$：

$$\frac{k+1}{(k+2)^2} \le \frac{1}{k+3}$$

交叉相乘（分母均为正）：

$$(k+1)(k+3) \le (k+2)^2$$

展开：

$$k^2 + 4k + 3 \le k^2 + 4k + 4 \iff 3 \le 4$$

恒成立！归纳完成。

$$\boxed{f(x_k) - f(x^*) \le \frac{2LD^2}{k+2} = O(1/k)}$$

此处取 $\gamma_k = 2/(k+2)$ 的原因：$\gamma_0 = 2/2 = 1$，意味着第一步完全跳到第一个 LMO 给出的顶点。

6.3.4 FW 与 PGD 的系统对比

维度 投影梯度法 (PGD) Frank-Wolfe (FW)
每步子问题 投影 $P_C(\cdot)$ 线性极小化 $\min_{s \in C} g^T s$
$\ell_1$ 球开销 $O(n \log n)$（排序） $O(n)$（扫描）
核范数球开销 $O(n^3)$（满SVD） $O(n^2)$（秩1幂迭代）
可行性 事后投影修正 自动（凸组合天然可行）
收敛率 $O(1/k)$ $O(1/k)$
收敛常数 $\frac{L}{2}|x_0 - x^*|^2$ $2LD^2$（$D \ge R$，常数偏大）
迭代点结构 密集向量 稀疏/低秩（顶点凸组合）
强凸下表现 线性收敛 仅 $O(1/k)$（无加速）
适用场景 投影便宜时 投影贵但 LMO 便宜时

选型原则：

  • 投影有 $O(n)$ 闭式 → PGD（最快最直接）
  • 投影需 $O(n \log n)$ 或以上 → 考虑 FW
  • 需要稀疏/低秩迭代点作为副产品 → FW
  • 需要高精度（$\epsilon \le 10^{-7}$）→ PGD（FW 常数大 + 后期慢）
  • 目标函数强凸 → 必须 PGD（FW 无法利用强凸性加速）

6.4 典型例题

例题1：投影非扩张性完整证明

题目：$C$ 非空闭凸，证明 $|P_C(x) - P_C(y)| \le |x - y|$。

证明：已在上文 §6.1.4 给出逐行推演——写两条投影不等式 → 相加 → 合并 → 利用 $|u-v|^2$ 恒等式 → Cauchy-Schwarz → 消去因子得证。

例题2：PGD 收敛性

题目：$f$ 是 $L$-光滑凸，$C$ 非空闭凸，$\alpha = 1/L$。证明 $f(x_k) - f^* \le \frac{L|x_0 - x^*|^2}{2k}$。

证明：关键三步——光滑性展开 $f(x_{k+1})$ + 投影非扩张性控制 $|x_{k+1} - x^*|$ + Telescoping。投影不扩大距离，约束不损害收敛率。

例题3：FW 收敛归纳法证明

题目：补全 §6.3.3 的归纳步骤，验证 $\gamma_k = 2/(k+2)$ 时 $\Delta_k \le 2LD^2/(k+2)$。

解答：核心验证为 $(k+1)(k+3) \le (k+2)^2 \iff k^2+4k+3 \le k^2+4k+4 \iff 3 \le 4$ 恒成立。取 $\gamma_k = 2/(k+2)$ 确保 $\gamma_0 = 1$。

例题4：$\ell_1$ 球 FW vs PGD 对比

题目：$C = {x: |x|_1 \le 1}$。对比 FW 和 PGD 每步的完整计算流程及复杂度。

解答：

步骤 FW PGD
子问题 找 $-|\nabla f(x_k)|_\infty$：$O(n)$ $\ell_1$ 球投影：$O(n \log n)$
更新 凸组合：$O(n)$ 直接赋值：$O(n)$
总步耗 $\approx 2n$ $\approx n \log n + n$

$n = 10^6$ 时：FW ≈ 2ms，PGD ≈ 20ms → FW 约快 10 倍。

例题5：核范数约束 FW

题目：$C = {X: |X|_* \le \tau}$。写出 FW 的 LMO 解及开销分析。

解答：$\min_{|S|_* \le \tau} \langle G, S \rangle = -\tau |G|_2$。取 $G = \nabla f(X_k)$ 的最大奇异值对应的左右奇异向量 $u_1, v_1$，得 LMO 解 $S_k = -\tau u_1 v_1^T$（秩 1）。开销：幂迭代法 $O(mn)$，vs 满 SVD 的 $O(mn\min(m,n))$。且 FW 自动维护低秩——$k$ 步后 $\text{rank}(X_k) \le k$。

例题6：半空间投影推导

题目：$C = {x: a^T x \le b}$，推导 $P_C(y)$ 的闭式。

解答：Lagrange 函数 → 导数为零 → $x = y - \lambda a$。分情况：若 $a^T y \le b$ 则 $\lambda = 0$；否则 $\lambda = (a^T y - b)/|a|^2$。合并公式：

$$\boxed{P_C(y) = y - \frac{\max(0, a^T y - b)}{\|a\|^2} a}$$

核心要点

  1. 投影：$P_C(y) = \arg\min_{x \in C} |x-y|^2$；$C$ 非空闭凸 → 存在唯一。
  2. 投影不等式：$\langle y - P_C(y), z - P_C(y) \rangle \le 0$，$\forall z \in C$。
  3. 非扩张性：$|P_C(x) - P_C(y)| \le |x - y|$ → PGD 不损失 GD 收敛率的根源。
  4. PGD 收敛率：光滑凸 → $O(1/k)$，与无约束 GD 完全一致。
  5. FW 动机：投影太贵时，用 $O(n)$ 的 LMO 替代（$\ell_1$ 球、核范数球的巨大差距）。
  6. FW 收敛率：$O(1/k)$ 归纳证明；$\gamma_k = 2/(k+2)$；核心验证 $3 \le 4$。
  7. 选型原则：投影便宜 → PGD；投影贵 → FW；需稀疏/低秩 → FW。

交叉引用：无约束 GD 见第2章；次梯度定义见第3章；非光滑约束下见投影次梯度法（与第4章一脉相承）。FW 的进阶变体（Away-step FW, Pairwise FW）可在强凸下获得线性收敛，属进阶专题。
