Algebraic Multigrid：换一个尺度消除难消的误差

Oct 04, 2026
阅读时长: 3 分钟

主题：Algebraic Multigrid（AMG，代数多重网格）
领域：有限元 × 数值线性代数 × 物理求解器 × HPC
阅读时间：约 4–5 分钟

今天补充一个此前尚未系统覆盖、但对大型有限元求解器至关重要的概念：代数多重网格。

它解决的是一个非常基础的问题：随着网格不断细化，为什么许多迭代求解器越来越慢？AMG 的核心发现是：

迭代方法难以消除的误差，往往可以通过改变表示尺度，转化成容易处理的误差。

这使得某些大型稀疏线性系统能够以接近 \(O(N)\) 的计算复杂度求解，而不必付出传统直接分解的高昂代价。AMG 尤其适合椭圆型 PDE 离散产生的系统，实际表现仍取决于算子性质和粗化策略。

一、为什么普通迭代法会越算越慢？

考虑有限元中的线性系统：

\[ Ku=f. \]

先用最简单的一维 Poisson 方程理解：

\[ -\frac{d^2u}{dx^2}=f(x). \]

离散以后：

\[ K=\frac{1}{h^2} \begin{bmatrix} 2&-1&&\\ -1&2&-1&\\ &\ddots&\ddots&\ddots\\ &&-1&2 \end{bmatrix}. \]

使用 Jacobi 迭代：

\[ u^{k+1}=u^k+\omega D^{-1}(f-Ku^k). \]

其中 \(D\) 是 \(K\) 的对角部分。

设误差为：

\[ e^k=u^k-u^\star. \]

那么：

\[ e^{k+1}=(I-\omega D^{-1}K)e^k. \]

对离散正弦误差模式进行分析，可以得到误差放大因子：

\[ \boxed{ \mu_j=1-\omega\left(1-\cos\frac{j\pi}{n+1}\right). } \]

取 \(\omega=2/3\)。

对于高频误差，\(|\mu_j|\) 通常较小，意味着误差快速衰减。

但对于低频误差：

\[ j\ll n, \]

有：

\[ \mu_j\approx1. \]

这意味着：

\[ \boxed{\text{Jacobi 很容易消除剧烈振荡的误差，却很难消除缓慢变化的误差。}} \]

随着网格加密，越来越多难以消除的低频误差模式出现。

这正是传统局部松弛迭代难以保持网格无关收敛速度的根源。

二、Multigrid 的核心：让低频误差变成高频误差

假设在细网格上存在一个缓慢变化的误差：

\[ e(x)=\sin(\pi x). \]

对于有 1000 个节点的网格，这个误差变化非常缓慢。

但如果把它转移到只有几十个节点的粗网格上，它相对于网格尺度就不再那么平缓。

多重网格利用的正是这种尺度变化。

一个经典的两层算法包含：

第一步：细网格平滑

用 Jacobi 或 Gauss–Seidel 消除高频误差。

第二步：将残差传递到粗网格

\[ r_h=f_h-K_hu_h. \]

通过限制算子 \(R\)：

\[ r_H=Rr_h. \]

第三步：在粗网格上求误差修正

\[ K_He_H=r_H. \]

第四步：把修正传回细网格

\[ u_h\leftarrow u_h+Pe_H. \]

其中 \(P\) 是插值算子。

随后再进行若干次平滑。

这一过程可以递归执行，形成 V-cycle。

它的本质是：

\[ \boxed{ \text{细网格消除局部误差，粗网格消除全局误差。} } \]

这比单纯增加 Jacobi 迭代次数有效得多。

三、AMG 最深刻的一步：没有几何网格，也能构造粗网格

查看完整推导与细节

传统 Geometric Multigrid（GMG）需要知道网格的几何层级。

但真实工业有限元往往使用：

  • 非结构化四面体网格；
  • 复杂拓扑；
  • 局部加密；
  • 不规则材料分布。

很难直接生成质量良好的几何粗网格。

AMG 提出了一个更抽象的问题：

\[ \boxed{\text{能否仅从矩阵 }K\text{ 的代数结构，推断哪些自由度应该一起粗化？}} \]

答案是可以。

AMG 根据矩阵系数、变量之间的强连接关系，以及松弛过程难以消除的误差模式，构造粗层空间。

它并不要求知道节点的真实坐标。

然后通过：

\[ \boxed{ K_H=R K_h P } \]

构造粗层算子。

对于对称正定问题，通常取：

\[ R=P^T, \]

于是：

\[ \boxed{ K_H=P^TK_hP. } \]

这实际上就是一个 Galerkin 投影。

因此 AMG 可以理解成：

从矩阵本身自动寻找适合误差修正的低维空间，并在多个尺度上反复求解。

SIAM 的经典教材 A Multigrid Tutorial 专门讨论了这一问题：即使未知量没有明确的几何位置，也可以根据代数关系建立多重网格方法。

四、一个非常重要的概念：Near-nullspace

查看完整推导与细节

AMG 的粗空间应该保留哪些模式？

答案是：

\[ \boxed{\text{那些能量很低、局部迭代难以消除的误差模式。}} \]

考虑线弹性系统：

\[ Ku=f. \]

对于一个没有约束的三维弹性体，存在六种刚体运动模式：

\[ \underbrace{3\text{ 个平移}}_{\text{translation}} + \underbrace{3\text{ 个转动}}_{\text{rotation}}. \]

这些模式不会产生弹性应变能。

因此：

\[ Kz_i=0. \]

它们构成刚度矩阵的零空间。

施加边界条件后，刚体模式通常不再是严格零模态，但相关低能量模式仍可能对迭代收敛十分重要。

如果 AMG 的粗空间无法表示这些模式，求解器就可能难以消除对应的误差。

这就是 Near-nullspace-aware AMG 的意义。

在实际工程中，PETSc 明确提供：

MatNullSpaceCreateRigidBody()

和：

MatSetNearNullSpace()

帮助 AMG 预条件器识别弹性系统的刚体运动模式。官方文档指出，这能够显著改善 PCGAMG 对弹性问题的求解效率。

这说明一个很重要的事实：

\[ \boxed{\text{优秀的线性求解器不仅利用矩阵数值，还利用矩阵背后的物理结构。}} \]

五、Smoothed Aggregation：从粗略分组到低能量插值

查看完整推导与细节

AMG 有多个技术分支，其中 Smoothed Aggregation（SA-AMG）特别值得理解。

它首先将自由度划分为若干聚合体（aggregates）。

构造一个初始插值矩阵：

\[ P_0. \]

然后对插值矩阵进行平滑，例如：

\[ \boxed{ P=(I-\omega D^{-1}K)P_0. } \]

这样得到的粗空间更适合表示代数光滑误差。

其关键思想是：

\[ \boxed{\text{粗空间不能只由变量分组决定，还应该适应系统的低能量结构。}} \]

Vaněk、Mandel 和 Brezina 在 1996 年的经典工作中系统发展了 Smoothed Aggregation，并将其用于二阶和四阶椭圆问题。

现代 PyAMG 和 PETSc 都实现了相关方法。

六、它对软体动力学求解器有什么价值？

考虑隐式软体动力学：

\[ M\ddot x+f_{\rm int}(x)=f_{\rm ext}. \]

使用 Newton 法后，需要反复求解：

\[ \boxed{ \left(\frac{M}{h^2}+K_t\right)\Delta x=-r. } \]

对于百万自由度的四面体模型，这个线性系统可能成为主要性能瓶颈。

AMG 可以作为 CG 等 Krylov 迭代法的预条件器：

\[ \boxed{\text{AMG-preconditioned CG}.} \]

它不要求像传统 ROM 一样提前收集训练轨迹，也不要求模型具有很低的全局秩。

因此它解决的是另一类问题：

  • ROM：降低需要求解的自由度数量；
  • AMG：在保留完整自由度的情况下，提高线性系统求解效率；
  • PD：通过特殊能量结构，让全局矩阵可以重复分解。

这三者具有完全不同的加速机制。

不过 AMG 也有明显限制。

对于严重材料非线性、强各向异性、接触激活引起的矩阵突变，或者不定的切线刚度矩阵，普通 AMG 可能退化，需要专门的平滑器、粗空间或块预条件策略。

此外，构建 AMG 层级本身也有成本。

如果每个时间步的矩阵都发生显著变化，就必须考虑：

\[ \boxed{\text{层级重建成本与迭代加速收益之间的平衡。}} \]

因此工业实现往往将 AMG 作为预条件器，并针对具体物理系统调整粗化与插值策略。

七、一个很值得做的数值实验

查看完整推导与细节

使用 Python 的 PyAMG，生成不同规模的二维 Poisson 问题：

\[ n=32,\ 64,\ 128,\ 256. \]

比较：

  1. Jacobi；
  2. CG；
  3. AMG-preconditioned CG。

统一要求：

\[ \frac{\|Ku-f\|_2}{\|f\|_2}<10^{-8}. \]

记录迭代次数、求解时间和 AMG 层级构建时间。

预期观察到：

Jacobi 的迭代次数会随着网格细化显著增长。

CG 也通常表现出一定的网格尺度依赖。

而配置良好的 AMG-preconditioned CG，在这类规则椭圆问题中，迭代次数往往能够基本保持稳定。

然后进一步尝试：

将 Poisson 问题替换为三维线弹性问题，并向 AMG 提供刚体 near-nullspace。

比较提供和不提供刚体模式时的收敛差异。

这个实验能够直接说明：粗空间的质量往往比增加局部迭代次数更重要。

它在知识体系中卡在哪里？

AMG 位于大型物理仿真的底层数值求解层：

\[ \text{物理方程} \]\[ \downarrow \]\[ \text{FEM / FV 离散} \]\[ \downarrow \]\[ Ku=f \]\[ \downarrow \]\[ \boxed{\text{Krylov 迭代 + AMG 预条件}} \]\[ \downarrow \]\[ \text{高效求解完整离散系统} \]

它与之前学习的 POD、Hyper-reduction、Projective Dynamics 共同构成了大型物理仿真的不同加速路线。

其中最值得记住的是：

\[ \boxed{ \text{一个误差模式难以消除， 可能只是因为你正在错误的尺度上处理它。} } \]

AMG 将这一思想从规则几何网格推广到了任意稀疏矩阵的代数结构。

更深一层，它告诉我们：预条件器本质上是在为迭代算法重新组织问题的几何结构。

这也是为什么预条件技术值得与有限元、ROM 和数值优化并列学习。
