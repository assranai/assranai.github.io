阅读时长: 7 分钟

Hyper-reduction：状态维数降到几十，并不意味着非线性有限元真的变快

主题：Hyper-reduction（超降阶），重点理解 DEIM 与 ECSW
领域：有限元 × 数值方法 × 代理模型 × 软体动力学
推荐阅读时间：约 8–10 分钟

这期选 Hyper-reduction，因为它揭示了降阶模型里一个非常容易被忽略的事实：

\[\boxed{ \text{“自由度少了”与“计算成本少了”不是同一件事。} }\]

假设原始有限元有：

\[N=10^6\]

个自由度。

通过 POD/Reduced Basis 得到：

\[u\approx Vq, \qquad V\in\mathbb R^{N\times r}, \quad r=50.\]

看起来问题已经从：

\[10^6\]

维降到了：

\[50\]

维。

但如果系统含有非线性内力：

\[f_{\rm int}(u),\]

每一步仍然必须先在完整网格上计算：

\[f_{\rm int}(Vq)\in\mathbb R^N,\]

然后才投影：

\[V^T f_{\rm int}(Vq).\]

于是你虽然只求 50 个未知量，却可能依然遍历：

\[\boxed{\text{全部百万个自由度 / 全部有限元单元。}}\]

这就是 projection-based nonlinear ROM 的经典瓶颈。DEIM 正是为此提出：让非线性项只在少数经过挑选的位置上求值；ECSW 则进一步从有限元虚功/能量结构出发，只计算少量具有权重的代表单元。

真正值得记住的是：

\[\boxed{ \text{Model reduction 降的是状态空间； Hyper-reduction 降的是算子求值成本。} }\]

1. 为什么线性 ROM 很容易真正做到快，非线性 ROM 却不行？

先看线性有限元：

\[M\ddot u+Ku=f.\]

设：

\[u=Vq.\]

Galerkin 投影：

\[V^TMV\ddot q + V^TKVq = V^Tf.\]

定义：

\[M_r=V^TMV,\]\[K_r=V^TKV.\]

这些矩阵可以在 offline 阶段提前算好。

在线计算只剩：

\[M_r\ddot q+K_rq=f_r,\]

矩阵规模只有：

\[r\times r.\]

于是 online cost 真正与：

\[N\]

脱钩。

这叫：

\[\boxed{\text{offline-online decomposition}}\]

，也是 Reduced Basis / projection ROM 最理想的状态。经典 projection-based model reduction 综述正是把“online cost 是否与高维系统规模无关”视为参数化降阶模型是否真正有效的重要标准。

2. 非线性一出现，offline-online decomposition 就断了

假设：

\[M\ddot u+f_{\rm int}(u)=f_{\rm ext}.\]

代入：

\[u=Vq,\]

得到：

\[M_r\ddot q + \boxed{ V^Tf_{\rm int}(Vq) } = f_r.\]

问题就在方框里。

即使：

\[q\in\mathbb R^{50},\]

为了算：

\[f_{\rm int}(Vq),\]

你通常仍需要：

1
2
3
4
5

对所有 element:
    计算 F
    计算 constitutive law
    计算 element force
    assemble

因此复杂度仍然接近：

\[O(N).\]

如果是隐式求解，还要计算：

\[K_t(u) = \frac{\partial f_{\rm int}}{\partial u}\]

以及：

\[V^TK_t(Vq)V.\]

于是：

\[\boxed{ \text{降阶后的线性系统很小， 但构造这个小系统仍然很贵。} }\]

Farhat 等对 ECSW 的分析明确指出：对于 nonlinear ROM，显式计算的主要成本在 projected residual；隐式计算还需要 projected Jacobian，这两个高维算子求值正是 hyper-reduction 要消除的瓶颈。

3. Hyper-reduction 到底“超”在哪里？

普通 reduction：

\[u\in\mathbb R^N\]

被压缩成：

\[q\in\mathbb R^r.\]

Hyper-reduction 再进一步问：

\[\boxed{ \text{为了算 reduced equation， 真的有必要看全部 }N\text{ 个空间位置吗？} }\]

如果真正重要的 nonlinear information 只需要在：

\[m\ll N\]

个位置上求值，

就可以把：

\[O(N)\]

operator evaluation 进一步变成：

\[O(m).\]

因此整个结构是：

\[\text{Full-order model}\]\[\downarrow\]\[\text{POD / Reduced Basis}\]\[\boxed{\text{降低未知量数目}}\]\[\downarrow\]\[\text{Hyper-reduction}\]\[\boxed{\text{降低 nonlinear operator 求值成本}}.\]

这两个层次必须同时存在，nonlinear ROM 才可能真正获得数量级的在线加速。

4. DEIM：既然整个非线性向量有低维结构，就没必要把它全部算出来

假设：

\[f(u)\in\mathbb R^N\]

虽然有：

\[N\]

个分量，但在训练数据中主要落在一个：

\[m\]

维子空间：

\[f(u)\approx Uc,\]

其中：

\[U\in\mathbb R^{N\times m}.\]

这个：

\[U\]

通常来自 nonlinear snapshots：

\[[f(u^{(1)}),f(u^{(2)}),\ldots]\]

的 POD/SVD。

这相当于说：

\[\boxed{ \text{不仅解 }u\text{ 有低秩结构， 非线性算子 }f(u)\text{ 本身也有低秩结构。} }\]

问题变成：

\[c\]

怎么求？

如果用标准 projection：

\[c=U^Tf,\]

仍然需要完整：

\[f\in\mathbb R^N.\]

所以没有解决问题。

DEIM 的关键是：

\[\boxed{ \text{只要求 }f\text{ 的 }m\text{ 个精选分量。} }\]

5. DEIM 的核心公式非常漂亮

选取：

\[m\]

个索引：

\[p_1,\ldots,p_m.\]

构造选择矩阵：

\[P= [e_{p_1},\ldots,e_{p_m}] \in\mathbb R^{N\times m}.\]

DEIM 要求近似向量：

\[Uc\]

在这些位置与真正的 nonlinear vector 一致：

\[P^TUc = P^Tf(u).\]

于是：

\[c= (P^TU)^{-1}P^Tf(u).\]

所以：

\[\boxed{ f(u) \approx U(P^TU)^{-1}P^Tf(u) }\]

。

真正在线需要计算的只有：

\[\boxed{ P^Tf(u) }\]

即：

\[m\]

个 nonlinear entries。

而 reduced nonlinear term：

\[V^Tf(u)\]

变成：

\[\boxed{ V^TU(P^TU)^{-1}P^Tf(u). }\]

前面的：

\[V^TU(P^TU)^{-1}\]

全部可以 offline 预计算。

因此 online 阶段只剩：

\[\boxed{ \text{算 }m\text{ 个非线性分量。} }\]

Chaturantabut 与 Sorensen 2010 年的 DEIM 论文正是通过这个结构，让 POD nonlinear ROM 的复杂度显著摆脱 full system dimension。

假设：

普通 POD ROM：

\[q\in\mathbb R^{30}.\]

但每次仍计算：

\[10^6\]

维 nonlinear force。

DEIM 则选择：

\[50\]

个代表位置。

于是：

7. DEIM 点不是随机选的

如果随便选择：

\[m\]

个坐标，很可能：

\[P^TU\]

接近奇异。

那么：

\[(P^TU)^{-1}\]

会放大误差。

DEIM 原始算法通过 greedy 过程选 interpolation indices。

直觉上：

  1. 取第一个 nonlinear POD mode；
  2. 找它幅值最大的坐标；
  3. 用已有点解释下一个 mode；
  4. 找剩余 residual 最大的位置；
  5. 加入新点；
  6. 重复。

所以每一个 interpolation point 都在回答：

\[\boxed{ \text{当前已有采样位置最难解释的 nonlinear mode 在哪里？} }\]

这和 greedy reduced basis、active learning 在思想上有明显相似性，但 DEIM 的目标很具体：

\[\boxed{ \text{让 nonlinear field 能从少数坐标稳定重构。} }\]

pyMOR 当前仍直接提供 deim() 和 empirical-interpolation operator 接口，并通过 nonlinear snapshots 生成 collateral basis 与 interpolation DOFs。

8. DEIM 的误差由两个东西共同控制

其典型误差结构可以理解成：

\[\|f-\tilde f\| \lesssim \underbrace{ \|(I-UU^T)f\| }_{\text{nonlinear basis 截断误差}} \times \underbrace{ \|(P^TU)^{-1}\| }_{\text{插值点条件数}} .\]

第一项回答：

nonlinear POD basis 本身够不够表达 \(f\)？

第二项回答：

选出的 interpolation points 稳不稳定？

因此只增加：

\[m\]

并不自动保证效果好。

你同时需要：

\[\boxed{ \text{good collateral basis} + \text{good sampling points}. }\]

后续 POD-DEIM 的理论分析明确给出了 reduced state error 与 neglected POD singular values、DEIM nonlinear approximation error 之间的关系。

9. 但 DEIM 用在非线性结构动力学上有一个隐患：它主要近似“向量”，不一定保持“物理结构”

查看完整推导与细节

考虑有限元内力：

\[f_{\rm int}(u) = \nabla_u \Pi(u).\]

也就是说它来自势能：

\[\Pi(u).\]

这意味着完整模型拥有：

\[\boxed{ \text{力—能量一致性} }\]

。

如果你直接用：

\[f_{\rm int} \approx U(P^TU)^{-1}P^Tf_{\rm int},\]

得到的近似力未必仍然等于某个近似势能的梯度。

于是可能破坏：

  • 对称切线刚度；
  • 势能结构；
  • Hamilton/Lagrangian structure；
  • 数值稳定性。

这在结构动力学里比一般函数逼近严重得多。

Farhat、Chapman、Avery 对 ECSW 的分析中特别比较了这一点：ECSW 能保留与 Hamilton 原理相关的 Lagrangian structure，而 DEIM 及其一些变体在他们测试的 nonlinear structural dynamics 问题中可能产生数值不稳定。

这揭示了一个非常重要的原则：

\[\boxed{ \text{非线性项拟合得准， 不代表 resulting dynamics 就一定好。} }\]

10. ECSW：与其重构整条 nonlinear force，不如直接挑少数“代表单元”

有限元内力天然可以写成单元求和：

\[f_{\rm int}(u) = \sum_{e=1}^{N_e} L_e^T f_e(u_e).\]

Galerkin 投影：

\[V^Tf_{\rm int}(Vq) = \sum_{e=1}^{N_e} V_e^T f_e(V_eq).\]

这提供了一个非常自然的机会：

真的需要算所有单元吗？

ECSW 选择一个小单元集合：

\[\mathcal S \subset \{1,\ldots,N_e\}\]

以及正权重：

\[\xi_e>0.\]

然后近似：

\[\boxed{ V^Tf_{\rm int}(Vq) \approx \sum_{e\in\mathcal S} \xi_e V_e^Tf_e(V_eq) }\]

。

也就是说：

full mesh:
100000 elements

hyper-reduced mesh:
only 500 sampled elements
+ learned weights

在线阶段只有这：

\[500\]

个单元真正调用 constitutive model。

Farhat 等最初正是基于 mesh sampling、virtual work 和 energy structure 构造这一方法，并在 nonlinear finite-element structural dynamics 上获得最高约四个数量级的 CPU 加速案例。

11. 为什么 ECSW 的权重必须认真学？

如果只是随机取：

\[1\%\]

单元：

\[\sum_{e\in S}V_e^Tf_e\]

通常会严重低估整个结构的内力。

ECSW 使用：

\[\xi_e\]

让被采样的少数单元代表未采样单元的整体贡献。

可以粗略理解成：

1
2
3
4

element 17  × 12.3
element 83  ×  5.7
element 91  × 21.5
...

训练阶段使用 full-order snapshots，希望：

\[\sum_{e\in S} \xi_e V_e^Tf_e\]

尽可能匹配：

\[\sum_{e=1}^{N_e} V_e^Tf_e.\]

因此 Hyper-reduction 本质上又变成：

\[\boxed{ \text{寻找少数代表单元 + 合适 quadrature weights} }\]

。

从这个角度看，ECSW 很像一种：

\[\boxed{\text{data-driven reduced quadrature}}\]

。

12. 为什么 ECSW 会比“直接重构 nonlinear vector”更适合结构力学？

因为有限元本身就是按单元积分/装配建立的。

ECSW 不打破：

\[\text{element contribution}\]

这个基本结构。

如果原始 reduced internal force 是：

\[f_r(q) = \nabla_q \Pi_r(q),\]

那么使用正权重：

\[\xi_e\]

对单元能量加权后仍然可以构造：

\[\tilde\Pi_r(q) = \sum_{e\in S} \xi_e\Pi_e(V_eq).\]

于是：

\[\tilde f_r(q) = \nabla_q\tilde\Pi_r(q).\]

所以：

\[\boxed{ \text{hyper-reduced force 仍然来自一个 hyper-reduced energy} }\]

。

这就是所谓：

\[\boxed{\text{structure preserving}}\]

。

2015 年 ECSW 理论工作证明了其对 Lagrangian structure 和相应数值稳定性质的保持，并报告在完整汽车发动机 nonlinear transient structural simulation 中获得超过四个数量级的 CPU 加速，同时维持较好准确度。

13. DEIM 与 ECSW 最值得记住的区别

可以这样理解：

DEIM ECSW
近似对象 nonlinear vector \(f(u)\) projected FE element contributions
采样对象 vector entries / DOFs finite elements
核心结构 interpolation sampled quadrature
主要优势 通用、简单、适合一般 nonlinear operator 特别适合 FE mechanics
物理结构 不自动保持 可保持能量/Lagrangian结构
在线成本 与选中 DOF 数相关 与选中单元数相关

所以对一般 nonlinear PDE：

\[\boxed{\text{DEIM 是非常自然的入口}}\]

而对 nonlinear FEM / structural dynamics：

\[\boxed{\text{ECSW 往往具有更强的物理结构优势}}\]

。

14. Hyper-reduction 和普通“网格粗化”不是一回事

假设原模型：

\[100000\]

个单元。

直接做 coarse mesh：

\[1000\]

个单元。

这会改变：

  • geometry；
  • discretization；
  • local constitutive resolution；
  • mode shapes。

Hyper-reduction 则可能仍然使用：

\[\boxed{\text{原始 fine-mesh basis 和 fine-mesh physics}}\]

，只是在每次 online evaluation 中跳过绝大多数单元。

所以：

\[\boxed{ \text{coarsening：改变离散模型} }\]

而：

\[\boxed{ \text{hyper-reduction：稀疏评估原模型的投影贡献} }\]

。

这是很重要的区别。

15. 为什么它与代理模型有本质区别？

Kriging / Neural Operator 通常直接学习：

\[\mu \rightarrow y\]

或者：

\[\mu \rightarrow u.\]

Hyper-reduced ROM 仍然显式保留：

\[\boxed{ \text{reduced equations of motion} }\]

例如：

\[M_r\ddot q+\tilde f_r(q)=f_r.\]

所以：

  • conservation law 仍可能存在；
  • boundary condition 仍进入方程；
  • time integration 仍由物理 solver 执行；
  • 新外力可以直接作用于模型。

因此它属于：

\[\boxed{\text{physics-based surrogate}}\]

，而不是纯粹 response fitting。

这使它在动力学、控制和反问题中非常有价值。

16. 但 Hyper-reduction 仍然有一个非常明显的“训练域”问题

假设 ECSW 只在：

\[\text{small deformation}\]

数据上训练。

然后在线进入：

\[\text{large bending + contact}.\]

原来选择的：

\[\mathcal S\]

可能已经无法代表新的 nonlinear force field。

DEIM 同样如此：

\[U_f\]

来自 training snapshots。

如果新的 nonlinear state 超出了：

\[\operatorname{span}(U_f),\]

误差就会明显增大。

所以：

\[\boxed{ \text{Hyper-reduction 并没有消灭 extrapolation problem。} }\]

它只是把问题从：

\[\text{response surrogate}\]

转移到了：

\[\text{operator surrogate}.\]

Localized DEIM 之所以出现，就是因为一个 global nonlinear subspace 可能无法覆盖具有多个不同局部行为区域的系统，因此改用多个 local subspaces。

17. 这和你的软体动力学尤其有一个值得注意的冲突：接触高度局部且会移动

查看完整推导与细节

假设软体落地。

时间：

\[t_1\]

接触区域是底部左边；

时间：

\[t_2\]

滚动后变成右边；

时间：

\[t_3\]

又产生新的 self-contact。

如果 Hyper-reduction 固定只采：

\[500\]

个单元，

而真正重要的 contact zone 没在：

\[\mathcal S\]

里，就可能完全漏掉关键局部事件。

这说明 nonlinear structural ROM 中存在一个很深的张力：

\[\boxed{ \text{Hyper-reduction 喜欢空间稀疏} }\]

但：

\[\boxed{ \text{contact 喜欢动态移动的局部激活区域。} }\]

因此接触问题更可能需要：

  • adaptive sampling；
  • local ROM；
  • state-dependent sampling；
  • contact region always-on；
  • ROM + full-order local correction。

这与固定 ECSW mesh 是不同的难度层级。

18. 一个特别值得迁移到物理引擎的思想：不要降整个系统，降“最贵的算子调用次数”

Hyper-reduction 给物理引擎开发最大的启发，甚至不一定要真正做 ROM。

假设一个 solver 每帧最贵的是：

\[\boxed{\text{100 万个 tet constitutive evaluations}}\]

。

传统优化会问：

怎样让每个 tet 算得更快？

Hyper-reduction 的思考方式会问：

真的每个 tet 每一帧都值得重新算吗？

如果大量区域：

  • 应变变化很小；
  • 远离接触；
  • 对当前低频形变贡献有限；

也许真正应该优化的是：

\[\boxed{\text{evaluation sparsity}}\]

而不只是：

\[\text{evaluation FLOPS}.\]

这与：

  • sleeping；
  • island activation；
  • adaptive substepping；
  • sparse collision detection；

属于同一种更高级的工程思想：

\[\boxed{ \text{最便宜的一次计算，是根本没有执行的那次计算。} }\]

19. 它对代理模型还有一个很强的启发：可以代理“算子”，不一定代理最终输出

通常代理模型研究：

\[x\rightarrow y.\]

但 DEIM 实际做的是：

\[\boxed{ \text{学习 nonlinear operator }f(u)\text{ 的低维表示} }\]

。

ECSW 更进一步：

\[\boxed{ \text{学习哪些局部 operator contributions 值得计算} }\]

。

所以代理建模其实可以分成三层：

\[\text{output surrogate}\]\[y\approx\hat y(x)\]
\[\text{state surrogate}\]\[u\approx Vq\]
\[\boxed{\text{operator surrogate}}\]\[F(u)\approx\tilde F(u).\]

第三层通常保留最多物理结构。

这对未来做：

  • learned constitutive operators；
  • neural preconditioner；
  • learned coarse solver；
  • operator compression；

都非常有迁移价值。

20. 一个特别适合亲手做的最小实验

查看完整推导与细节

可以做一个 nonlinear spring chain：

\[m\ddot x_i + k(x_i-x_{i-1}) + \beta(x_i-x_{i-1})^3 +\cdots =0.\]

取：

\[N=1000.\]

首先收集 full-order snapshots：

\[X=[x(t_1),\ldots,x(t_M)].\]

做 POD：

\[X\approx VQ, \qquad r=10.\]

然后比较三种模型。

A. 纯 POD

每一步仍计算全部：

\[N\]

个 cubic spring forces。

B. POD + DEIM

另外收集：

\[F= [f_{\rm nl}(x(t_1)),\ldots].\]

对它做 POD：

\[F\approx U_fC.\]

选：

\[m=20\]

个 DEIM points。

C. Full model

作为基准。

记录：

\[\boxed{\text{state error}}\]

和：

\[\boxed{\text{wall-clock time}}\]

。

最重要的观察很可能是：

\[\boxed{ \text{POD 已经把 1000 DOF 降到 10， 但真正的明显加速要等 DEIM 加进去才出现。} }\]

这个实验能够非常直接地理解为什么 Hyper-reduction 是 nonlinear ROM 不可缺少的第二步。

今天值得留下的一句话

Hyper-reduction 最重要的公式并不是：

\[f \approx U(P^TU)^{-1}P^Tf.\]

真正值得记住的是：

\[\boxed{ \text{减少未知量，并不自动减少构造方程的成本。} }\]

所以 nonlinear model reduction 真正完整的知识结构是：

\[\text{Full nonlinear FEM}\]\[\downarrow\]\[\boxed{ u\approx Vq }\]

State reduction

\[\downarrow\]\[\boxed{ F(Vq) \text{只在少数 DOF / elements 上计算} }\]

Hyper-reduction

\[\downarrow\]\[\boxed{\text{Online cost 真正与 }N\text{ 脱钩}}\]

。

而 DEIM 与 ECSW 的区别又揭示了一个更深的原则：

\[\boxed{ \text{“近似得准”只是第一层要求； 对于物理求解器，还要问近似以后保留了什么结构。} }\]

对非线性有限元、软体动力学乃至代理模型而言，这都是非常重要的分界线：

\[\boxed{ \text{你究竟是在压缩状态， 压缩输出， 还是压缩物理算子的计算本身？} }\]

Hyper-reduction 正好卡在第三层。
