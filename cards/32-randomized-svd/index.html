Randomized SVD：为什么“随机乘几个向量”就能抓住一个百万维矩阵最重要的子空间

Sep 14, 2026
阅读时长: 7 分钟

Randomized SVD：为什么“随机乘几个向量”就能抓住一个百万维矩阵最重要的子空间

主题：Randomized SVD / Randomized Numerical Linear Algebra（随机化奇异值分解 / 随机数值线性代数）
领域：代理模型 × 有限元 × 科学机器学习 × AI 全栈工程
推荐阅读时间：约 8–10 分钟
这次选 Randomized SVD，因为它体现了一种很值得迁移的计算思想：

\[\boxed{ \ ext{如果你只需要一个巨大系统最重要的低维结构， 就没有必要精确理解整个巨大系统。} }\]

标准 SVD：

\[A=U\Sigma V^T\]

是数值线性代数最重要的工具之一，但当：

\[A\in\mathbb R^{10^6\ imes10^4}\]

时，精确 SVD 本身就可能成为瓶颈。

Randomized SVD 的做法非常反直觉：

随机生成少量方向，让大矩阵作用在这些方向上，再根据这些响应反推出矩阵的主导子空间。

典型结构只有：

\[\boxed{ Y=A\Omega }\]

其中：

\[\Omega\in\mathbb R^{n\ imes(k+p)}\]

是一组随机向量。

然后对：

\[Y\]

正交化：

\[Y=QR,\]

就能得到：

\[Q\]

作为 \(A\) 主导列空间的近似。

Halko、Martinsson、Tropp 2011 年的 SIAM Review 论文把这一框架系统化；Martinsson 与 Tropp 2020 年的 Acta Numerica 综述进一步将其扩展到低秩近似、回归、核矩阵、流式算法和线性系统等多个方向。

真正值得学的不是“随机算法会更快”，而是：

\[\boxed{ \ ext{随机探测为什么足以发现确定性的低维结构？} }\]

1. 先明确问题：很多时候我们根本不需要完整 SVD

假设有限元跑出：

\[m=10000\]

个快照，

每个快照有：

\[N=10^6\]

个自由度。

组成 snapshot matrix：

\[X= [u(t_1),u(t_2),\ldots,u(t_m)] \in\mathbb R^{10^6\ imes10^4}.\]

POD 通常通过 SVD：

\[X=U\Sigma V^T\]

取前：

\[r=50\]

个模态：

\[U_r.\]

真正需要的是：

\[\boxed{\ ext{前 50 个主方向}}\]

而不是后面：

\[9950\]

个奇异向量。

这就是 truncated SVD：

\[X \approx U_r\Sigma_rV_r^T.\]

理论上最优的 rank-\(r\) 近似由 Eckart–Young 定理给出：

\[\|A-A_r\|_2=\sigma_{r+1}.\]

问题在于：

\[\boxed{ \ ext{为了得到 50 个方向， 传统算法有时仍需要对整个巨大矩阵做大量工作。} }\]

Randomized SVD 就专门针对这种：

\[r\ll\min(m,n)\]

的场景。Scikit-learn 当前的官方 randomized_svd 也明确将其定位为：当矩阵很大、而只需要少量 singular components 时，随机化 truncated SVD 往往非常高效。

2. 最核心的思想：不要直接分解 \(A\)，先找到它的 range

假设：

\[A\]

实际上近似 rank-\(k\)：

\[A \approx U_k\Sigma_kV_k^T.\]

那么任意向量：

\[\omega\]

经过：

\[y=A\omega\]

后：

\[y \approx U_k\Sigma_kV_k^T\omega.\]

无论随机输入：

\[\omega\]

是什么，

输出：

\[y\]

都会落到或接近：

\[\boxed{\operatorname{span}(U_k)}\]

。

所以如果连续随机生成：

\[\omega_1,\omega_2,\ldots,\omega_l\]

并计算：

\[y_i=A\omega_i,\]

这些：

\[y_i\]

自然会“照亮” \(A\) 的主导列空间。

写成矩阵：

\[\boxed{ Y=A\Omega }\]

其中：

\[\Omega= [\omega_1,\ldots,\omega_l].\]

然后：

\[Q=\operatorname{orth}(Y).\]

于是：

\[\boxed{ A \approx QQ^TA. }\]

这一步叫：

\[\boxed{\ ext{randomized range finder}}\]

，也是 Randomized SVD 的核心。

Halko 等把大量随机化矩阵分解统一成“两阶段”框架：先用随机采样找到近似 range，再在这个低维空间里做传统确定性线性代数。

3. 为什么随机方向不会刚好错过重要子空间？

这是最关键的问题。

假设真实主导右奇异空间：

\[V_k = [v_1,\ldots,v_k].\]

随机高斯向量：

\[\omega\sim N(0,I)\]

在任何固定方向：

\[v_i\]

上的投影：

\[v_i^T\omega\]

几乎不可能严格为零。

因此：

\[A\omega = \sum_i \sigma_i u_i(v_i^T\omega).\]

主导奇异值：

\[\sigma_1,\sigma_2,\ldots,\sigma_k\]

会放大相应方向。

如果：

\[\sigma_1\gg\sigma_{100},\]

那么：

\[A\omega\]

天然被前几个：

\[u_i\]

支配。

所以：

\[\boxed{ \ ext{矩阵本身在替你过滤随机噪声， 把随机输入变成主导结构的混合。} }\]

多取几个随机向量，就能把整个 dominant subspace 展开出来。

这其实和 power iteration 的思想非常接近。

5. 这其实是“先压缩，再精确计算”

Randomized SVD 并不是完全随机地给答案。

随机性只用于：

\[\boxed{\ ext{发现一个好的低维子空间}}\]

。

找到：

\[Q\]

之后，

后面的：

\[B=Q^TA\]

和：

\[B=\ ilde U\Sigma V^T\]

仍然是标准确定性 SVD。

所以它的结构是：

\[\ ext{Huge deterministic problem}\]\[\downarrow\]\[\boxed{\ ext{Random sketch}}\]\[\downarrow\]\[\ ext{Small deterministic problem}.\]

这是 Randomized Numerical Linear Algebra 一个非常典型的架构。

6. 为什么 oversampling 很重要？

假设真正要：

\[k=20\]

个 modes。

理论上可以只取：

\[20\]

个随机向量。

但如果刚好某些随机组合对第 20 个方向响应很弱，

子空间质量就可能下降。

所以常取：

\[l=k+p\]

例如：

\[k=20,\quad p=10.\]

相当于给算法一些：

\[\boxed{\ ext{冗余观察方向}}\]

。

然后最终仍只保留：

\[20\]

个 singular vectors。

Scikit-learn 当前默认：

\[n_{\rm oversamples}=10,\]

并明确指出：对于高噪声、有效秩较大或 singular spectrum 衰减缓慢的问题，可以增加 oversampling 来改善近似质量。

7. 真正麻烦的是奇异值衰减慢

查看完整推导与细节

假设：

\[\sigma_1=1000, \quad \sigma_2=500, \quad \sigma_{50}=1, \quad \sigma_{51}=0.001.\]

主导子空间非常清楚。

Randomized range finder 很容易抓住。

但如果：

\[\sigma_i\sim\frac1i,\]

那么：

\[\sigma_{50}\]

和：

\[\sigma_{100}\]

差别不大。

这时随机采样得到的：

\[Y=A\Omega\]

中，尾部方向仍占有明显能量。

于是：

\[\boxed{ \ ext{dominant subspace 不够突出。} }\]

Randomized SVD 最常用的解决方法就是：

\[\boxed{\ ext{Power Iteration}.}\]

8. Power Iteration 为什么有效？

查看完整推导与细节

改成计算：

\[Y=(AA^T)^qA\Omega.\]

利用 SVD：

\[A=U\Sigma V^T,\]

得到：

\[(AA^T)^qA = U\Sigma^{2q+1}V^T.\]

所以奇异值变成：

\[\boxed{ \sigma_i \rightarrow \sigma_i^{2q+1}. }\]

假设：

\[\frac{\sigma_k}{\sigma_{k+1}} = 2.\]

当：

\[q=0\]

差距：

\[2.\]

当：

\[q=2\]

差距变成：

\[2^5=32.\]

主导子空间一下变得非常明显。

所以 power iteration 的本质是：

\[\boxed{ \ ext{人为把 singular spectrum 拉开。} }\]

Scikit-learn 也把 n_iter 暴露为 Randomized SVD 的核心参数，特别用于噪声较大或谱衰减较慢的问题。

9. 但 Power Iteration 不是免费的

查看完整推导与细节

每次：

\[AA^T\]

都意味着再次访问大矩阵。

如果：

\[A\]

非常巨大，

真正昂贵的可能不是 FLOPs，

而是：

\[\boxed{\ ext{内存带宽 / 数据读取}}\]

。

所以实际 Randomized Linear Algebra 很关心：

\[\boxed{\ ext{passes over the matrix}}\]

。

例如：

  • 1-pass algorithm；
  • 2-pass algorithm；
  • streaming algorithm；

本身就是重要研究方向。

Martinsson 与 Tropp 的综述专门讨论 single-view / streaming randomized algorithms，因为很多大数据环境中：

\[\boxed{ \ ext{把矩阵从磁盘或分布式存储读第二遍， 可能比额外算几亿次乘法更贵。} }\]

这和现代 AI 系统非常相似：

\[\boxed{ \ ext{数据移动经常比计算本身更贵。} }\]

10. Randomized SVD 和普通随机采样行/列并不是一回事

容易产生误解：

随机方法是不是从 \(A\) 里随便抽几行、几列？

经典 Gaussian range finder 并不是这样。

它计算：

\[A\Omega.\]

每一个随机 probe：

\[\omega_j\]

都是所有列的随机线性组合。

所以每个：

\[A\omega_j\]

都包含：

\[\boxed{\ ext{整个矩阵的全局信息}}\]

。

相比直接随机挑列，这通常更稳定。

当然 Randomized Numerical Linear Algebra 也包括：

  • row/column sampling；
  • CUR；
  • Nyström；
  • leverage-score sampling；

但这是另一条方法线。Martinsson–Tropp 的综述正是把这些技术放进同一个 randomized matrix computation 框架中。

11. 它与 Johnson–Lindenstrauss 思想有同一个根

Random projection 中有一个著名事实：

高维点：

\[x_i\in\mathbb R^N\]

投影到：

\[r\ll N\]

维随机空间后，

只要：

\[r\]

足够大，

点之间的距离：

\[\|x_i-x_j\|\]

可以近似保持。

背后的核心思想是：

\[\boxed{ \ ext{随机低维投影通常不会系统性破坏所有重要方向。} }\]

Randomized SVD 用的是类似直觉：

\[\boxed{ \ ext{随机 probe 很难同时避开一个固定的重要低维子空间。} }\]

所以随机性在这里不是：

\[\boxed{\ ext{用随机误差换速度}}\]

这么简单。

它更像：

\[\boxed{ \ ext{利用高维空间的几何集中性质， 廉价获得对全局结构的观测。} }\]

12. 为什么它和 POD 天然结合？

POD snapshot matrix：

\[X= [u_1,\ldots,u_m].\]

标准 POD：

\[X=U\Sigma V^T.\]

取：

\[U_r.\]

所以 POD 本质就是 truncated SVD。

如果：

\[N=10^7, \quad m=10^5,\]

POD 的 offline SVD 本身就可能极其昂贵。

这时可以直接：

\[\boxed{ X \overset{\ ext{randomized SVD}} {\longrightarrow} U_r. }\]

已有 randomized POD 工作正是针对 PDE 离散后产生的大型 snapshot systems，通过随机投影/随机采样减少生成 dominant modes 所需的成本。

最近的 ROM 工作也继续使用 randomized SVD、randomized DMD 等方式降低大规模降阶建模中 basis construction 的成本。

13. 这和上一张 Hyper-reduction 卡片正好位于不同阶段

Hyper-reduction 主要解决：

\[\boxed{\ ext{ROM online evaluation 太贵}}\]

例如：

\[f(Vq)\]

仍然需要全部有限元单元。

Randomized SVD 解决：

\[\boxed{\ ext{ROM offline basis construction 太贵}}\]

。

完整流程可以写成：

\[\ ext{Full simulations}\]\[\downarrow\]\[\ ext{huge snapshot matrix}\]\[\downarrow\]\[\boxed{\ ext{Randomized SVD}}\]\[\downarrow\]\[\ ext{Reduced basis}\]\[\downarrow\]\[\boxed{\ ext{DEIM/ECSW Hyper-reduction}}\]\[\downarrow\]\[\ ext{fast online ROM}.\]

两者解决的是 completely different bottleneck。

14. 一个有限元中的具体量级

查看完整推导与细节

假设软体模型：

\[N=3\ imes10^6\]

DOF。

记录：

\[50000\]

帧。

Snapshot matrix：

\[X\in \mathbb R^{3\ imes10^6\ imes50000}.\]

如果用 float64，光存储：

\[3\ imes10^6\ imes50000\ imes8\]

约等于：

\[1.2\ ext{ TB}.\]

这时问题已经不再是：

LAPACK SVD 快不快？

而是：

\[\boxed{ \ ext{矩阵甚至放不进普通内存。} }\]

Randomized/streaming algorithm 可以：

  1. 分块读取 snapshots；
  2. 计算： \[X\Omega;\]
  3. 累积一个小得多的 sketch；
  4. 不再长期保存完整矩阵。

所以 Randomized Linear Algebra 在这里不只是：

\[\boxed{\ ext{算法提速}}\]

而可能改变：

\[\boxed{\ ext{这个计算是否可做。}}\]

15. 这对可靠性分析也有非常直接的价值

查看完整推导与细节

假设你有：

\[10^6\]

个蒙特卡洛样本，

每个样本输出：

\[5000\]

个时序/空间响应量。

于是响应矩阵：

\[Y\in\mathbb R^{10^6\ imes5000}.\]

你可能想分析：

  • dominant response modes；
  • sensitivity directions；
  • failure-response correlations；
  • covariance structure。

如果直接形成：

\[Y^TY\]

或完整 PCA，

成本可能很高。

Randomized SVD 可以直接提取：

\[\boxed{\ ext{主导随机响应子空间}}\]

而无需完整 covariance decomposition。

这与之前 Active Subspaces 的区别也很清楚：

Active Subspaces

分析：

\[\boxed{\ ext{输入空间中哪些方向最影响输出}}\]

通常依赖梯度信息。

Randomized SVD/PCA

分析：

\[\boxed{\ ext{观测数据本身主要落在哪些线性方向}}\]

。

二者都降维，但问题完全不同。

16. 它还可以加速 Kriging / Gaussian Process 的另一部分瓶颈

查看完整推导与细节

Gaussian Process 通常需要处理：

\[K\in\mathbb R^{N\ imes N}.\]

标准训练和推理涉及：

\[K^{-1}\]

或 Cholesky：

\[K=LL^T.\]

经典复杂度：

\[O(N^3).\]

如果 kernel matrix 具有：

\[\boxed{\ ext{低有效秩}}\]

可以近似：

\[K \approx QQ^TK\]

或使用：

\[\boxed{\ ext{Nyström approximation}}\]

构造低秩表示。

Randomized numerical linear algebra 的成熟体系也专门包含：

  • Nyström；
  • randomized kernel approximation；
  • low-rank positive-semidefinite approximation。

Martinsson–Tropp 的综述明确将 kernel matrices from machine learning/scientific computing 列为典型应用。

所以 Randomized Linear Algebra 实际位于：

\[\boxed{ \ ext{数值线性代数} \cap \ ext{代理模型} \cap \ ext{机器学习} }\]

的交界处。

17. 对 AI 全栈工程，它为什么也值得学？

查看完整推导与细节

大型 AI 系统里到处存在：

\[\boxed{\ ext{低秩结构}}\]

：

  • embedding covariance；
  • activation matrix；
  • gradient matrix；
  • Hessian approximation；
  • LoRA weight updates；
  • attention matrices；
  • dataset features。

假设：

\[X\in\mathbb R^{10^7\ imes4096}.\]

想做 PCA。

直接：

\[X^TX\]

或 full SVD 可能非常贵。

Randomized projection 可以首先构造：

\[Y=X\Omega\]

把：

\[4096\]

维压到：

\[100\]

左右。

然后大部分后续分析都在小空间完成。

这也是 randomized SVD 已经成为成熟数据科学软件中的标准工具的原因之一，而不是停留在研究论文里。

18. 它和 LoRA 有一个非常漂亮的联系

之前 LoRA 的核心假设：

\[\Delta W\]

具有低秩结构。

Randomized SVD 则回答另一个问题：

\[\boxed{ \ ext{如果一个巨大矩阵确实近似低秩， 怎样便宜地找到那个低秩子空间？} }\]

因此在分析 LoRA training dynamics 时，如果想研究：

\[\Delta W\]

到底有多少有效奇异方向，

无需一定做完整：

\[4096\ imes4096\]

SVD。

可以直接 randomized SVD。

更一般地：

\[\boxed{ \ ext{Low-rank modeling} }\]

和：

\[\boxed{ \ ext{Randomized low-rank discovery} }\]

天然是一对。

19. 但它不是万能的：真正低秩才是前提

查看完整推导与细节

考虑：

\[\sigma_1,\sigma_2,\ldots\]

几乎不衰减。

比如：

\[\sigma_i\approx1\]

直到数千维。

那么：

\[\boxed{ \ ext{矩阵本身就没有明显低维结构。} }\]

这时 randomized SVD 无法凭空制造：

\[k=20\]

的高质量近似。

它最多更快地告诉你：

\[\boxed{\ ext{rank-20 近似本身很差。}}\]

这是一条非常重要的原则：

随机化可以降低发现结构的成本，但不能创造不存在的结构。

20. 第二个局限：低能量方向可能恰恰是最重要的方向

查看完整推导与细节

这对可靠性尤其重要。

POD/SVD 优先保留：

\[\boxed{\ ext{最大方差 / 最大能量方向}}\]

。

假设 99.99% 的正常样本沿：

\[u_1\]

波动。

但真正决定失效的微小模式：

\[u_{37}\]

只占：

\[0.01\%\]

能量。

如果直接截断：

\[r=10,\]

这个 failure-sensitive mode 会被完全删除。

Randomized SVD 仍然会很好地逼近标准 SVD，

但：

\[\boxed{ \ ext{标准 SVD 的任务目标本身就错了。} }\]

所以：

\[\boxed{ \ ext{Randomized SVD 解决的是计算问题， 不解决“哪个子空间对任务最重要”的建模问题。} }\]

这是和 DWR、Active Subspaces、goal-oriented reduction 的根本区别。

21. 一个很值得记住的误区：随机算法并不意味着结果“不可靠”

Randomized SVD 经常给人一种感觉：

每次结果随机，会不会不靠谱？

实际上现代 randomized numerical linear algebra 通常有严格的：

\[\boxed{\ ext{probabilistic error bounds}}\]

。

比如对 range finder，可以控制：

\[\|(I-QQ^T)A\|\]

与：

\[\sigma_{k+1}\]

之间的关系，并且失败概率可以通过 oversampling 快速降低。

所以这里的随机性更像 Monte Carlo：

\[\boxed{ \ ext{允许极小概率失败， 换取显著计算优势。} }\]

但 Randomized SVD 和普通 Monte Carlo 又有所不同：

最终误差通常与：

\[\boxed{\ ext{矩阵本身的 singular spectrum}}\]

强相关。

矩阵越接近低秩，它越容易成功。Halko–Martinsson–Tropp 的经典工作正是系统建立了这类概率误差分析。

23. 对你后续有限元/软体方向，一个实际可迁移场景

假设未来做大规模软体 simulation dataset：

\[u(\ heta,t)\]

参数包括：

  • Young’s modulus；
  • Poisson ratio；
  • loading；
  • contact configuration；
  • geometry。

很快就可能积累：

\[10^4\sim10^5\]

个大型 deformation fields。

你想研究：

\[\boxed{ \ ext{这些百万维形变场真正占据多少维 manifold？} }\]

第一步通常就是 PCA/POD/SVD。

如果 full SVD 太贵，

Randomized SVD 可以直接成为：

\[\boxed{ \ ext{数据诊断工具} }\]

，而不必立即把它理解成最终 ROM 方法。

比如你可能发现：

\[r=30\]

已经解释：

\[99.9\%\]

snapshot energy。

这就告诉你：

\[\boxed{ \ ext{虽然每帧有百万 DOF， 真实运动数据可能只访问了几十维子空间。} }\]

这个结论会直接影响后续是否值得研究：

  • ROM；
  • reduced coordinates；
  • neural latent state；
  • LoRA-style low-rank adaptation；
  • learned physics manifold。

今天值得留下的一句话

Randomized SVD 最值得记住的不是：

\[Y=A\Omega.\]

真正重要的是：

\[\boxed{ \ ext{如果一个巨大系统只有少数真正重要的方向， 你无需完整检查系统的每一个方向， 只要用少量随机探针让这些重要方向自己显现出来。} }\]

它在知识体系中的位置可以这样理解：

\[\ ext{Large matrix / dataset}\]\[\downarrow\]\[\boxed{\ ext{Random sketch}}\]\[\downarrow\]\[\boxed{\ ext{Approximate dominant subspace}}\]\[\downarrow\]\[\ ext{small deterministic linear algebra}.\]

与最近几张卡片相比，它代表的是一个新的优化轴：

\[\boxed{\ ext{Hyper-reduction：少计算算子}}\]\[\boxed{\ ext{Schur complement：少参与全局协调}}\]\[\boxed{\ ext{Randomized SVD：少观察无关方向}}\]

。

更普遍的工程启发则是：

\[\boxed{ \ ext{面对百万维问题时， 第一反应不一定应该是“怎样更快地把所有东西算完”， 而应该先问：“我真正需要知道的结构有多少维？”} }\]

如果答案是：

\[50\]

那么精确分析：

\[10^6\]

个方向，本身可能就是错误的计算目标。
