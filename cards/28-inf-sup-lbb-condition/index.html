Inf-Sup / LBB 条件：为什么“位移和压力都插值正确”仍可能得到一个完全错误的有限元

Sep 10, 2026
阅读时长: 6 分钟

Inf-Sup / LBB 条件：为什么“位移和压力都插值正确”仍可能得到一个完全错误的有限元

主题：Inf-Sup Condition / Ladyzhenskaya–Babuška–Brezzi 条件
领域：有限元 × 流体 × 软体动力学 × 数值方法
推荐阅读时间：约 8–10 分钟
今天选 Inf-Sup 条件，因为它解决的是有限元里一个很反直觉的问题：

\[\boxed{ \ ext{两个变量各自都有合理的有限元空间，并不意味着它们组合起来就是稳定的。} }\]

这在近不可压材料、Stokes 流、压力—位移混合有限元、Lagrange multiplier 约束里极其重要。

经典混合有限元理论由 Babuška、Brezzi、Fortin 等建立。Brezzi 1974 年关于 saddle-point problems 的工作给出了这类问题存在性、唯一性和离散稳定性的核心条件；后来的 Boffi–Brezzi–Fortin 专著已经把它发展成完整的 mixed FEM 理论框架。

真正值得记住的不是那个看起来很抽象的：

\[\inf\sup\]

公式，而是：

\[\boxed{ \ ext{约束变量必须拥有足够强、但又不过强的“控制能力”。} }\]

1. 为什么普通位移有限元到了近不可压材料会出问题？

考虑线弹性：

\[\sigma = 2\mu\varepsilon(u) + \lambda\operatorname{tr}(\varepsilon(u))I.\]

其中：

\[\lambda = \frac{E\ u} {(1+\ u)(1-2\ u)}.\]

当：

\[\ u\rightarrow0.5,\]

有：

\[\lambda\rightarrow\infty.\]

物理上意味着材料趋向：

\[\boxed{ \ abla\cdot u=0 }\]

即几乎不能改变体积。

如果继续用纯 displacement FEM，相当于能量里出现一个极强的体积惩罚：

\[\Pi_{\rm vol} \sim \frac{\lambda}{2} (\ abla\cdot u)^2.\]

当 \(\lambda\) 极大时，离散位移空间必须非常精确地满足：

\[\ abla\cdot u\approx0.\]

但低阶位移单元通常没有足够自由度做到。

结果就是：

\[\boxed{\ ext{volumetric locking}}\]

——结构数值上变得异常僵硬。

近不可压弹性文献通常因此转向 displacement–pressure mixed formulation，以避免锁死。

2. 混合形式：把“体积约束”变成一个独立变量

引入压力：

\[p=-\lambda\ abla\cdot u.\]

原问题可以写成：

\[-2\mu\ abla\cdot\varepsilon(u) -\ abla p=f,\]

以及：

\[\ abla\cdot u+\frac{1}{\lambda}p=0.\]

当：

\[\lambda\rightarrow\infty,\]

第二式趋近：

\[\boxed{ \ abla\cdot u=0. }\]

这时候：

\[u\]

和：

\[p\]

成为两个独立未知量。

有限元离散后：

\[u_h\in V_h, \qquad p_h\in Q_h.\]

得到经典 saddle-point system：

\[\boxed{ \begin{bmatrix} A&B^T\\ B&-\frac1\lambda M_p \end{bmatrix} \begin{bmatrix} u\\p \end{bmatrix} = \begin{bmatrix} f\\0 \end{bmatrix}. }\]

在完全不可压极限：

\[\lambda=\infty,\]

就变成：

\[\begin{bmatrix} A&B^T\\ B&0 \end{bmatrix}.\]

这里开始出现真正的问题。

3. 为什么不能随便选 \(V_h\) 和 \(Q_h\)？

直觉上你可能会想：

位移用线性单元 \(P_1\)，压力也用线性单元 \(P_1\)，多自然。

也就是：

\[P_1-P_1.\]

但这种 equal-order pairing 对标准 Stokes/不可压混合问题通常不满足 LBB 条件，未经稳定化会产生不稳定压力模式。近不可压固体文献也明确指出，equal-order linear pairs 需要额外 stabilization；Taylor–Hood 等则属于经典稳定组合。

所以：

\[\boxed{ \ ext{每个空间单独“看起来合理”，并不能保证组合合理。} }\]

这是理解 mixed FEM 最关键的一步。

4. Inf-Sup 条件到底在测什么？

典型条件写成：

\[\boxed{ \inf_{q_h\in Q_h} \sup_{v_h\in V_h} \frac{b(v_h,q_h)} {\|v_h\|_V\|q_h\|_Q} \ge \beta>0. }\]

并要求：

\[\beta\]

在：

\[h\rightarrow0\]

时不趋近零。

对于不可压问题：

\[b(v,q) = \int_\Omega q\,\ abla\cdot v\,d\Omega.\]

所以公式实际上在问：

对任意一个压力模式 \(q_h\)，能不能找到某个位移模式 \(v_h\)，使其散度对这个压力模式产生足够强的响应？

即：

\[\boxed{ \ ext{每一个离散压力自由度，都必须能被某种位移体积变化“看见”。} }\]

如果存在一个压力模式：

\[q_h\ eq0\]

却对所有：

\[v_h\]

都近似有：

\[b(v_h,q_h)\approx0,\]

那么这个压力模式就是：

\[\boxed{\ ext{几乎不受控制的 spurious mode}}\]

。

此时：

\[\beta_h\rightarrow0.\]

系统便失去稳定性。

压力在单元间剧烈变化。

但某些位移离散下：

\[\boxed{\ ext{spurious pressure mode}}\]

。

如果离散空间搭配不满足 inf-sup，

6. 所以 Inf-Sup 条件本质上是一个“离散可观测性”条件

可以把：

\[B:V_h\rightarrow Q_h^*\]

理解成：

\[\boxed{ \ ext{位移/速度变化} \rightarrow \ ext{约束响应} }\]

。

那么 inf-sup 要求：

\[B\]

不能在某些压力方向上失去控制。

用线性代数语言，\(\beta_h\) 与合适缩放后的：

\[B\]

最小奇异值密切相关。

如果：

\[\sigma_{\min}\rightarrow0,\]

意味着存在某些：

\[q_h\]

几乎落在：

\[B^T\]

的零空间中。

于是整个问题可以理解成：

\[\boxed{ \ ext{constraint Jacobian 是否拥有足够好的数值秩？} }\]

这和你做物理引擎时检查约束：

\[J M^{-1}J^T\]

是否奇异，其实是同一种思维。

7. 为什么 Taylor–Hood 很经典？

Taylor–Hood 通常采用：

\[\boxed{ P_2\ ext{ velocity/displacement} - P_1\ ext{ pressure} }\]

。

即：

\[u_h\]

用二次插值，

\[p_h\]

用一次插值。

FEniCS 当前教程仍直接把 Taylor–Hood 作为 mixed Stokes 问题的标准示例；其 mixed-element API 也是按这种不同变量使用不同空间的方式构建。

为什么位移阶次通常更高？

因为 incompressibility 约束作用的是：

\[\ abla\cdot u.\]

如果：

\[u\in P_2,\]

那么：

\[\ abla\cdot u\]

大致落在：

\[P_1\]

级空间。

所以：

\[P_2-P_1\]

在函数空间结构上更加匹配。

可以粗略理解成：

\[\boxed{ \ ext{压力空间不应该比位移散度能够表达的空间更丰富。} }\]

这是很重要的直觉。

8. 为什么“压力自由度越多”反而可能越糟？

查看完整推导与细节

这也是 mixed FEM 最反直觉的地方之一。

普通拟合问题里常觉得：

\[\boxed{\ ext{自由度越多 → 表达能力越强}}\]

。

但约束问题中：

如果压力空间：

\[Q_h\]

过于丰富，而位移空间：

\[V_h\]

不足以回应这些压力模式，

就产生：

\[\boxed{\ ext{constraint over-resolution}}\]

。

也就是说：

\[\ ext{pressure asks questions}\]

比：

\[\ ext{displacement can answer}\]

还多。

于是额外 pressure DOFs 不是增加精度，而是在制造：

\[\boxed{\ ext{不可观测约束模态。}}\]

这也是为什么 mixed discretization 的设计不是：

\[\boxed{\ ext{每个变量各自选最强单元}}\]

而是：

\[\boxed{\ ext{整个变量对必须兼容。}}\]

9. 这和 locking 又是什么关系？

查看完整推导与细节

这里有两个看似相反的问题。

位移空间过于受约束

纯 displacement 近不可压 formulation：

\[\ abla\cdot u\approx0\]

被 penalty-like volumetric stiffness 极强地施加。

结果：

\[\boxed{\ ext{locking}}\]

。

压力空间过于自由

mixed formulation 中，如果：

\[V_h,Q_h\]

不匹配：

\[\boxed{\ ext{spurious pressure}}\]

。

所以 mixed FEM 真正要在两者之间找平衡：

\[\boxed{ \ ext{约束不能太硬， 也不能太自由。} }\]

Inf-sup 条件就是这个平衡的数学表达。

10. 为什么这对 Neo-Hookean 软体尤其重要？

很多软体使用：

\[\Psi(F) = \frac{\mu}{2}(I_1-d) - \mu\ln J + \frac{\lambda}{2}(\ln J)^2.\]

如果想做接近橡胶的材料：

\[\ u=0.49\]

甚至：

\[0.499.\]

那么：

\[\lambda\gg\mu.\]

此时低阶 displacement-only tet 很容易出现 volumetric locking：

一个自然解决方案就是 mixed displacement-pressure formulation：

\[(u,p).\]

对于大变形、近不可压超弹性，目前工程文献仍广泛使用稳定 mixed pairs 或 stabilized equal-order formulations，以避免 locking。

因此：

\[\boxed{ \ ext{如果以后做高质量软体 FEM， LBB 条件几乎绕不过去。} }\]

11. 为什么很多商业有限元里会出现“mixed / hybrid element”？

查看完整推导与细节

例如近不可压橡胶、塑性材料里，经常会看到：

  • hybrid elements；
  • mixed \(u-p\) elements；
  • enhanced strain；
  • selective/reduced integration；
  • pressure stabilization。

这些方法看起来很杂。

它们往往都在处理同一个核心问题：

\[\boxed{ \ ext{体积约束与离散位移自由度不兼容。} }\]

Mixed \(u-p\) 方法直接引入压力。

Reduced/selective integration 通过降低某些体积约束积分的强度来缓解 locking。

Stabilized methods 则允许使用原本不满足 inf-sup 的空间，例如：

\[P_1-P_1,\]

再加入一个稳定化项抑制 spurious pressure。2019 年关于近/完全不可压固体的工作就系统比较了 stable mixed pairs 与 pressure-projection stabilized equal-order methods。

12. Stabilization 本质上是在“修复”失败的 Inf-Sup

假设：

\[P_1-P_1\]

原本不稳定。

一种方式是改变空间：

\[\boxed{ P_2-P_1 }\]

。

另一种方式是保留：

\[P_1-P_1\]

但修改变分形式：

\[a(u,v) + b(v,p) + b(u,q) + \boxed{s(p,q)}.\]

其中：

\[s(p,q)\]

专门惩罚那些不受 \(B\) 控制的压力模式。

于是：

\[\boxed{ \ ext{稳定化项本质上是在填补离散算子的“盲区”。} }\]

这和物理引擎中的 regularization 很相似。

不过 stabilized FEM 的关键是：

\[\boxed{ s(p,q)\]

需要尽可能保持 consistency。

不能简单：

\[p^Tp\ imes10^6\]

粗暴惩罚。

13. MINI element 是另一个很漂亮的解决办法

查看完整推导与细节

MINI element 通常是：

\[\boxed{ (P_1+\ ext{bubble})-P_1. }\]

也就是说位移仍主要用线性 shape functions，

但每个 element 内增加一个：

\[\boxed{\ ext{bubble mode}}\]

。

这个 bubble：

  • 在单元内部非零；
  • 在边界为零；
  • 不增加跨单元 global continuity 复杂度。

它的意义就是：

\[\boxed{ \ ext{给位移空间增加额外局部自由度， 让它有能力回应压力约束。} }\]

FEniCS 当前 UFL 教程也把 MINI 和 Taylor–Hood 并列作为经典 mixed-element 示例。

这个思路特别值得记：

有时系统不稳定，不需要全面提高单元阶次，只要增加那些正好填补约束盲区的模式。

14. 这其实和 Hourglass mode 是“镜像问题”

之前卡片讲过 reduced integration 的 hourglass mode。

那里发生的是：

\[\boxed{ \ ext{某些位移模式没有被能量看见。} }\]

于是存在：

\[u_h\ eq0\]

却：

\[E(u_h)\approx0.\]

Inf-sup 失败时则是：

\[\boxed{ \ ext{某些压力模式没有被位移空间看见。} }\]

存在：

\[p_h\ eq0\]

却：

\[B^Tp_h\approx0.\]

两者都是：

\[\boxed{\ ext{离散算子出现非物理零空间。}}\]

区别只是：

  • Hourglass：primal 位移空间中出现盲区；
  • LBB failure：dual/constraint 空间中出现盲区。

这是一个很有价值的统一视角。

15. 它和 Schur complement 也正好接上

上一张卡片中：

\[\begin{bmatrix} A&B^T\\ B&0 \end{bmatrix}\]

消掉 \(u\) 后得到 pressure Schur complement：

\[S_p = BA^{-1}B^T.\]

现在 inf-sup 条件又告诉你：

\[\boxed{ S_p \ ext{ 必须在压力空间上足够非退化。} }\]

如果存在：

\[p\ eq0\]

满足：

\[B^Tp\approx0,\]

那么：

\[p^TBA^{-1}B^Tp \approx0.\]

于是：

\[\boxed{ S_p }\]

就出现接近零的特征值。

因此可以把 inf-sup 理解成：

\[\boxed{ \ ext{pressure Schur complement 必须具有良好的谱下界。} }\]

这就把抽象函数分析和实际求解器 conditioning 连起来了。

16. 一个特别重要的区别：连续问题稳定，不代表离散问题稳定

连续 Stokes/不可压弹性问题本身可能完全 well-posed：

\[\beta>0.\]

但是有限元离散后：

\[\beta_h\]

可能：

\[\beta_h\rightarrow0.\]

这意味着：

\[\boxed{ \ ext{PDE 本身没有问题， 是你的离散空间创造了一个不存在的病态。} }\]

这是 numerical PDE 中非常值得建立的意识。

很多仿真异常：

  • 压力振荡；
  • locking；
  • 约束力异常；
  • mesh refinement 不收敛；

不一定来自：

\[\boxed{\ ext{材料参数、求解器容差或时间步}}\]

。

有时问题已经发生在：

\[\boxed{\ ext{离散空间设计}}\]

这一层。

17. 这对 XPBD / constraint solver 也有一个非常强的迁移启发

假设约束：

\[C(x)=0.\]

线性化：

\[J\Delta x=-C.\]

约束空间求解：

\[JM^{-1}J^T\lambda=b.\]

如果某些约束：

  • 重复；
  • 几乎线性相关；
  • 过密；
  • 与当前自由度不兼容；

就会让：

\[JM^{-1}J^T\]

接近奇异。

这和 mixed FEM 的：

\[\boxed{\beta_h\rightarrow0}\]

本质上非常接近。

因此 Inf-Sup 给物理引擎一个很深的启发：

\[\boxed{ \ ext{“约束数量多”不等于“约束质量高”。} }\]

真正应该关心的是：

\[\boxed{ \ ext{constraint space 与 state space 是否兼容。} }\]

这比简单地讨论 compliance、iteration count 或 solver tolerance 更底层。

18. 为什么这对 PBD 体积约束也值得警惕？

假设每个 tet 都有：

\[C_e(x) = V_e(x)-V_e^0=0.\]

如果近不可压材料中给大量 tet 强施加体积约束，

从离散结构角度，其实就是建立了一个非常丰富的：

\[\boxed{\ ext{constraint space}}\]

。

但 vertex positions：

\[x\]

能否独立满足所有这些局部体积模式？

如果约束之间高度相关：

\[\boxed{ J\]

就可能有很差的谱性质。

于是可能看到：

  • λ 很大；
  • convergence 慢；
  • alternating corrections；
  • rigid-like behavior；
  • sensitivity to ordering。

这虽然不是严格意义上 FEM LBB theorem 的直接套用，但思想完全值得迁移：

\[\boxed{ \ ext{状态离散和约束离散必须一起设计。} }\]

19. Inf-Sup 甚至给“增加物理约束”这件事一个反直觉警告

通常工程上遇到不稳定会想：

再加几个约束。

但 mixed theory 告诉我们：

\[\boxed{ \ ext{添加 constraint DOFs 可能让系统更差。} }\]

因为每增加一个：

\[q_h\]

方向，

你都要求 primal space：

\[V_h\]

能够对它产生足够独立的 response。

否则就是给系统增加：

\[\boxed{\ ext{新的接近零特征值。}}\]

因此约束系统真正需要的不是：

\[\ ext{maximum constraints}\]

而是：

\[\boxed{\ ext{compatible constraints}.}\]

这对：

  • 接触点选取；
  • joint constraints；
  • incompressibility；
  • multiphysics coupling；

都有迁移意义。

20. 一个最值得自己做的实验

查看完整推导与细节

做二维 Stokes：

\[-\Delta u+\ abla p=f,\]\[\ abla\cdot u=0.\]

在同一个网格上比较：

A. \(P_1-P_1\)

\[u:P_1,\qquad p:P_1.\]

B. Taylor–Hood

\[u:P_2,\qquad p:P_1.\]

分别画：

\[p_h(x,y).\]

很可能 A 出现明显 checkerboard / oscillatory pressure，

B 则平滑稳定。

然后继续细化 mesh。

最关键的观察是：

\[\boxed{ \ ext{A 的问题不一定因为 mesh 更细而消失。} }\]

再进一步计算离散 inf-sup constant。

一种数值方法是构造广义特征值问题，大致检查：

\[BA^{-1}B^Tq = \lambda M_q q.\]

最小非零特征值满足：

\[\boxed{ \beta_h^2\sim\lambda_{\min}. }\]

观察：

\[h\downarrow\]

时：

  • 稳定 pair：\(\beta_h\) 保持有界；
  • 不稳定 pair：\(\beta_h\rightarrow0\)。

这个实验会把抽象的：

\[\inf\sup\]

直接变成一个你能看到的谱问题。

21. 对近不可压软体，一个很实用的设计路线

如果未来实现 mixed tet solver，不要从：

1

P1 displacement + P1 pressure

直接开始，然后靠调 stabilization 参数救火。

更合理的顺序是：

  1. 明确 continuum formulation 是：

    \[(u,p)\]

    还是 displacement-only；

  2. 如果是 mixed formulation，先选一个理论上稳定的 pair，例如 Taylor–Hood 或 MINI；

  3. 用 manufactured solution / patch test 检查：

    \[u,p\]

    的收敛；

  4. 再测试：

    \[\ u=0.49,\ 0.499,\ 0.4999\]

  5. 检查 displacement error 是否随着：

    \[\lambda\rightarrow\infty\]

    爆炸；

  6. 最后才考虑 equal-order + stabilization 来换取 GPU/工程便利性。

这样能区分：

\[\boxed{ \ ext{基础离散问题} }\]

和：

\[\boxed{ \ ext{工程优化问题}. }\]

近不可压弹性中的稳定 mixed pair、stabilized equal-order 和 gradient-robust variants 正是在这条脉络上发展的。

今天值得留下的一句话

Inf-Sup 条件最值得记住的并不是：

\[\inf_{q_h} \sup_{v_h} \frac{b(v_h,q_h)} {\|v_h\|\|q_h\|} \ge\beta.\]

真正应该留下的是：

\[\boxed{ \ ext{一个约束变量只有在 primal variable 能“感觉到它”时，才是合法的离散自由度。} }\]

它在知识体系中的位置可以这样看：

\[\ ext{ordinary Galerkin FEM}\]\[\downarrow\]\[\ ext{mixed / saddle-point formulation}\]\[\downarrow\]\[\boxed{\ ext{Inf-Sup compatibility}}\]\[\downarrow\]\[\ ext{stable pressure / multiplier / constraint discretization}.\]

它对物理求解器最大的启发则更普遍：

\[\boxed{ \ ext{数值稳定性不只由“方程写得对不对”决定， 还取决于不同变量空间之间是否拥有正确的相对自由度。} }\]

因此下次看到：

  • 近不可压软体异常僵硬；
  • pressure checkerboard；
  • multiplier oscillation；
  • constraint matrix 几乎奇异；
  • 增加约束反而更难收敛；

可以把诊断层级向上提一层：

\[\boxed{ \ ext{先检查空间兼容性， 再去调 solver 参数。} }\]

这就是 LBB 条件真正值得学的原因。

拓展阅读

查看完整推导与细节

  1. Franco Brezzi, On the Existence, Uniqueness and Approximation of Saddle-Point Problems Arising from Lagrangian Multipliers, 1974。Inf-Sup/Brezzi 理论的奠基工作之一。适合在理解直觉之后回头看严格 formulation。
    NUMDAM 原文页面

  2. Boffi, Brezzi & Fortin, Mixed Finite Element Methods and Applications, Springer, 2013。如果想系统掌握 mixed FEM，这是最标准的教材之一，覆盖 saddle-point theory、inf-sup、stabilization、不可压流动、弹性以及 \(H(\mathrm{div})/H(\mathrm{curl})\) 元。

  3. Karabelas et al., Versatile stabilized finite element formulations for nearly and fully incompressible solid mechanics, Computational Mechanics, 2020。如果重点是软体/近不可压固体，这篇非常直接：比较稳定 mixed element pair 与 stabilized \(P_1-P_1\)，并明确讨论 locking 与 LBB 条件。
    Springer 开放论文

  4. Basava & Wollner, Gradient Robust Mixed Methods for Nearly Incompressible Elasticity, Journal of Scientific Computing, 2023。适合进一步看一个更现代的问题：即使 element pair 满足 inf-sup，压力仍可能污染 displacement error；gradient robustness 进一步提高近不可压极限下的质量。

  5. FEniCSx Mixed Finite Element Tutorial。适合直接实现 Taylor–Hood / MINI。当前教程明确展示了 mixed spaces、Taylor–Hood 和 MINI 的构建方式。
    FEniCS mixed problem 教程
