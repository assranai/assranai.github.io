Backward Error Analysis：数值积分器真正求解的，往往不是原方程，而是一个“附近的精确方程”

Sep 13, 2026
阅读时长: 6 分钟

Backward Error Analysis：数值积分器真正求解的，往往不是原方程，而是一个“附近的精确方程”

主题：Backward Error Analysis（后向误差分析）与 Shadow Hamiltonian（影子哈密顿量）
领域：数值方法 × 有限元 × 物理引擎 × 非线性动力学
推荐阅读时间：约 8–10 分钟
今天选这个主题，是因为它解释了一个非常重要、又容易被误解的现象：

为什么某些二阶积分器运行几百万步后，能量仍然只是在一个范围内振荡；另一些局部误差看起来同样很小的方法，却会出现持续的能量漂移？

只比较：

\[\|x_{n+1}-x(t_{n+1})\|\]

通常解释不了这件事。

Backward Error Analysis（BEA）换了一个问题：

\[\boxed{ \ ext{不要问“数值解离原方程的精确解多远”， 而问“这个数值轨迹究竟是哪一个微分方程的精确轨迹？”} }\]

这个视角是 geometric numerical integration 的核心工具之一。Hairer、Lubich、Wanner 的经典专著正是用 modified equations / backward error analysis 来解释辛积分器和对称积分器优异的长期行为。

1. 先看普通误差分析在问什么

考虑：

\[\dot y=f(y).\]

数值积分器给：

\[y_{n+1}=\Phi_h(y_n).\]

传统 forward error analysis 比较：

\[y_n\]

和原方程的精确解：

\[y(t_n).\]

例如某二阶方法：

\[\|y_n-y(t_n)\|=O(h^2).\]

这告诉你：

\[\boxed{\ ext{在有限时间内，轨迹位置有多准。}}\]

但动力系统还有另一个问题：

\[\boxed{\ ext{轨迹的几何性质是否正确？}}\]

例如：

  • 能量是否长期漂移；
  • 相空间体积是否保持；
  • 周期轨道是否逐渐螺旋出去；
  • 角动量是否保持；
  • 高频模态是否产生人工耗散。

这些并不能仅靠“每一步局部误差是 \(O(h^3)\)”回答。

2. BEA 的核心反转

假设积分器：

\[y_{n+1}=\Phi_h(y_n).\]

Backward error analysis 尝试寻找一个 modified differential equation：

\[\boxed{ \dot y = f_h(y) }\]

其中：

\[f_h = f + h f_1 + h^2f_2 + h^3f_3+\cdots\]

使得数值映射：

\[\Phi_h\]

可以被看作这个修正方程在一个时间步 \(h\) 上的精确流，至少在截断到足够高阶时高度近似。

于是：

\[\boxed{ \ ext{Numerical trajectory} \approx \ ext{exact trajectory of a nearby system}. }\]

这个“nearby”是整个思想的关键。

数值积分器每一步确实有误差，

但它可能不是在随机地偏离原动力学，而是在非常忠实地跟随另一个略微变形后的动力系统。这就是 modified differential equations 的基本出发点。

3. 一个非常简单的例子：显式 Euler 到底精确求解了什么？

原方程：

\[\dot y=f(y).\]

Explicit Euler：

\[y_{n+1} = y_n+h f(y_n).\]

我们寻找：

\[\dot y = f(y)+h g(y)+O(h^2)\]

使它的精确一步解与 Euler 匹配。

精确解 Taylor 展开：

\[y(h) = y_0 + h f_h(y_0) + \frac{h^2}{2}f_h'(y_0)f_h(y_0) + O(h^3).\]

代入：

\[f_h=f+hg+\cdots\]

得到：

\[y(h) = y_0 + hf + h^2 \left[ g+\frac12f'f \right] +O(h^3).\]

而 Euler 只有：

\[y_0+hf.\]

所以要求：

\[g = -\frac12f'f.\]

于是 Euler 对应的 modified equation 开头是：

\[\boxed{ \dot y = f(y) - \frac h2 f'(y)f(y) + O(h^2). }\]

这条式子的意义很大：

Euler 的误差可以解释为：

\[\boxed{ \ ext{你实际上给原物理方程偷偷加入了一些 }O(h)\ ext{ 的额外动力学。} }\]

于是可以开始问一个比 truncation error 更物理的问题：

这些额外项是什么性质？

它们是耗散？

反耗散？

频率修正？

刚度修正？

4. 在谐振子上，区别立即变得明显

考虑：

\[\dot q=p,\]\[\dot p=-q.\]

Hamiltonian：

\[H(q,p) = \frac12(p^2+q^2).\]

真实轨迹是相平面里的圆：

\[H=\ ext{const}.\]

Explicit Euler

\[q_{n+1}=q_n+h p_n,\]\[p_{n+1}=p_n-hq_n.\]

计算能量：

\[q_{n+1}^2+p_{n+1}^2 = (1+h^2)(q_n^2+p_n^2).\]

所以：

\[\boxed{ H_{n+1} = (1+h^2)H_n. }\]

每一步都人工增加能量。

轨迹变成：

\[\boxed{\ ext{不断向外扩张的螺旋。}}\]

无论 \(h\) 多小，只要运行足够久，这种系统性偏差都会积累。

5. 换成 Symplectic Euler，事情完全不同

一种 symplectic Euler：

\[p_{n+1} = p_n-hq_n,\]\[q_{n+1} = q_n+h p_{n+1}.\]

它同样只有：

\[\boxed{\ ext{一阶精度}}\]

。

如果只看 local truncation order：

\[\ ext{Explicit Euler}\]

与：

\[\ ext{Symplectic Euler}\]

似乎差不多。

但长期行为完全不同。

Symplectic Euler 的能量通常不会持续单调增长，

而是在真实能量附近：

\[\boxed{\ ext{有界振荡。}}\]

为什么？

并不是因为它神奇地精确保持原始：

\[H(q,p).\]

实际上通常没有。

真正发生的是：

\[\boxed{ \ ext{它近似精确保持了另一个非常接近 }H\ ext{ 的 Hamiltonian。} }\]

这就是：

\[\boxed{\ ext{Shadow / Modified Hamiltonian}.}\]

辛积分器的长期近能量守恒正是 backward error analysis 的经典结果之一；在适当条件下，这种小幅能量误差可以维持极长时间。

6. Shadow Hamiltonian 到底是什么？

对于 Hamiltonian 系统：

\[\dot z = J^{-1}\ abla H(z),\]

如果使用一个 symplectic integrator，

其 modified equation 仍然可以形式上写成 Hamiltonian 系统：

\[\boxed{ \dot z = J^{-1} \ abla\ ilde H(z) }\]

其中：

\[\ ilde H = H + hH_1 + h^2H_2+\cdots.\]

如果方法还具有对称性，例如 Störmer–Verlet，

通常 odd/even 修正结构会进一步受到限制，例如常出现：

\[\ ilde H = H+h^2H_2+h^4H_4+\cdots.\]

数值轨迹于是近似满足：

\[\boxed{ \ ilde H(z_n) \approx \ ext{constant}. }\]

而因为：

\[\ ilde H-H=O(h^p),\]

原始能量：

\[H(z_n)\]

就会围绕真实值产生小幅、有界变化，

而不是长期单向漂移。

这就是：

\[\boxed{ \ ext{辛积分器“能量表现好”的真正原因， 通常并不是它逐步精确守恒原能量。} }\]

Hairer、Lubich、Wanner 的 Störmer–Verlet 综述专门用这一方法说明几何结构保持为何带来更好的 long-time behaviour。

7. 这点非常容易和“Energy-conserving method”混淆

有两种完全不同的目标。

精确能量守恒

某些算法构造：

\[H(z_{n+1})=H(z_n)\]

逐步精确成立。

Symplectic / shadow-energy preservation

通常：

\[H(z_{n+1})\ eq H(z_n),\]

但存在：

\[\ ilde H\]

使：

\[\ ilde H(z_n)\approx\ ext{const}.\]

因此原始能量：

\[H(z_n)\]

在附近振荡。

这两者不能简单画等号。

Geometric numerical integration 更关心的是：

\[\boxed{\ ext{整个 Hamiltonian phase-space geometry}}\]

而不只是某一个标量 invariant。辛积分器的定义本身就是保持 Hamiltonian flow 的 symplectic structure。

8. 为什么这比“高阶”更深一层？

查看完整推导与细节

假设有：

方法 A

四阶，但非 symplectic。

方法 B

二阶 Störmer–Verlet，但 symplectic。

短时间：

\[A\]

很可能位置误差更小。

但运行：

\[10^6\]

甚至：

\[10^9\]

个周期，

B 可能在轨道结构和长期能量上更可信。

因此 numerical integration 至少有两个评价轴：

\[\boxed{\ ext{local/global approximation order}}\]

以及：

\[\boxed{\ ext{geometric fidelity}}\]

。

这两者相关，却完全不是一回事。

这也是 geometric numerical integration 作为独立理论体系存在的原因。

9. 一个非常有价值的理解：数值误差可以被看作“模型误差”

传统视角：

\[\boxed{ \ ext{离散化} \rightarrow \ ext{误差} }\]

。

Backward error 视角：

\[\boxed{ \ ext{离散化} \rightarrow \ ext{modified physics} }\]

。

例如：

\[\dot y=f(y)\]

通过某积分器以后，

实际上变成：

\[\dot y= f(y) + h^p g(y)+\cdots.\]

于是：

\[g(y)\]

就是离散化引入的“虚拟物理”。

这可能是：

  • artificial damping；
  • artificial antidamping；
  • frequency shift；
  • modified stiffness；
  • modified inertia；
  • nonlinear coupling。

所以一个积分器并不是简单地：

“每步误差 0.01%。”

它更像：

“你把真实系统替换成了一个参数依赖于时间步的附近系统。”

这个视角对物理引擎尤其重要。

10. 为什么游戏物理里的“稳定”不等于“物理正确”？

例如 implicit Euler 对弹簧系统非常稳定。

即使：

\[h\]

较大，它通常不会爆炸。

但它会引入明显 numerical damping。

也就是说：

\[\boxed{ \ ext{稳定性来自它实际模拟了一个更耗散的 modified system。} }\]

因此你看到：

1
2
3
4
5

真实系统：
振动很久

Implicit Euler：
几步以后振没了

从传统数值稳定性角度：

\[\boxed{\ ext{非常稳定。}}\]

从动力学 fidelity 角度：

\[\boxed{\ ext{modified physics 很强。}}\]

这解释了一个求解器开发里极其重要的区别：

\[\boxed{ \ ext{不爆炸} \ eq \ ext{动力学正确}. }\]

11. XPBD 也可以用这个视角重新理解

XPBD 常被写成 constraint correction：

\[\Delta\lambda = \frac{-C-\ ilde\alpha\lambda} {\ abla C^TM^{-1}\ abla C+\ ilde\alpha}.\]

工程上容易把注意力集中到：

  • compliance；
  • iteration count；
  • substeps；
  • damping；
  • velocity update。

但从 modified-equation 思维看，可以再问：

\[\boxed{ \ ext{这些离散操作组合起来， 究竟对应什么连续动力学？} }\]

特别是：

  • position projection；
  • velocity reconstruction；
  • constraint damping；
  • collision projection；

都会引入隐含的：

\[\boxed{\ ext{effective stiffness / damping / impulse law}}\]

。

当 soft body 接触后出现：

  • 能量持续注入；
  • 过度耗散；
  • 高频抖动；
  • volume oscillation；

一个非常有价值的诊断问题就是：

这是不是某个离散步骤系统性地引入了错误符号的 modified-energy term？

这比单纯追：

\[\ ext{NaN}\]

或某帧：

\[\Delta x\]

异常更接近机制。

12. 为什么 Substepping 有时“神奇地治好了物理”？

查看代码与实现

如果 modified equation 是：

\[\dot y = f(y) + h^p g_p(y) + O(h^{p+1}),\]

时间步从：

\[h\]

改成：

\[h/2,\]

人工动力学的幅度会变成大约：

\[\frac{1}{2^p}.\]

所以 substepping 不只是：

\[\boxed{\ ext{提高轨迹精度}}\]

。

它同时在：

\[\boxed{\ ext{减弱离散化引入的虚拟物理。}}\]

这解释了为什么某些系统：

1
2
3
4
5

1 substep:
明显人工阻尼/爆能

4 substeps:
突然“像真的”

背后可能不是 solver iteration 单纯变多，而是：

\[\boxed{ h\ ext{-dependent modified dynamics 显著变弱。} }\]

13. Störmer–Verlet 为什么成为物理模拟中的经典方法？

对于可分 Hamiltonian：

\[H(q,p)=T(p)+V(q),\]

Störmer–Verlet 可以写成：

\[p_{n+\frac12} = p_n - \frac h2\ abla V(q_n),\]\[q_{n+1} = q_n + h\ abla_pT(p_{n+\frac12}),\]\[p_{n+1} = p_{n+\frac12} - \frac h2\ abla V(q_{n+1}).\]

它同时具有：

\[\boxed{\ ext{二阶}}\]\[\boxed{\ ext{对称 / time reversible}}\]\[\boxed{\ ext{symplectic}}\]

几个非常关键的结构。

Hairer、Lubich、Wanner 甚至以 Störmer–Verlet 为核心写过一篇完整的 Acta Numerica 综述，因为它几乎是理解 geometric numerical integration 的最佳样板。

14. 为什么“对称性”也特别重要？

查看完整推导与细节

如果一个积分器满足：

\[\Phi_{-h} = \Phi_h^{-1},\]

称为 symmetric / time-reversible。

直觉上：

向前一步：

\[h\]

再向后一步：

\[-h\]

能回到原状态。

对于这类方法，modified equation 也具有特殊的奇偶结构。

例如二阶 symmetric method 的 modified vector field 通常形如：

\[f_h = f+h^2f_2+h^4f_4+\cdots,\]

没有：

\[h,\ h^3,\ldots\]

这样的项。

所以很多 systematic drift 项天然消失。

这也是为什么：

\[\boxed{ \ ext{symmetry} }\]

常与优秀的长期行为联系在一起；在可积 Hamiltonian 系统上，相关理论也能得到长时间的小能量误差性质。

15. BEA 也解释了“相位误差”和“能量误差为什么不是同一个东西”

查看完整推导与细节

考虑振子。

数值积分器可能模拟一个 modified oscillator：

\[\ddot q+\ ilde\omega^2q=0\]

其中：

\[\ ilde\omega = \omega + c h^2+\cdots.\]

那么它的能量结构可以非常好，

但频率略有误差。

运行很久以后：

\[\boxed{\ ext{phase error 可以非常大}}\]

——数值振子可能和真实振子差了很多个周期相位。

与此同时：

\[\boxed{\ ext{energy error 仍然很小。}}\]

所以：

\[\boxed{ \ ext{长期能量稳定} \ eq \ ext{长期轨迹点逐点准确}. }\]

这是理解 Hamiltonian numerical simulation 必须接受的一件事。

长期模拟通常更现实的目标是保持：

  • qualitative phase portrait；
  • invariants；
  • statistical properties；
  • orbital behaviour；

而不是要求 \(t=10^9\) 时位置仍逐点相同。

16. 这对混沌系统尤其重要

查看完整推导与细节

在 chaotic system 中：

\[\|\delta x(t)\| \sim e^{\lambda t}\|\delta x(0)\|.\]

任何浮点误差、离散误差都会指数放大。

所以长期要求：

\[x_{\rm numerical}(t) \approx x_{\rm exact}(t)\]

本身可能就没有现实意义。

Backward-error / geometric viewpoint 提供了另一套评价：

\[\boxed{ \ ext{数值系统是不是仍然属于正确的附近动力系统类别？} }\]

例如：

  • 保持 symplectic geometry；
  • 能量长期有界；
  • invariants 近似保持；
  • 相空间统计行为正确。

这比“第 100 万步的位置误差是多少”往往更有物理意义。

17. 对有限元动力学，它提供了一个非常重要的算法选择标准

半离散 FEM 常得到：

\[M\ddot q+\ abla V(q)=0.\]

这本身已经是有限维 Hamiltonian / Lagrangian system。

此时还有第二次离散：

\[\boxed{\ ext{time discretization}.}\]

所以最终误差有两层：

\[\ ext{continuum} \rightarrow \ ext{spatial FEM} \rightarrow \ ext{time integrator}.\]

即使空间 FEM 很准确，

如果时间积分持续制造 artificial energy drift，

长期 dynamics 仍然会错。

因此 transient structural FEM 选算法时不应该只看：

\[\boxed{\ ext{A-stable?}}\]

还应看：

  • 是否需要 physical/numerical damping；
  • 高频模态是否应被过滤；
  • 是否要求长期 conservative dynamics；
  • 是否需要 reversibility；
  • 是否存在 Hamiltonian structure。

Hairer 等对 geometric integration 的系统理论正是围绕这些结构保持问题展开。

18. 这也解释了为什么“数值耗散”有时反而是设计目标

查看完整推导与细节

并不是所有问题都应该 symplectic。

结构 FEM 里常有很多高频 mesh modes：

\[\omega_{\rm high}\]

其实并不是你关心的物理。

此时 generalized-\(\alpha\) 一类方法有意给高频加入数值耗散：

\[\boxed{ \ ext{抑制非物理高频， 保留低频工程响应。} }\]

从 BEA 的角度：

这相当于有意识地设计 modified dynamics。

因此真正成熟的问题不是：

有没有 numerical damping？

而是：

\[\boxed{ \ ext{离散算法引入了什么 damping， 它作用在哪些频率， 是不是我想要的？} }\]

这比单纯追求“绝对无耗散”更接近工程。

19. 对可靠性分析，它还有一个经常被忽略的意义

查看完整推导与细节

假设极限状态依赖动态峰值：

\[g(\ heta) = F_{\rm limit} - \max_t F(t;\ heta).\]

如果 time integrator 带来 artificial damping，

那么：

\[F_{\max}\]

可能系统性偏小。

于是：

\[P_f\]

也可能被系统性低估。

这种误差并不是：

\[\boxed{\ ext{随机 surrogate error}}\]

而是：

\[\boxed{\ ext{numerical-model bias}.}\]

更危险的是：

时间步减半时代理模型本身可能仍然拥有：

\[R^2=0.99,\]

但它拟合的是两个不同 modified physical systems。

所以动态可靠性中非常值得进行：

\[\boxed{ h \rightarrow g_h(\ heta) }\]

的时间步收敛分析。

真正需要确认的是：

\[g_h \rightarrow g.\]

不是只确认：

\[\hat g_h \approx g_h.\]

这区分了：

\[\boxed{\ ext{代理模型误差}}\]

和：

\[\boxed{\ ext{底层数值物理误差}.}\]

20. 一个非常适合自己做的实验

查看完整推导与细节

只需要模拟：

\[\ddot q+q=0.\]

初始：

\[q(0)=1,\qquad p(0)=0.\]

真实能量：

\[H=\frac12.\]

分别使用：

  1. Explicit Euler；
  2. Implicit Euler；
  3. Symplectic Euler；
  4. Störmer–Verlet；
  5. RK4。

统一：

\[h=0.1\]

运行：

\[10^5\]

步。

不要只画：

\[q(t).\]

同时画：

\[\boxed{ H_n-H_0 }\]

以及 phase portrait：

\[(q_n,p_n).\]

你很可能看到：

  • Explicit Euler：不断向外螺旋；
  • Implicit Euler：不断向内螺旋；
  • Symplectic Euler：围绕某条附近闭轨道运动；
  • Verlet：能量在一个很窄的范围内振荡；
  • RK4：短期极准，但超长时间行为需要另外观察其系统性漂移。

然后把：

\[h=0.1,\ 0.05,\ 0.025\]

重复一遍。

真正值得看的不是某一步误差，

而是：

\[\boxed{ \ ext{“人工动力学”如何随 }h\ ext{ 缩小。} }\]

这个实验会比背一堆 symplectic 定义更快建立直觉。

21. 对自研求解器，一个非常实用的诊断建议

查看完整推导与细节

以后看到动力学异常，不妨把诊断分成三层。

第一层：

\[\boxed{\ ext{方程层}}\]

连续物理模型本身对不对？

第二层：

\[\boxed{\ ext{空间离散层}}\]

FEM/PBD constraints 有没有 locking、hourglass、inversion 等问题？

第三层：

\[\boxed{\ ext{时间离散层}}\]

积分器正在给系统增加什么 modified physics？

尤其可以做：

\[h,\quad h/2,\quad h/4\]

对照，记录：

  • 总能量；
  • 动能；
  • 势能；
  • 约束功；
  • 接触冲量；
  • COM；
  • 主频；
  • 峰值 \(J\)。

如果异常量按：

\[h^p\]

稳定下降，

它很可能就是离散时间产生的 modified-equation effect。

如果不下降，

再继续寻找空间离散或物理模型问题。

这会比单纯“把 substep 再调大一点看看”更有解释力。

今天值得留下的一句话

Backward Error Analysis 最值得记住的不是 modified equation 的展开式。

真正重要的是这个视角：

\[\boxed{ \ ext{数值算法不是简单地“带误差求解原物理”； 它往往是在非常准确地求解一个略微被修改的物理系统。} }\]

于是评价一个积分器时，问题就从：

\[\ ext{这一步误差是多少？}\]

升级为：

\[\boxed{ \ ext{它把我的物理系统修改成了什么？} }\]

这也解释了为什么：

\[\boxed{\ ext{稳定性、精度、守恒性、长期真实性}}\]

是四个相关却不同的维度。

在整个知识体系中，它处在：

\[\ ext{ODE / semi-discrete mechanics}\]\[\downarrow\]\[\ ext{time discretization}\]\[\downarrow\]\[\boxed{\ ext{Backward Error Analysis / Modified Equation}}\]\[\downarrow\]\[\ ext{Geometric Numerical Integration}\]\[\downarrow\]\[\ ext{long-time physical fidelity}.\]

对于物理引擎开发，我认为它最有迁移价值的一点尤其简单：

\[\boxed{ \ ext{当一个算法“稳定但看起来不物理”时， 不要只问参数该怎么调； 试着问：它究竟在模拟哪个 modified system？} }\]

这往往能把调参问题提升成一个可以分析的数值模型问题。

拓展阅读

查看扩展内容

  1. Hairer, Lubich & Wanner, Geometric Numerical Integration: Structure-Preserving Algorithms for Ordinary Differential Equations。这一领域最系统的经典教材，完整讨论 symplectic、symmetric integrators、modified equations、backward error analysis 和长期行为。
    Springer 图书页

  2. Hairer, Lubich & Wanner, Geometric numerical integration illustrated by the Störmer–Verlet method, Acta Numerica, 2003。如果只读一篇，我更推荐这一篇；它用 Verlet 把 symplecticity、backward error analysis 和长期能量行为串成一个完整故事。
    Cambridge 论文页

  3. Sanz-Serna, Symplectic Integrators for Hamiltonian Problems: An Overview, Acta Numerica。经典综述，适合理解 symplectic integrator 在 Hamiltonian 数值计算中的理论定位。

  4. Chartier, Hairer & Vilmart, Modified Differential Equations, 2007。篇幅很短，适合作为 backward-error / modified-equation 的快速数学入口。
    Université de Genève 开放页面

  5. Hairer, Important Aspects of Geometric Numerical Integration, Journal of Scientific Computing, 2005。进一步讨论 Hamiltonian systems、reversibility、backward error analysis、energy conservation 与高度振荡系统。
