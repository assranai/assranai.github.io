FAS：非线性问题的“粗网格”不该只修正误差，而应该直接解一个粗尺度的完整非线性状态

Sep 03, 2026
阅读时长: 7 分钟

FAS：非线性问题的“粗网格”不该只修正误差，而应该直接解一个粗尺度的完整非线性状态

主题：Full Approximation Scheme（FAS，全近似格式）
领域：有限元 × 数值方法 × 软体动力学 × 接触力学
推荐阅读时间：约 8–10 分钟

上一期 Multigrid 的核心是：

\[\boxed{ \text{细网格消高频误差，粗网格消低频误差} }\]

但那套最经典的推导针对的是线性问题：

\[Au=f.\]

真正进入软体、超弹性、塑性、接触以后，我们面对的是：

\[\boxed{ F_h(u_h)=f_h }\]

其中 \(F_h\) 是非线性算子。

这时一个关键问题出现了：

粗网格到底应该解“误差”，还是应该解“解本身”？

FAS 给出的答案是：

\[\boxed{ \text{在非线性问题里，粗层应当求一个完整的 coarse approximation。} }\]

这也是它名字里 Full Approximation 的真正含义。

Achi Brandt 在 1970 年代建立了现代 multigrid/FAS 框架；其 1977 年经典论文已经明确讨论了利用多层网格以近线性复杂度求解包括非线性在内的边值问题。今天 PETSc 的 SNESFAS 仍然直接实现这一 nonlinear multigrid 体系。

1. 为什么线性 multigrid 的“误差方程”到了非线性里不再自然？

线性问题：

\[Au=f.\]

当前近似：

\[\tilde u.\]

定义误差：

\[e=u-\tilde u.\]

因为线性性：

\[A(u-\tilde u) = Au-A\tilde u,\]

所以：

\[\boxed{ Ae=f-A\tilde u=r. }\]

于是 coarse grid 很自然地解：

\[A_H e_H=r_H.\]

然后：

\[u_h \leftarrow u_h+Pe_H.\]

整个 coarse level 只负责计算：

\[\boxed{\text{correction}}\]

这就是上一期讲的 coarse-grid correction。

2. 非线性时，这条等式坏掉了

现在：

\[F(u)=f.\]

当前近似：

\[\tilde u.\]

你仍然想写：

\[u=\tilde u+e.\]

但：

\[F(\tilde u+e) \neq F(\tilde u)+F(e).\]

所以不能得到：

\[F(e)=f-F(\tilde u).\]

也就是说：

\[\boxed{ \text{非线性算子不能把“当前状态”和“误差”拆开。} }\]

这看起来只是一个代数小问题，实际却决定了 nonlinear multigrid 的 formulation。

FAS 正是为这个问题设计的。Brandt–Livne 的多重网格专著把 FAS 作为解决 nonlinear problems 的标准多层框架之一。

3. FAS 的关键：粗网格解的是 \(u_H\)，不是 \(e_H\)

假设 fine-grid equation：

\[F_h(u_h)=f_h.\]

当前 fine approximation：

\[\tilde u_h.\]

先计算 residual：

\[r_h = f_h-F_h(\tilde u_h).\]

然后把当前解限制到 coarse grid：

\[\tilde u_H=I_h^H\tilde u_h.\]

FAS 不让 coarse grid 解：

\[F_H(e_H)=r_H.\]

而是构造一个新的 coarse equation：

\[\boxed{ F_H(u_H) = F_H(\tilde u_H) + Rr_h. }\]

等价地写：

\[F_H(u_H) = f_H+\tau_H.\]

其中：

\[\boxed{ \tau_H = F_H(I_h^H\tilde u_h) - R F_h(\tilde u_h) }\]

就是著名的：

\[\boxed{\tau\text{-correction}}\]

或：

\[\boxed{\text{FAS coarse-grid defect correction}}\]

。

PETSc 当前文档对 FAS 的描述非常直接：粗层求解的是 coarse versions of the nonlinear problem，并通过扰动粗问题，使 fine-grid projected solution 在粗层上产生零修正。

4. \(\tau\)-correction 到底在修什么？

这是 FAS 最值得理解的一点。

假设你只是简单地把 fine-grid 方程换成 coarse-grid 方程：

\[F_H(u_H)=f_H.\]

那么 coarse operator：

\[F_H\]

并不等于：

\[F_h\]

的完美缩小版。

因为：

  • discretization 不同；
  • 网格分辨率不同；
  • 非线性 constitutive response 不同；
  • 几何表示不同。

于是即使：

\[\tilde u_h\]

已经是真正 fine-grid solution，

直接限制：

\[I_h^H\tilde u_h\]

通常也不会精确满足 naïve coarse equation：

\[F_H(I_h^H\tilde u_h) \neq f_H.\]

这就很危险：

fine grid 已经对了，coarse grid 却会告诉你“还应该修一点”。

FAS 的 \(\tau\)-correction 就是消除这种假修正。

它要求一个非常重要的 fixed-point consistency：

如果：

\[F_h(u_h)=f_h,\]

那么把它限制到 coarse grid 后：

\[u_H=I_h^H u_h\]

应该恰好满足 FAS coarse equation。

于是 coarse correction：

\[u_H-I_h^Hu_h\]

为零。

所以：

\[\boxed{ \tau\text{ 的作用，是让 coarse physics 与当前 fine physics 保持一致。} }\]

这比“修正离散误差”更准确。

5. 一个很直观的非线性弹簧例子

考虑：

\[F(u)=ku+\beta u^3.\]

目标：

\[ku+\beta u^3=f.\]

假设 fine model 的非线性参数和 coarse approximation 不完全一致：

\[F_h(u)=k_hu+\beta_hu^3,\]\[F_H(u)=k_Hu+\beta_Hu^3.\]

如果直接把 fine 状态：

\[\tilde u_h\]

投到 coarse grid，再解：

\[F_H(u_H)=f_H,\]

coarse solver 会尝试把状态拉向：

\[F_H\]

自己的平衡点。

但这个平衡点未必与 fine problem 一致。

FAS 额外加入：

\[\tau_H = F_H(\tilde u_H) - RF_h(\tilde u_h),\]

于是 coarse problem 变成：

\[F_H(u_H) = Rf_h+\tau_H.\]

这样 coarse level 的任务就变成：

\[\boxed{ \text{用粗模型描述当前 fine residual 所对应的大尺度非线性修正} }\]

而不是：

\[\text{假装 coarse model 就是真实问题。}\]

function FAS(level h, u_h, f_h):

    pre-smooth:
        nonlinear_relax(F_h(u_h)=f_h)

    residual:
        r_h = f_h - F_h(u_h)

    restrict current state:
        u_H0 = I_h^H u_h

    build coarse RHS:
        f_H = F_H(u_H0) + R r_h

    recursively solve:
        u_H = FAS(H, u_H0, f_H)

    coarse correction:
        u_h += P (u_H - u_H0)

    post-smooth:
        nonlinear_relax(F_h(u_h)=f_h)

注意 coarse correction：

\[\boxed{ P(u_H-u_H^0) }\]

这里真正插值回来的是 coarse solution 的变化量。

但 coarse level 内部存储和求解的是：

\[\boxed{u_H}\]

完整近似。

这就是 FAS 与 linear correction scheme 最大的结构区别。

PETSc 的 FAS 实现今天仍保留 V/W cycle、pre/post smoothers、multiplicative/additive/full 等多种结构。

7. 为什么这对超弹性问题很有意义？

考虑 quasi-static hyperelasticity：

\[R(u) = f_{\rm int}(u)-f_{\rm ext} = 0.\]

例如 Neo-Hookean：

\[\Psi(F) = \frac{\mu}{2}(I_1-3) - \mu\ln J + \frac{\lambda}{2}(\ln J)^2.\]

于是：

\[f_{\rm int}(u) = \nabla_u \int\Psi(F(u))\,dV.\]

这个方程显然是强非线性的。

传统 Newton：

\[K(u_k)\Delta u=-R(u_k)\]

每轮：

  1. 线性化；
  2. 解一个大 tangent system；
  3. 更新。

而 FAS 的思路更接近：

\[\boxed{ \text{直接让多层网格共同处理 nonlinear state} }\]

粗层可以直接修正：

  • 大尺度整体弯曲；
  • 全局拉伸；
  • 大区域体积响应；

fine layer 再处理：

  • 局部材料非线性；
  • 几何细节；
  • 高频误差。

所以它不是：

\[\text{Newton + linear multigrid}\]

的简单改名。

它属于：

\[\boxed{\text{nonlinear multilevel solve}}\]

。

8. 它和 Newton–Multigrid 到底有什么区别？

这是最值得分清楚的相邻概念。

Newton–Krylov–Multigrid

先在当前状态：

\[u_k\]

线性化：

\[J(u_k)\Delta u=-R(u_k).\]

然后 multigrid 只负责求这个线性系统：

\[\boxed{ J\Delta u=-R. }\]

所以结构是：

\[\text{nonlinear outer Newton}\]\[\downarrow\]\[\text{linear multigrid inner solve}.\]

FAS

每一个 grid level 都拥有：

\[\boxed{\text{自己的 nonlinear problem}}\]

所以 nonlinear correction 本身跨尺度传播。

可以粗略记：

\[\boxed{ \text{Newton-MG：先线性化，再多层求解} }\]\[\boxed{ \text{FAS：非线性本身就是多层的} }\]

两者都非常有价值。

对很多成熟 FEM，Newton + geometric/AMG tangent preconditioner 往往更容易实现；例如有限应变超弹性的 matrix-free geometric multigrid 工作，就是在 tangent operator 上使用 multigrid。

FAS 则在强非线性、非线性平滑器有效、粗层非线性 operator 可以合理构造时更具吸引力。

9. FAS 真正困难的地方其实不是 V-cycle，而是 coarse nonlinear operator

查看完整推导与细节

线性问题可以自然做：

\[A_H = R A_h P\]

即 Galerkin coarse operator。

非线性时：

\[F_H\]

怎么定义就复杂得多。

你希望 coarse model：

  • 足够便宜；
  • 能代表低频 nonlinear modes；
  • 与 fine operator 一致；
  • 不会产生错误物理平衡点。

真实非结构网格里尤其困难。

近期 nonlinear multigrid 研究仍然重点关注这个问题。例如基于 AMGe coarse spaces 的 nonlinear FAS 工作强调：此前在一般非结构网格上，FAS 的难点之一就是 coarse nonlinear operators 不够稳定和准确；改进 coarse space 后，才能恢复更可靠的多层性能。

所以：

\[\boxed{ \text{FAS 成败很大程度由 coarse model quality 决定。} }\]

10. 这与代理模型有一个很有意思的联系

通常 surrogate 被理解成：

\[x\rightarrow y.\]

但 FAS 中 coarse nonlinear model 实际上也是一种：

\[\boxed{\text{低成本、低分辨率物理代理}}\]

区别是：

它不是替代 fine model 输出最终答案。

它的任务是：

\[\boxed{ \text{预测 fine problem 当前缺失的低频非线性修正。} }\]

这是一种非常不同的 surrogate philosophy：

\[\text{surrogate for outputs}\]

vs.

\[\boxed{ \text{surrogate for solver corrections} }\]

后一种思路很值得迁移到 learned solver。

比如：

\[\text{NN}\]

不必预测最终 FEM state，

它可以只预测：

\[\boxed{ \text{coarse/global correction} }\]

再让 fine physics solver 消除局部误差。

这通常比“AI 直接替代求解器”更加可控。

11. 为什么 FAS 可能特别适合“局部迭代传播很慢”的软体求解器？

假设一个 XPBD/Jacobi 软体长条：

局部 constraint projection 的信息传播是：

\[1\rightarrow2\rightarrow3\rightarrow\cdots\]

因此全局形变修正要经过很多 iteration 才能传遍整个物体。

上一期 Multigrid 已经说明：

\[\boxed{ \text{这是低频误差传播问题。} }\]

但如果 constraint 本身是强非线性：

  • volume constraints；
  • nonlinear strain；
  • contact active set；
  • large rotation；

简单在线性 correction space 做 coarse solve 可能不够。

FAS 给出的更自然思路是：

\[\boxed{ \text{粗层软体本身也做 nonlinear constraint solve} }\]

那么 fine level 有 contact：

\[C_f(x)\ge0,\]

coarse level 却根本不知道这个 contact。

于是 coarse correction 可能把物体推向：

\[\boxed{\text{fine level 不可行的方向}}\]

。

所以 contact-aware nonlinear multigrid 很难。

它要求 coarse hierarchy 不只是：

\[\text{geometry hierarchy}\]

还要考虑：

\[\boxed{ \text{constraint / active-set hierarchy} }\]

。

实际上，FAS 早就被扩展到 complementarity / variational inequality 问题。经典 PFAS 工作把 FAS 用于 free-boundary / complementarity problem；而 2024 年 SIAM JSC 的 FAS constraint-decomposition 方法进一步针对 nonlinear variational inequalities，并报告近似 mesh-independent convergence 与 optimal full-multigrid complexity。

这说明：

\[\boxed{ \text{FAS + inequality/contact} }\]

并不是纯理论想象，而是一条仍在发展的路线。

13. 这里其实和 IPC 又连起来了

查看完整推导与细节

IPC 每个时间步求：

\[\min_x E(x)+B_{\rm contact}(x).\]

随着网格越来越细：

\[x\in\mathbb R^{3N}\]

非线性优化规模越来越大。

如果有 nonlinear multilevel hierarchy：

\[x_h \leftrightarrow x_H,\]

理论上 coarse level 可以解决：

\[\boxed{ \text{大尺度 elastic/contact configuration} }\]

fine level 再处理：

  • 局部 barrier；
  • 细几何接触；
  • 高频 deformation。

但关键难点就在：

\[\boxed{ \text{如何让 coarse contact problem 与 fine contact feasible set 一致？} }\]

这实际上比“给 IPC 加 AMG”深很多。

它涉及：

\[\text{nonlinear coarse energy} + \text{constraint coarsening} + \text{feasibility}.\]

从研究角度看，这类问题的含金量明显高于单纯继续调 iteration count。

14. FAS 和普通 coarse-to-fine initialization 也不是一回事

很多图形学方法会做：

\[\text{先粗网格解} \rightarrow \text{插值到细网格} \rightarrow \text{再细网格解}.\]

这只发生一次。

叫：

\[\boxed{\text{nested iteration}}\]

或者 coarse-to-fine initialization。

FAS 则在每个 nonlinear solve 中反复：

\[h \downarrow H \uparrow h.\]

coarse state 不断根据 fine residual 被修改。

所以它形成：

\[\boxed{\text{双向持续反馈}}\]

而不只是：

\[\text{coarse initialization}.\]

PETSc 当前甚至把 full FAS、multiplicative FAS、additive FAS 等不同循环方式显式区分。

15. \(\tau\)-correction 还有一个更深的意义：它可以测量“粗模型到底错了什么”

查看完整推导与细节

回忆：

\[\tau_H = F_H(I_h^H u_h) - R F_h(u_h).\]

如果：

\[\tau_H\approx0,\]

说明：

\[F_H\]

对当前状态而言很好地代表了 fine operator。

如果：

\[\|\tau_H\|\gg0,\]

说明 coarse physics 与 fine physics 差异明显。

所以：

\[\boxed{ \tau }\]

不仅是算法补偿项，

还可以理解成：

\[\boxed{ \text{跨尺度模型失配量} }\]

。

这其实与 multilevel UQ / multifidelity 的 discrepancy 很像：

\[f_H-f_L.\]

只是这里 discrepancy 发生在：

\[\boxed{\text{nonlinear operator space}}\]

而不是最终 scalar response。

这个视角非常值得保留。

16. 它对多保真代理模型有一个很强的迁移启发

查看完整推导与细节

传统 multifidelity ：

\[y_H(x) = \rho y_L(x)+\delta(x).\]

即：

\[\boxed{ \text{高保真} = \text{低保真} + \text{discrepancy}. }\]

FAS：

\[\boxed{ \text{fine nonlinear problem} = \text{coarse nonlinear problem} + \tau\text{-correction}. }\]

两者结构非常相似。

区别在于 FAS 中：

\[\tau\]

不是通过统计拟合学习出来，

而是从当前 fine residual 和 coarse operator 一致性直接构造。

所以 FAS 提供一个很有价值的概念：

低保真模型最重要的不一定是绝对准确，而是它的失配是否可以被结构化地修正。

这对于代理建模也非常重要。

一个粗模型：

\[R^2=0.7\]

未必没价值。

如果其 discrepancy：

\[\delta(x)\]

非常平滑、低维、容易学习，

它仍然可能是很优秀的低保真模型。

17. 一个非常值得自研的最小实验

如果已有一个 nonlinear spring/cloth/soft-body solver，不需要直接上三维大 tet。

可以从 1D nonlinear Poisson 开始：

\[-\frac{d}{dx} \left[ (1+u^2)\frac{du}{dx} \right] = f.\]

离散得到：

\[F_h(u_h)=f_h.\]

建立：

\[N=1025\]

的 fine grid，

以及：

\[513,\ 257,\ 129,\dots\]

coarse grids。

比较三种方法：

  1. 单层 nonlinear Gauss–Seidel；
  2. Newton + linear multigrid；
  3. FAS V-cycle。

记录：

\[\|F_h(u_k)-f_h\|.\]

最重要的实验不是哪个最快，而是观察：

\[\boxed{ \text{网格从 }N=10^3\rightarrow10^5 \text{ 后，iteration count 是否增长。} }\]

如果 FAS hierarchy 设计良好，它追求的是：

\[\boxed{\text{近似 mesh-independent nonlinear convergence}}\]

。

这才是 nonlinear multigrid 真正的价值。

18. 对大型游戏物理最值得迁移的一层

查看完整推导与细节

很多实时 solver 的典型架构是：

\[\boxed{ \text{大量便宜局部迭代} }\]

例如：

  • constraint projection；
  • Jacobi；
  • Gauss–Seidel；
  • local contacts。

这种方法最大优势是：

\[\text{简单、GPU友好、随时可以停}.\]

最大弱点是：

\[\boxed{\text{全球信息传播慢。}}\]

FAS 提醒我们，未来更成熟的实时 solver 不一定要走：

\[\text{完全 Newton 化}\]

这条路。

还有另一条非常有吸引力的路线：

\[\boxed{ \text{cheap local nonlinear solver} + \text{coarse nonlinear correction} }\]

即：

\[\text{保留局部求解器的并行性}\]

同时：

\[\text{增加低频 global communication path}.\]

这正是 hierarchical physics solver 很值得研究的方向。

今天值得留下的一句话

FAS 最值得记住的并不是：

\[\tau_H = F_H(I_h^Hu_h)-RF_h(u_h).\]

真正重要的是：

\[\boxed{ \text{非线性问题中的粗层，不能只被理解成“低分辨率误差修正器”；它本身应该承载一个完整的粗尺度非线性状态。} }\]

因此可以把线性 Multigrid 与 FAS 的区别压缩成：

\[\boxed{ \text{Linear MG：coarse grid solves the error} }\]\[\boxed{ \text{FAS：coarse grid solves the solution} }\]

而 \(\tau\)-correction 负责保证：

\[\boxed{ \text{粗层看到的物理，与 fine level 当前看到的物理相容。} }\]

它在整个知识体系中的位置大约是：

\[\text{Multigrid}\]\[\downarrow\]\[\boxed{\text{FAS / Nonlinear Multigrid}}\]\[\downarrow\]\[\text{Nonlinear FEM / contact / constrained optimization}\]\[\downarrow\]\[\text{multilevel physics solver}.\]

如果以后要做真正大规模软体求解器，我会把这类方法视为比“单纯增加 XPBD iteration”更值得长期掌握的一层，因为它针对的正是大型局部迭代器最根本的瓶颈：

\[\boxed{\text{低频、全局、强非线性修正如何快速传播。}}\]

查看扩展内容

  1. Achi Brandt, Multi-Level Adaptive Solutions to Boundary-Value Problems, Mathematics of Computation, 1977。现代 multigrid/FAS 的奠基论文之一；已经讨论了多层方法对 possibly nonlinear systems 的近线性复杂度求解。

  2. Brandt & Livne, Multigrid Techniques: 1984 Guide with Applications to Fluid Dynamics，Chapter 8: Full Approximation Scheme and Applications。如果想专门理解 FAS、\(\tau\)-correction 和多层程序结构，这是很直接的经典来源。
    SIAM 章节页面

  3. PETSc SNESFAS 官方文档。非常推荐直接看一个成熟 HPC 库今天怎样暴露 nonlinear multigrid：层数、V/W-cycle、additive/multiplicative/full FAS、pre/post nonlinear smoothers 和 coarse solve 都能直接配置。
    PETSc SNESFAS

  4. Christensen, Vassilevski & Villa, Nonlinear multigrid solvers exploiting AMGe coarse spaces with approximation properties。适合继续追现代 nonlinear AMG/FAS：真正困难的是怎样在一般非结构有限元网格上构造高质量 coarse nonlinear operators。

  5. Farrell 等, A Full Approximation Scheme Multilevel Method for Nonlinear Variational Inequalities, SIAM JSC, 2024。如果想把 FAS 与 contact/complementarity 联系起来，这篇尤其值得看；它把 FAS 扩展到 nonlinear variational inequalities，并提供可复现实验代码。
