Asynchronous Variational Integrators：为什么整个有限元模型必须共用同一个时间步？

主题：Asynchronous Variational Integrators（AVI，异步变分积分器）
领域：有限元 × 软体动力学 × 数值方法 × 物理引擎
推荐阅读时间：约 8–10 分钟
今天选一个与前几天的 IPC、Anderson Acceleration、Randomized SVD 明显不同的问题：

\[\boxed{\ ext{为什么一个拥有百万个单元的动力学系统，通常必须所有单元一起走 } \Delta t？}\]

这件事我们太习惯了，以至于很少质疑它。

显式有限元通常执行：

\[t_n \rightarrow t_n+\Delta t\]

然后：

\[\boxed{\ ext{所有单元统一更新一次。}}\]

但如果一个软体里：

  • 95% 区域柔软、变化缓慢；
  • 4% 区域发生较快振动；
  • 1% 区域非常刚、需要极小稳定时间步；

整个系统的：

\[\Delta t\]

往往被最后那 1% 决定。

AVI 提出了一个很激进但自然的答案：

\[\boxed{ \ ext{每个有限元单元可以拥有自己的时间步， 甚至这些时间步不需要互为整数倍。} }\]

例如：

\[h_1=1\ ext{ ms}, \qquad h_2=1.7\ ext{ ms}, \qquad h_3=5.3\ ext{ ms}.\]

哪个单元下一次该更新，就只更新哪个单元。

这听起来像简单的 local time stepping，但真正让 AVI 特别的地方是：

\[\boxed{\ ext{这种异步更新仍然来自一个离散 Hamilton 变分原理。}}\]

因此它并非随意把不同时间步拼起来，而是在离散时空上重新构造力学系统。Lew、Marsden、Ortiz 与 West 2003 年的原始 AVI 工作证明，这种结构允许每个单元选择相互独立、甚至没有整数比例关系的局部时间步，同时精确保留局部动量以及离散 multisymplectic structure；后续数值实验也显示出很好的长期能量行为。

真正值得学的是：

\[\boxed{ \ ext{时间离散本身也可以被局部化。} }\]

1. 传统显式有限元的一个结构性浪费

考虑半离散动力学：

\[M\ddot x=-\ abla V(x),\]

其中：

\[V(x)=\sum_{e=1}^{N_e}V_e(x).\]

每个有限元单元贡献一个势能：

\[V_e.\]

显式积分的稳定时间步通常受最高频率限制：

\[\Delta t \lesssim \frac{C}{\omega_{\max}}.\]

在 FEM 中也常写成类似 CFL 条件：

\[\Delta t_e \sim \frac{h_e}{c_e},\]

其中：

  • \(h_e\)：单元尺度；
  • \(c_e\)：局部波速。

假设模型中：

\[100000\]

个单元。

其中只有一个极小单元：

\[h_{\min}=0.01h_{\rm typical}.\]

那么：

\[\Delta t_{\rm global}\]

可能直接缩小约两个数量级。

于是：

\[\boxed{ 99999\ ext{ 个本来不需要这么频繁更新的单元， 被迫陪着那个最刚/最小的单元一起计算。} }\]

这就是 AVI 要攻击的问题。

2. 最直接的想法当然是 Local Time Stepping

假设：

\[\Delta t_e\]

是单元 \(e\) 的稳定时间步。

可以自然地想：

\[\boxed{\ ext{每个 element 自己走自己的时间。}}\]

例如：

element timestep
\(e_1\) 0.1 ms
\(e_2\) 0.1 ms
\(e_3\) 1 ms
\(e_4\) 5 ms

那么 5 ms 内：

\[e_1,e_2\]

更新 50 次，

而：

\[e_4\]

只更新一次。

理论计算量可能大幅降低。

问题随之出现：

\[\boxed{\ ext{这些单元共享节点。}}\]

例如：

1

tet A ---- node i ---- tet B

如果：

\[t_A=1.3\ ext{ ms}\]

而：

\[t_B=4.7\ ext{ ms},\]

共享节点 \(i\) 到底“处于哪个时间”？

这就是 asynchronous dynamics 真正困难的地方。

3. AVI 的突破：不要先写微分方程再异步积分

普通思路是：

\[M\ddot x=f(x)\]

然后寻找一个 asynchronous ODE solver。

AVI 走了一条更底层的路线：

\[\boxed{\ ext{从 Hamilton's principle 开始离散。}}\]

连续力学的 action：

\[S[q] = \int L(q,\dot q)\,dt\]

其中：

\[L=T-V.\]

真实轨迹满足：

\[\boxed{\delta S=0.}\]

Variational Integrator 不先离散：

\[\ddot q=f(q),\]

而是先离散：

\[\boxed{\ ext{action integral}.}\]

然后要求：

\[\delta S_d=0.\]

Marsden 与 West 的经典 Acta Numerica 综述系统说明了这种 discrete mechanics 思路，并展示了 Verlet、SHAKE、RATTLE、Newmark 和 symplectic Runge–Kutta 等大量熟悉算法都可以放进离散变分框架。

这一步非常重要：

\[\boxed{ \ ext{算法的守恒结构不是事后补出来的， 而是从离散力学原理里长出来的。} }\]

4. AVI 再进一步：每个势能项拥有自己的“时钟”

因为：

\[V(x) = \sum_eV_e(x),\]

可以给每个：

\[V_e\]

单独定义更新时间：

\[t_e^0,t_e^1,t_e^2,\ldots\]

其中：

\[t_e^{j+1}-t_e^j=h_e.\]

于是整个系统不再拥有唯一：

\[t_0,t_1,t_2,\ldots\]

而拥有很多交错的 event times：

\[\boxed{ \mathcal T = \bigcup_e \{t_e^0,t_e^1,\ldots\}. }\]

例如：

1
2
3
4
5

element A: |---|---|---|---|---|
element B: |---------|---------|
element C: |-----|-----|-----|

time ------→

系统每到达一个：

\[t\in\mathcal T\]

只处理在这个时间触发的 element。

于是时间积分器本质上变成：

\[\boxed{\ ext{event-driven simulation}.}\]

6. 为什么这里会出现“impulse”？

查看完整推导与细节

如果某个 element：

\[e\]

在时刻：

\[t\]

被更新，

其势能：

\[V_e(x)\]

产生力：

\[f_e=-\ abla V_e.\]

在一个局部时间间隔：

\[h_e\]

内，它可以形成近似 impulse：

\[\boxed{ \Delta p_e = -h_e\ abla V_e(x). }\]

于是节点 momentum 更新：

\[p_i \leftarrow p_i+\Delta p_{e,i}.\]

位置则根据当前 momentum 在 event 之间漂移。

因此一个很粗略的 AVI 心智模型是：

\[\boxed{ \ ext{节点自由漂移} + \ ext{不同 element 在自己的时刻施加 impulse}. }\]

这已经足以理解它为什么能够异步。

7. 一个非常直观的例子：软体里嵌了一块高刚度材料

假设一个角色腹部软组织：

\[E=10^4\ ext{ Pa}.\]

内部有一个刚得多的骨骼附近区域：

\[E=10^8\ ext{ Pa}.\]

波速近似：

\[c\sim\sqrt{\frac{E}{\rho}}.\]

于是刚区域的：

\[c\]

可能高约：

\[100\ imes.\]

如果使用 global explicit timestep：

\[\Delta t \propto\frac{1}{c_{\max}},\]

整个软体都必须跟着骨骼附近区域使用很小：

\[\Delta t.\]

AVI 可以让：

\[h_{\rm stiff}=0.01\ ext{ ms},\]

而远处柔软区域：

\[h_{\rm soft}=1\ ext{ ms}.\]

于是：

\[\boxed{ \ ext{高频动力学只在真正产生高频动力学的地方付费。} }\]

这就是 local temporal adaptivity 的核心价值。

9. 为什么 Variational 这部分非常重要？

查看代码与实现

如果简单地：

1
2
3

tet A 用 dtA
tet B 用 dtB
然后凭经验交换力

很容易破坏：

  • momentum；
  • angular momentum；
  • energy behavior；
  • long-term stability。

Variational Integrator 的优势是：

\[\boxed{\ ext{离散 Noether theorem}.}\]

连续系统中：

\[\ ext{symmetry} \rightarrow \ ext{conserved quantity}.\]

例如空间平移对称：

\[\rightarrow \ ext{linear momentum}.\]

旋转对称：

\[\rightarrow \ ext{angular momentum}.\]

VI 在离散 action 上保留相应 symmetry 后，会自然得到离散守恒律。Marsden–West 的综述正是把 discrete variational principle 与 discrete Noether theorem 作为整个体系的核心联系。

AVI 进一步证明异步时空离散仍可以精确保留局部 momentum 和离散 multisymplectic structure。

10. 一个反直觉点：AVI 不一定严格守恒总能量

查看完整推导与细节

这值得特别强调。

Symplectic/variational integrator 的优势通常并不是：

\[E_n=E_0\]

每一步严格成立。

更典型的是：

\[\boxed{\ ext{长期能量误差保持有界并振荡。}}\]

普通积分器可能出现：

\[E_n-E_0 \sim Cn\]

长期系统性漂移。

Variational/symplectic 方法更常出现：

\[E_n-E_0\]

在一个小范围内上下摆动。

原始 AVI 论文明确指出，虽然局部 energy balance 并没有被强制精确满足，但数值实验中的全局与局部能量行为非常好；作者将这种表现与其 symplectic/variational structure 联系起来。

这和软体求解器里的一个常见误区很相关：

\[\boxed{ \ ext{“单步误差小” 并不等于 “长期动力学结构好”。} }\]

11. 这与 XPBD 有一个很有意思的对照

XPBD 的主要思想是：

\[\boxed{\ ext{把刚度编码进 constraint compliance}.}\]

解决的是：

\[\ ext{constraint stiffness dependence on } \Delta t.\]

AVI 的问题则是：

\[\boxed{\ ext{为什么所有局部物理必须共享 }\Delta t？}\]

所以二者攻击的是不同层：

\[\ ext{XPBD} \rightarrow \ ext{spatial constraint solve}\]\[\ ext{AVI} \rightarrow \ ext{temporal scheduling}.\]

理论上甚至可以想象：

\[\boxed{ \ ext{局部 constraint/element} + \ ext{local clock} }\]

这种更激进的物理引擎架构。

但它马上会遇到后面要说的 GPU 问题。

12. AVI 最大的现代工程问题：它天然不喜欢 SIMD/GPU

CPU event queue：

1
2
3

update element
push event

非常自然。

GPU 喜欢的是：

1

AVI 却不断说：

1
2
3
4
5

现在更新 element 18291

下一次 element 7

然后 element 892033

这会产生：

  • irregular memory access；
  • synchronization；
  • priority queue overhead；
  • poor occupancy；
  • dependency conflicts。

所以 AVI 的理论优势：

\[\boxed{\ ext{只计算需要更新的局部区域}}\]

会与现代硬件优势：

\[\boxed{\ ext{大量统一并行计算}}\]

发生冲突。

这是一个非常值得记住的工程规律：

\[\boxed{ \ ext{减少 FLOPs 不一定减少 wall-clock time。} }\]

13. 这个问题后来在 Asynchronous Contact Mechanics 中表现得非常明显

查看完整推导与细节

AVI 后来被用于 contact。

Harmon、Vouga、Smith、Tamstorf 与 Grinspun 2009 年提出 Asynchronous Contact Mechanics（ACM），把：

  • AVI；
  • kinetic data structures；
  • 一组嵌套 contact barrier potentials；

组合起来，希望同时保证：

\[\boxed{\ ext{无穿透、因果性、动量/能量性质以及有限时间完成。}}\]

但异步 contact 的 scheduling 很复杂。

2012 年，Ainsley、Vouga、Grinspun 与 Tamstorf 又提出 Speculative Parallel ACM。

有趣的是，他们获得了约：

\[\boxed{100\ imes}\]

的性能提升，而核心思想之一恰恰是：

不再每次微小 trajectory change 后立刻重新做碰撞调度，而是在一个时间窗口里先批量处理，再并行检测碰撞。

这样原本极难并行的算法变成了高度并行的结构。

这是一个很漂亮的例子：

\[\boxed{ \ ext{理论上最细粒度的异步， 未必是硬件上最快的异步。} }\]

15. 它和 Multi-Rate Time Integration 的关系

查看完整推导与细节

AVI 属于更大的：

\[\boxed{\ ext{multirate integration}}\]

思想。

Multirate 方法的基本目标都是：

\[\boxed{ \ ext{不同时间尺度的自由度， 不应该以同样频率更新。} }\]

但普通 multirate ODE 方法常把变量划分成：

\[y_{\rm fast}, \qquad y_{\rm slow}.\]

AVI 的特别之处是：

\[\boxed{ \ ext{时间尺度直接附着在有限元 element/potential 上。} }\]

这对 continuum mechanics 很自然：

\[V(x)=\sum_eV_e(x)\]

本来就是局部势能之和。

所以：

\[\boxed{ \ ext{空间局部性} \rightarrow \ ext{时间局部性}. }\]

这是 AVI 最漂亮的结构之一。

16. 它和有限元自适应还有一个重要对应

查看完整推导与细节

空间自适应 FEM 已经非常成熟：

高误差区域：

\[h_x\downarrow\]

网格加密。

低误差区域：

\[h_x\uparrow.\]

AVI 做的事情可以理解成：

\[\boxed{\ ext{temporal adaptivity 的局部化版本}.}\]

即：

高频区域：

\[h_t\downarrow.\]

低频区域：

\[h_t\uparrow.\]

于是完整的时空自适应实际上应该考虑：

\[\boxed{ (h_x,h_t) }\]

而不是只问：

\[\boxed{\ ext{mesh 要不要加密？}}\]

这也是原始 AVI 从 spacetime discrete variational principle 出发的重要原因之一。

17. 对可靠性分析也有一个不太显眼但很实用的迁移

查看完整推导与细节

假设做机构动态可靠性：

\[g(\ heta) = F_{\rm lim} - \max_tF(t;\ heta).\]

某些参数样本会进入：

  • 高频碰撞；
  • 高频振动；
  • near-singular configuration。

另外大量样本动力学非常平缓。

传统固定 timestep：

\[\Delta t\]

必须按照最困难情况选择。

于是：

\[\boxed{\ ext{简单样本被严重过计算。}}\]

AVI/multirate 的思想提醒我们：

\[\boxed{ \ ext{计算 fidelity 不只可以在样本之间变化， 也可以在单次仿真的时间和空间内部变化。} }\]

因此 fidelity allocation 有三个维度：

\[\boxed{ \ ext{sample} \ imes \ ext{space} \ imes \ ext{time}. }\]

这是把 multi-fidelity 思想推进到 solver 内部之后很值得思考的一步。

19. 对自研软体求解器最值得迁移的思想

我认为不应该马上去实现完整 AVI。

更有价值的是先建立一个 profiler：

对每个 tet 估计局部时间尺度：

\[\ au_e \sim \frac{h_e}{c_e}\]

或者根据：

\[\|\Delta x_e\|, \quad \|\Delta\lambda_e\|, \quad J_e, \quad \ ext{contact activity}\]

\[\ au_e.\]

\[\boxed{\ ext{local required timestep histogram}.}\]

\[8h,\]

\[1\%\]

\[h,\]

\[\boxed{ \ ext{先证明问题存在可利用的非均匀结构， 再设计利用这种结构的算法。}\]

今天值得留下的一句话

AVI 最值得记住的不是：

\[h_1\ eq h_2.\]

\[\boxed{ \ ext{全局最困难的局部区域， 没有天然权利决定整个系统的计算频率。} }\]

它在整个知识体系中的位置大致是：

\[\ ext{Hamilton's Principle}\]\[\downarrow\]\[\ ext{Variational Integrators}\]\[\downarrow\]\[\boxed{\ ext{Asynchronous Variational Integrators}}\]\[\downarrow\]\[\ ext{local temporal resolution}\]\[\downarrow\]\[\ ext{multirate FEM / asynchronous contact}.\]

而它留下的第二层工程教训甚至更重要：

\[\boxed{ \ ext{算法上的“少算”，只有和硬件上的“好算”同时成立， 才真正意味着更快。} }\]

AVI 极端强调局部计算；后来的并行 ACM 又不得不重新引入 batching 和 speculative execution 来适配并行硬件。这个历史本身就很值得求解器开发者学习：数学结构、计算复杂度和硬件执行结构，是三个必须同时设计的层次。
