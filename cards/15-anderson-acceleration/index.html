Anderson Acceleration：把“过去几次迭代为什么没收敛”变成下一步的搜索方向

主题：Anderson Acceleration（安德森加速，AA）
领域：有限元 × 计算力学 × 数值优化
推荐阅读时间：约 8 分钟

Anderson Acceleration 值得学，因为它解决的是一个极其常见、但经常被低估的问题：

\[ \boxed{\text{一个迭代器本来能收敛，只是收敛得太慢。}} \]

很多求解器都可以写成固定点形式：

\[ x_{k+1}=G(x_k). \]

例如：

  • Picard iteration；
  • local-global Projective Dynamics；
  • 某些 PBD/Jacobi 迭代；
  • nonlinear FEM splitting；
  • ADMM；
  • 多物理场 staggered coupling。

普通固定点迭代每一步只利用当前状态：

\[ x_k\rightarrow G(x_k). \]

Anderson Acceleration 多问了一件事：

过去几次迭代的残差是怎么变化的？能不能据此推测哪种线性组合会更快逼近固定点？

它只保存很短的一段迭代历史，并解一个小型 least-squares problem，却常能显著减少昂贵的外层迭代次数。Walker 与 Ni 的经典分析还证明：在线性问题上，不截断历史的 Anderson acceleration 与 GMRES 在一定意义下“本质等价”；同时它也和 multisecant quasi-Newton 方法存在深刻联系。

1. 固定点求解器到底在干什么？

假设要求解：

\[ F(x)=0. \]

你构造一个容易计算的映射：

\[ G(x), \]

使真正答案满足：

\[ x^*=G(x^*). \]

然后迭代：

\[ x_{k+1}=G(x_k). \]

定义 fixed-point residual：

\[ \boxed{ r_k=G(x_k)-x_k. } \]

如果：

\[ r_k=0, \]

那么：

\[ G(x_k)=x_k, \]

问题解决。

所以固定点迭代实际上是在反复做：

\[ x_{k+1}=x_k+r_k. \]

这非常便宜。

问题是，如果：

\[ G'(x^*) \]

的谱半径接近 1：

\[ \rho(G')\lesssim1, \]

那么误差：

\[ e_{k+1}\approx G'(x^*)e_k \]

每一步只减少一点。

例如：

\[ \|e_{k+1}\|=0.95\|e_k\|. \]

100 次以后还有：

\[ 0.95^{100}\approx0.006. \]

对于一个每次迭代都要做：

  • constraint projection；
  • sparse solve；
  • collision；
  • constitutive update

的物理求解器，这已经很贵。

2. Anderson 的核心：残差历史其实包含了局部 Jacobian 信息

现在假设已经得到：

\[ x_{k-m},\ldots,x_k. \]

同时有：

\[ r_{k-m},\ldots,r_k. \]

如果残差从：

\[ r_{k-1} \]

变成：

\[ r_k, \]

那么：

\[ \Delta r_k=r_k-r_{k-1}. \]

而状态变化：

\[ \Delta x_k=x_k-x_{k-1}. \]

局部线性化下：

\[ \Delta r \approx J_r\,\Delta x. \]

于是每一组：

\[ (\Delta x,\Delta r) \]

其实都在告诉你：

\[ \boxed{ \text{未知 residual Jacobian 在某个方向上大概是什么样子。} } \]

Newton 法会直接计算：

\[ J_r. \]

Anderson 不计算它。

它从最近几步：

\[ \Delta x_1,\Delta r_1,\dots \]

反推局部行为。

这就是它与：

\[ \boxed{\text{quasi-Newton / multisecant}} \]

联系起来的原因。Walker–Ni 对这一关系进行了系统讨论，并引用 Fang–Saad 的 multisecant 解释。

3. 算法核心其实只是一个很小的最小二乘

定义最近 \(m\) 次 residual difference：

\[ \Delta R_k= [ \Delta r_{k-m+1},\ldots,\Delta r_k ] \]

以及：

\[ \Delta X_k= [ \Delta x_{k-m+1},\ldots,\Delta x_k ]. \]

先解：

[ \boxed{ \gamma

\arg\min_\gamma | r_k-\Delta R_k\gamma |_2 } ]

意思是：

能不能用过去残差变化的线性组合，尽可能解释当前 residual？

然后使用一种常见 AA 更新：

[ \boxed{ x_{k+1}

x_k+r_k

(\Delta X_k+\Delta R_k)\gamma. } ]

普通 fixed-point：

\[ x_{k+1}=x_k+r_k. \]

AA 则额外增加：

\[ -(\Delta X+\Delta R)\gamma. \]

也就是：

\[ \boxed{ \text{利用历史信息修正当前 fixed-point direction。} } \]

而这个 least-squares 的维度只有：

\[ m. \]

实践中：

\[ m=3\sim10 \]

就很常见。

所以即使：

\[ x\in\mathbb R^{10^6}, \]

真正新增的核心优化问题可能只是一个：

\[ 5\times5 \]

级别的小问题。

假设你在二维状态空间里迭代：

每一次 fixed-point map 都在纠正误差，但两个方向的收缩速度不同，于是出现：

\[ \boxed{\text{zig-zag}} \]

过去几次 residual：

\[ r_{k-2},r_{k-1},r_k \]

已经透露出：

“我每次都在这两个方向之间来回过度修正。”

Anderson 做的事情近似是：

\[ \boxed{ \text{寻找这些历史更新的一个组合，使预测 residual 最小。} } \]

实际上在线性 fixed-point 问题上，Walker 与 Ni 证明了无截断 AA 与 GMRES 存在本质等价关系。

5. 为什么这个 GMRES 联系这么重要？

考虑线性系统：

\[ Ax=b. \]

Jacobi / Richardson 一类迭代可以写成：

\[ x_{k+1}=Gx_k+c. \]

普通 fixed-point 每次只能：

\[ e_{k+1}=Ge_k. \]

因此误差方向受到：

\[ G^k e_0 \]

控制。

GMRES 则在 Krylov 子空间：

[ \mathcal K_m

\operatorname{span} { r_0,Ar_0,A^2r_0,\dots } ]

中寻找最小 residual 的解。

Anderson 虽然没显式建立 Krylov basis，却通过：

\[ \boxed{\text{历史 residual 的线性组合}} \]

实现了类似的 residual minimization。

因此可以把它粗略理解成：

\[ \boxed{ \text{nonlinear fixed-point iteration 上的“轻量 Krylov 化”。} } \]

这个理解比“给迭代加个 momentum”更接近它的数值本质。

6. 它为什么特别适合 Projective Dynamics / local-global solver？

回忆 PD：

\[ x_k \xrightarrow{\text{local}} p_k \xrightarrow{\text{global}} x_{k+1}. \]

整个 local-global iteration 可以视为：

\[ \boxed{ x_{k+1}=G(x_k). } \]

PD 的优势：

  • 每次 iteration 很便宜；
  • 固定 global matrix 可预分解；
  • 稳定；

但缺点之一是：

\[ \boxed{\text{高精度收敛阶段可能很慢。}} \]

2018 年 Peng 等在 ACM TOG/SIGGRAPH 工作中，直接把每个 local-global step 当作固定点映射，用 Anderson acceleration 加速 geometry optimization 和 physics simulation；论文报告，AA 能显著减少达到高精度所需的迭代次数，而单次迭代只增加很小额外成本。

这正好解释为什么 AA 和 PD 很般配：

\[ \boxed{ \text{PD 提供一个便宜但线性收敛的 }G(x) } \]\[ + \]\[ \boxed{ \text{AA 用历史信息提高这个 }G\text{ 的有效收敛速度} } \]

而不必把整个 solver 改写成 Newton FEM。

7. 这对 PBD/XPBD 有什么潜在意义？

如果一个 constraint solve 是：

[ x^{(k+1)}

G(x^{(k)}), ]

那么原则上也可以做 AA。

例如 GPU Jacobi PBD：

\[ x^{k} \rightarrow \text{all constraint corrections} \rightarrow x^{k+1}. \]

如果 stiff material 下需要：

\[ 30\sim100 \]

轮 Jacobi 才足够硬，AA 可以尝试用最近几轮的位置/residual 历史提高收敛。

2019 年一项面向交互式软体的工作就将 Anderson acceleration 加入 PBD/Jacobi 框架，以改善 stiff material 的收敛，同时使用 graph coloring 等方法实现 GPU 实时计算。

不过这里有一个重要条件：

\[ \boxed{ \text{最好加速“完整一轮 solver map”， 而不是随便加速单个 constraint correction。} } \]

因为 AA 假设你有一个相对稳定的：

\[ G:x\mapsto x'. \]

如果 Gauss-Seidel 顺序、active contact set、clamp 状态每次剧烈变化，那么：

\[ G \]

本身就在跳变，历史信息就可能失去意义。

8. 为什么 Anderson 有时反而会把 solver 搞炸？

这是它最需要警惕的地方。

普通 fixed-point 假设：

\[ G(x_k) \]

本身有某种稳定性。

Anderson 却做：

\[ \boxed{\text{extrapolation}} \]

也就是说：

\[ x_{k+1} \]

可能落在历史状态的凸包之外。

如果非线性很强，例如：

  • contact active set 改变；
  • tet 接近 inversion；
  • friction stick/slip 切换；
  • barrier 快速变陡；

历史线性模型可能完全失效。

于是：

\[ \gamma \]

可能非常大，

导致：

\[ \|x_{k+1}-x_k\|\gg1. \]

这也是为什么 graphics 中真正实用的 AA 往往需要：

\[ \boxed{\text{safeguard}} \]

Peng 等 2018 年的方法并没有盲目接受 AA step，而是加入目标能量下降判据，从而解决经典 AA 的稳定性问题并保证其 local-global 框架的全局收敛性质。

9. 一个非常重要的工程原则：AA 应该是“加速器”，不是“基础稳定器”

假设原始 iteration：

\[ x_{k+1}=G(x_k) \]

本身会发散：

\[ \rho(G')>1. \]

不要期待 AA 一定把它救回来。

它有时确实能扩大实际收敛区，但工程上更合理的顺序仍然是：

\[ \boxed{ \text{先有一个靠谱的 baseline iteration} } \]

然后：

\[ \boxed{ \text{再用 Anderson 降低 iteration count。} } \]

也就是说，如果 XPBD 出现：

  • 四面体反转；
  • NaN；
  • contact explosion；
  • compliance 定义错误；

AA 几乎肯定不是第一治疗手段。

它解决的是：

\[ \boxed{\text{slow convergence}} \]

而不是：

\[ \boxed{\text{wrong formulation}}. \]

这一区分很重要。

10. History length \(m\) 为什么不能无限加？

乍看：

\[ m\uparrow \]

拥有更多信息，似乎越好。

但 residual differences：

\[ \Delta r_i \]

可能逐渐变得近似线性相关。

于是 least-squares matrix：

\[ \Delta R \]

条件数：

\[ \kappa(\Delta R)\uparrow. \]

此时：

\[ \gamma \]

会非常敏感。

同时：

  • 内存增加；
  • dot product/reduction 增加；
  • 旧历史越来越不代表当前局部非线性。

因此 practical AA 通常只保存：

\[ \boxed{m\approx3\sim10} \]

步历史，并可能：

  • restart；
  • regularize；
  • 删除近线性相关方向；
  • 对 \(\gamma\) 加限制。

近年的理论工作也仍在研究 restarted AA 的收敛性质，说明“历史到底保留多少”并不是已经完全解决的问题。

11. 它和 Newton 的真正关系在哪里？

Newton：

[ x_{k+1}

x_k

J_r(x_k)^{-1}r_k. ]

优点：

\[ \boxed{\text{利用完整局部导数}} \]

缺点：

\[ J_r \]

可能：

  • 很贵；
  • 难推；
  • 难 assemble；
  • 难 factorize。

Anderson 近似在做：

[ x_{k+1}

x_k

H_k r_k, ]

其中：

\[ H_k \]

不是显式构造的完整矩阵，而是通过历史：

\[ (\Delta x_i,\Delta r_i) \]

满足若干 secant conditions。

所以可以把三类方法排成：

\[ \boxed{ \text{Fixed point} } \]

几乎不利用导数信息；

\[ \boxed{ \text{Anderson / multisecant} } \]

从历史中低成本推断部分 Jacobian 信息；

\[ \boxed{ \text{Newton} } \]

显式使用完整 Jacobian/Hessian。

AA 正好卡在两者中间。

这也是它特别适合实时求解器的原因之一。

12. 一个很有价值的类比：AA 是“solver 的短期记忆”

普通迭代是：

\[ \boxed{\text{memoryless}} \]

每一步只看：

\[ x_k. \]

Anderson 有：

\[ \boxed{\text{short-term memory}} \]

它记住：

\[ (x_{k-j},r_{k-j}). \]

这些历史不是用来“平均答案”，而是用来估计：

\[ \boxed{ \text{当前 nonlinear map 的局部响应结构。} } \]

所以 AA 揭示了一个很普遍的设计原则：

如果求解器每轮都产生昂贵的信息，不要在下一轮全部丢掉。

这一原则会再次出现在：

  • BFGS/L-BFGS；
  • Krylov subspace；
  • warm starting；
  • contact impulse caching；
  • temporal coherence；
  • recurrent optimization。

13. 对接触问题为什么要更谨慎？

假设：

\[ G(x) \]

中包含 contact projection。

上一轮：

\[ \text{contact A active} \]

下一轮：

\[ \text{contact A inactive}, \quad \text{contact B active}. \]

那么 residual map 可能是非光滑的。

经典 AA 理论最舒服的场景还是：

\[ G \]

足够平滑、局部 contractive。

不过后续研究已经把理论推进到某些 nonsmooth fixed-point 问题，并证明在“平滑 contraction + Lipschitz 较小的 nonsmooth component”等条件下仍能建立收敛结果。

但对物理引擎而言，这仍然意味着：

\[ \boxed{ \text{contact-heavy iteration 应配合 restart / safeguard。} } \]

例如检测：

\[ \text{active set 大幅变化} \]

时直接清空 AA history，通常是很合理的工程策略。

这种结构非常吸引人，因为 AA 可以成为：

\[ \boxed{\text{solver wrapper}} \]

而不是侵入：

  • constraint kernel；
  • FEM constitutive law；
  • GPU collision kernel；

内部。

这正是 Peng 等强调它适合加速已有 iterative algorithms 的原因之一。

15. 对 XPBD/PD 求解器最值得做的实验

如果要判断 AA 是否值得加入，不要一开始看 FPS。

先选一个没有碰撞、没有塑性、确定能收敛的 stiff soft-body case。

记录：

\[ \|r_k\| \]

随 iteration：

\[ k \]

的变化。

比较：

\[ \text{baseline} \]

与：

\[ m=2,\ 4,\ 6 \]

的 AA。

最值得看的不是：

\[ \text{最终形状} \]

而是：

\[ \log\|r_k\| \]

曲线。

如果 baseline：

\[ \|r_{k+1}\|\approx0.92\|r_k\|, \]

而 AA 很快变成明显更陡的下降曲线，就说明：

\[ \boxed{\text{问题主要是 fixed-point convergence rate。}} \]

如果 residual 本来就在：

\[ \text{oscillate / diverge / NaN}, \]

那么应该先修 formulation。

今天值得留下的一句话

Anderson Acceleration 最值得记住的不是那个 least-squares 公式，而是：

\[ \boxed{ \text{迭代历史本身就是对未知 Jacobian 的观测数据。} } \]

普通 fixed-point solver 每轮算完：

\[ x_k\rightarrow x_{k+1} \]

以后，把之前的信息全部扔掉。

AA 则利用最近几轮：

\[ \Delta x,\Delta r \]

构造一个非常廉价的局部模型。

所以它在整个知识体系中的位置非常漂亮：

\[ \text{Fixed-point / PBD / PD} \]\[ \downarrow \]\[ \boxed{\text{Anderson / multisecant acceleration}} \]\[ \downarrow \]\[ \text{quasi-Newton} \]\[ \downarrow \]\[ \text{full Newton / Newton-Krylov}. \]

对于实时物理求解器而言，这条路线尤其值得学，因为它代表一种非常实用的工程哲学：

\[ \boxed{ \text{如果单次迭代已经足够便宜和鲁棒， 优先想办法让它少迭代几次， 而不一定要把整个 solver 换成更昂贵的方法。} } \]
