Schur 补与静态凝聚：真正高效的大型求解器，经常不是“更快地解全部未知量”，而是先把不重要的自由度消掉

Schur 补与静态凝聚：真正高效的大型求解器，经常不是“更快地解全部未知量”，而是先把不重要的自由度消掉

主题：Schur Complement（Schur 补）与 Static Condensation（静态凝聚）
领域：有限元 × 数值方法 × 数值优化 × 流体
推荐阅读时间：约 8–10 分钟
今天选 Schur 补，因为它代表了一种非常核心、但容易被低估的求解器思想：

\[\boxed{ \ ext{一个大系统里的不同未知量，并不一定值得被同等对待。} }\]

很多有限元、多物理场和约束问题最终都会得到块矩阵：

\[\begin{bmatrix} A & B\\ C & D \end{bmatrix} \begin{bmatrix} x\\ y \end{bmatrix} = \begin{bmatrix} f\\ g \end{bmatrix}.\]

Schur 补做的事情很直接：

如果 \(x\) 相对容易求，那么先把 \(x\) 消掉，只留下一个关于 \(y\) 的有效系统。

得到：

\[\boxed{ S=D-CA^{-1}B }\]

这就是 Schur complement。

看起来只是一条线性代数公式，但它实际上同时出现在：

  • 高阶有限元的 static condensation；
  • FETI/BDDC 等 domain decomposition；
  • Stokes/Navier–Stokes pressure solve；
  • incompressibility；
  • contact multiplier systems；
  • 多物理场 block preconditioning；
  • hybridized FEM；
  • 图优化和高斯消元。

PETSc 当前的 PCFIELDSPLIT 就直接把 Schur factorization 作为块系统的核心求解/预处理方式，并允许为 Schur complement 单独配置求解器和近似预条件器。

真正值得学的不是公式本身，而是：

\[\boxed{ \ ext{消元以后，剩下的变量究竟代表了什么“有效物理”。} }\]

1. Schur 补其实就是一次精确消元

从：

\[Ax+By=f\]\[Cx+Dy=g\]

开始。

假设 \(A\) 可逆。

第一式：

\[x=A^{-1}(f-By).\]

代入第二式：

\[CA^{-1}(f-By)+Dy=g.\]

整理：

\[\boxed{ (D-CA^{-1}B)y = g-CA^{-1}f. }\]

所以：

\[S=D-CA^{-1}B.\]

先解：

\[Sy=\ ilde g,\]

然后回代：

\[x=A^{-1}(f-By).\]

这并不是近似。

如果 \(A^{-1}\) 精确计算，Schur 系统与原系统：

\[\boxed{\ ext{数学上完全等价。}}\]

因此 Schur 补的本质不是“降阶模型”。

而是：

\[\boxed{\ ext{通过变量消元重新组织同一个问题。}}\]

2. 为什么消掉变量以后，系统反而可能更难？

这里有个很重要的反直觉点。

原矩阵可能很稀疏：

1
2

A B
C D

但：

\[CA^{-1}B\]

通常是稠密的。

因为：

\[A^{-1}\]

一般不是稀疏矩阵。

所以 Schur complement：

\[S\]

经常比原来的 \(D\) 更“全局”。

这不是坏事，而是它的物理含义：

\[\boxed{ \ ext{被消掉的局部自由度，通过 }A^{-1}\ ext{ 把远处变量耦合起来了。} }\]

也就是说，Schur complement 其实是一种：

\[\boxed{\ ext{effective interaction operator}}\]

。

被消掉的变量虽然不再显式出现，但它们的影响全部被编码进：

\[S.\]

3. 一个非常直观的弹簧例子

考虑三个节点：

1
2

boundary —— interior —— boundary
   x1          xi           x2

中间节点没有外部兴趣，只承担弹簧传力。

完整系统写成：

\[\begin{bmatrix} K_{ii} & K_{ib}\\ K_{bi} & K_{bb} \end{bmatrix} \begin{bmatrix} u_i\\ u_b \end{bmatrix} = \begin{bmatrix} f_i\\ f_b \end{bmatrix}.\]

消掉内部位移：

\[u_i = K_{ii}^{-1} (f_i-K_{ib}u_b).\]

边界系统变成：

\[\boxed{ S_bu_b = f_b-K_{bi}K_{ii}^{-1}f_i }\]

其中：

\[S_b = K_{bb} - K_{bi}K_{ii}^{-1}K_{ib}.\]

从外面看，这个含内部自由度的弹簧结构被替换成了：

\[\boxed{\ ext{边界节点之间的等效刚度}}\]

。

内部节点消失了，

但它们对端点关系的所有影响仍然存在。

这就是 Schur complement 最好的物理直觉：

\[\boxed{ \ ext{把内部物理“压缩”成边界上的等效响应。} }\]

4. Static Condensation 就是有限元里的 Schur 补

这在高阶有限元中特别重要。

一个高阶单元内部可能有很多 DOF：

1
2
3
4
5
6

┌──────────────┐
│ · · · · · ·  │
│ · interior · │
│ · · · · · ·  │
└──────────────┘
boundary DOFs

其中一部分自由度只属于当前 element：

\[u_I.\]

另一部分位于：

  • edge；
  • face；
  • vertex；

需要和邻居共享：

\[u_\Gamma.\]

于是单元矩阵可以写：

\[\begin{bmatrix} K_{II} & K_{I\Gamma}\\ K_{\Gamma I} & K_{\Gamma\Gamma} \end{bmatrix}.\]

关键来了：

\[K_{II}\]

只对应单元内部 DOF。

所以不同单元的内部块互相不直接耦合。

这意味着：

\[\boxed{ K_{II}^{-1} }\]

可以完全在每个 element 内局部计算。

然后只组装：

\[\boxed{ S_\Gamma = K_{\Gamma\Gamma} - K_{\Gamma I}K_{II}^{-1}K_{I\Gamma}. }\]

MFEM 官方 StaticCondensation 正是这么定义的：先消去 element-interior DOFs，只构造并求解 interface DOFs 的 Schur system，之后再局部恢复内部未知量。

5. 为什么高阶 FEM 尤其喜欢 static condensation？

假设三维 \(p\)-order element。

单元内部 DOF 数大致会快速随：

\[p\]

增长。

但真正跨 element 通信的只是在：

\[\boxed{\ ext{faces / edges}}\]

上的自由度。

如果把所有 interior DOFs 都直接放进 global solve：

\[N_{\rm global}\]

会非常大。

Static condensation 让：

\[\boxed{ \ ext{大量局部未知量永远不进入全局 Krylov system。} }\]

于是问题变成：

1
2
3
4
5
6
7
8

local work:
    element interior solve
        ↓
global work:
    interface solve
        ↓
local work:
    recover interior

这和 HPC 中一个非常普遍的原则完全一致：

\[\boxed{ \ ext{尽量把计算留在本地，把真正需要全局通信的部分压到最小。} }\]

所以 static condensation 不只是减少 DOF。

它减少的是：

\[\boxed{\ ext{global coupling dimension}.}\]

这在并行求解里往往比单纯减少 FLOPs 更重要。

6. “内部变量”与“接口变量”的分离，其实就是 domain decomposition 的核心

假设把一个大有限元区域切成：

\[\Omega_1,\Omega_2,\ldots,\Omega_m.\]

每个子域有：

  • interior DOFs；
  • interface DOFs。

对子域内部自由度全部消元后，

整个 PDE 问题变成：

\[\boxed{ S_\Gamma u_\Gamma=f_\Gamma }\]

只存在于子域边界上。

这就是经典 substructuring 思路。

Toselli 与 Widlund 的 domain decomposition 专著把这类 Schur complement/substructuring formulation 作为 FETI、BDD/BDDC 等非重叠域分解方法的重要基础：每个子域内部可以局部求解，全局问题主要转化为接口自由度协调。

所以可以把两种方法看成同一个思想在不同尺度的应用：

\[\boxed{ \ ext{element-level elimination} \rightarrow \ ext{static condensation} }\]\[\boxed{ \ ext{subdomain-level elimination} \rightarrow \ ext{substructuring / domain decomposition} }\]

。

7. 这解释了一个很深的求解器原则：全局问题本质上是“接口协调问题”

很多 PDE 在每一个局部区域内部其实都很好解。

真正困难的是：

\[\boxed{\ ext{不同区域怎么彼此一致。}}\]

例如：

  • 位移连续；
  • traction 平衡；
  • 压力/速度协调；
  • 接触界面；
  • 多物理变量耦合。

Schur complement 把内部变量全部消去以后，

剩下的往往恰恰就是：

\[\boxed{\ ext{这些全局协调变量。}}\]

所以一个很有价值的观察是：

大规模 PDE 求解器的真正核心，有时不是解每个局部 PDE，而是高效解决接口上的协调问题。

这正是 domain decomposition 为什么如此适合大规模并行计算。

8. Schur 补在不可压流体里又变成了什么？

考虑 Stokes：

\[-\mu\ abla^2u+\ abla p=f\]\[\ abla\cdot u=0.\]

离散后常得到 saddle-point system：

\[\begin{bmatrix} A & B^T\\ B & 0 \end{bmatrix} \begin{bmatrix} u\\ p \end{bmatrix} = \begin{bmatrix} f\\ 0 \end{bmatrix}.\]

消掉速度：

\[u = A^{-1}(f-B^Tp).\]

代入 incompressibility：

\[BA^{-1}(f-B^Tp)=0.\]

于是压力满足：

\[\boxed{ -BA^{-1}B^Tp = -BA^{-1}f. }\]

所以 pressure Schur complement：

\[\boxed{ S_p=-BA^{-1}B^T. }\]

它代表：

一个压力场通过动量方程激发速度，再通过散度方程反馈出的有效作用。

这就是为什么 incompressible solver 中：

\[\boxed{\ ext{pressure solve}}\]

如此核心。

PETSc 当前专门为 saddle-point/field-split 系统提供 Schur-complement preconditioning；例如其 LSC preconditioner 就针对这类 Schur 系统，并指出在 incompressible flow 中相关 \(A_{10}A_{01}\) 结构对应 Laplacian 型算子。

9. 所以 projection method 和 Schur complement 其实很近

在流体里常见：

  1. 先算 provisional velocity；
  2. 解 pressure Poisson；
  3. pressure correction；
  4. 得到 divergence-free velocity。

从线性代数角度看，

pressure projection 很大程度上就是在近似处理：

\[\boxed{ BA^{-1}B^T }\]

这一 pressure Schur complement。

所以很多“物理算法”和“块矩阵求解器”其实只是：

\[\boxed{\ ext{同一结构的不同表达。}}\]

这个联系非常值得记住。

10. 接触和约束问题里也会出现同样结构

考虑约束动力学：

\[M\Delta v = f+J^T\lambda\]

以及速度约束：

\[J(v+\Delta v)=b.\]

消掉：

\[\Delta v = M^{-1}(f+J^T\lambda).\]

代入：

\[JM^{-1}(f+J^T\lambda)=b.\]

于是：

\[\boxed{ JM^{-1}J^T\lambda = b-JM^{-1}f. }\]

这里：

\[\boxed{ W=JM^{-1}J^T }\]

就是约束空间里的 Schur complement。

在刚体物理里它经常叫：

\[\boxed{\ ext{Delassus operator}}\]

或有效质量矩阵。

这条公式非常重要：

\[W = JM^{-1}J^T.\]

它回答：

给约束施加一个单位 impulse，约束速度会改变多少？

于是可以直接看出：

\[\boxed{ \ ext{LCP / contact solver 实际是在 constraint space 中求 Schur system。} }\]

这和有限元 static condensation 竟然是同一个数学母结构。

11. 一个销轴—孔接触的直观理解

查看完整推导与细节

假设整个柔性机构有：

\[10^6\]

个 displacement DOFs。

但当前真正 active contacts 只有：

\[100.\]

理论上你可能希望：

  1. 消掉结构内部位移响应；
  2. 只在 100 个 contact constraints 上求 contact forces；
  3. 再恢复结构 displacement。

得到：

\[S_c\lambda=b.\]

其中：

\[S_c\]

编码：

\[\boxed{ \ ext{一个接触点施力以后，所有其他接触点会发生多大位移响应。} }\]

这其实就是：

\[\boxed{\ ext{interface compliance matrix}}\]

。

所以 Schur complement 有一个特别清晰的物理解释：

\[\boxed{ \ ext{它把整个内部结构压缩成边界/接触点之间的等效柔度或刚度关系。} }\]

这也是 boundary element、substructuring、component mode synthesis 等方法背后共有的思维之一。

12. 但为什么实际中通常不显式形成 \(S\)？

因为：

\[S=D-CA^{-1}B.\]

如果真的计算：

\[A^{-1}\]

通常非常贵。

更糟的是：

\[S\]

可能非常稠密。

所以大型系统里通常不会：

1
2

compute inv(A)
form S explicitly

而是实现：

\[y\mapsto Sy.\]

也就是：

1
2
3
4
5
6
7

given y:

    t = B y

    solve A z = t

    result = D y - C z

因此：

\[\boxed{ \ ext{应用一次 Schur operator} }\]

内部实际上包含一次：

\[A^{-1}\]

子问题求解。

这就是所谓：

\[\boxed{\ ext{matrix-free Schur complement}}\]

思想。

PETSc 的 Schur machinery 也支持符号 Schur operator，而不是要求始终显式组装完整 Schur matrix。

13. 于是新的问题出现：Schur complement 本身怎么预条件？

查看完整推导与细节

这是真正的工程核心。

如果：

\[S\]

很难解，

只是把原问题改写成 Schur system 并没有魔法般解决它。

所以实际方法通常寻找：

\[\boxed{ \hat S\approx S }\]

且：

\[\hat S^{-1}\]

便宜。

例如 PETSc 允许：

  • 使用 \(A_{11}\)；
  • 使用用户提供的 approximation；
  • 使用 symbolic Schur；
  • 用 \[A_{11}-A_{10}\operatorname{diag}(A_{00})^{-1}A_{01}\] 这样的显式近似；
  • 对 saddle-point 系统使用 LSC 等专门预条件器。

这揭示了一个很重要的现实：

\[\boxed{ \ ext{Schur complement 的威力，通常来自“好的近似”，而不是显式精确构造。} }\]

14. 为什么这又和前面讲过的 Multigrid 不重复？

。

Schur complement 解决的是：

\[\boxed{\ ext{不同变量/拓扑角色的耦合}}\]

。

所以它们经常组合，而不是互相替代。

15. 它和 Hyper-reduction 也有一个很重要的区别

查看完整推导与细节

上一期 Hyper-reduction：

\[u\approx Vq\]

会产生：

\[\boxed{\ ext{近似模型}}\]

。

Schur elimination：

\[S=D-CA^{-1}B\]

如果精确执行，则：

\[\boxed{\ ext{不损失任何信息。}}\]

所以：

Model reduction

减少：

\[\boxed{\ ext{物理状态空间}}\]

可能引入 approximation error。

Schur reduction

减少：

\[\boxed{\ ext{显式未知量}}\]

但被消掉的信息以 effective operator 形式保留。

这是“降维”这个词下两种完全不同的数学操作。

16. 对软体物理引擎，最值得迁移的不是公式，而是“local solve + interface solve”架构

假设一个软体由多个区域组成：

1

[soft body A] — interface — [soft body B]

每块内部可能有：

\[10^5\]

个 DOF。

但接口只有：

\[10^3.\]

一种思路是全局一起跑：

\[201000\]

自由度的大迭代。

另一种是：

\[\boxed{ \ ext{每个 body 内部局部求解} + \ ext{只在 interface 上协调} }\]

。

这特别适合：

  • destructible objects；
  • component-based deformables；
  • soft-rigid coupling；
  • distributed simulation；
  • multi-GPU physics。

从系统角度：

\[\boxed{ \ ext{Schur complement 把“局部计算”和“全局通信”分开。} }\]

这和 GPU/分布式求解器的硬件结构非常契合。

17. 对组件级数字样机，它还有一个很现实的价值

查看完整推导与细节

假设一台机构有：

  • 杆件；
  • 支座；
  • 耳片；
  • 销轴区域；
  • 柔性壳体。

你可能不需要在整个系统装配以后仍保留每个组件的所有内部自由度。

可以先为组件构造：

\[\boxed{\ ext{boundary/interface operator}}\]

然后系统级只耦合：

  • 接口位移；
  • 接口力；
  • 连接 DOFs。

这正是 substructuring 与 component reduction 思想的自然基础。

如果以后要做：

\[\boxed{\ ext{模块化高保真数字样机}}\]

Schur complement 几乎是绕不开的数学语言。

18. 对代理模型也有一个非常值得迁移的启发

查看完整推导与细节

通常我们想直接代理：

\[x\rightarrow y.\]

但如果复杂系统天然由：

\[\ ext{internal state} + \ ext{interface state}\]

组成，

可能更好的学习目标是：

\[\boxed{ \ ext{interface input} \rightarrow \ ext{interface response} }\]

也就是学习一个近似：

\[\boxed{\hat S}\]

。

例如：

\[\ ext{边界位移} \rightarrow \ ext{边界力}.\]

这是一种：

\[\boxed{\ ext{learned Schur operator}}\]

。

它相比直接学习整个内部 displacement field 有几个天然优势：

  • 输出维数更小；
  • 与模块耦合直接兼容；
  • 可替换一个昂贵子结构；
  • 内部细节可以隐藏。

这其实是非常自然的 physics-module surrogate。

19. 一个非常值得自己实现的最小实验

查看代码与实现

做一个二维 Poisson FEM。

把 mesh 中 DOF 分成：

\[u_I\]

内部节点，

和：

\[u_\Gamma\]

边界/接口节点。

原系统：

\[\begin{bmatrix} K_{II} & K_{I\Gamma}\\ K_{\Gamma I} & K_{\Gamma\Gamma} \end{bmatrix} \begin{bmatrix} u_I\\ u_\Gamma \end{bmatrix} = \begin{bmatrix} f_I\\ f_\Gamma \end{bmatrix}.\]

实现：

\[S= K_{\Gamma\Gamma} - K_{\Gamma I} K_{II}^{-1} K_{I\Gamma}.\]

然后：

  1. 直接解原系统；
  2. 解 Schur system；
  3. 回代内部自由度。

比较：

\[\|u_{\rm full}-u_{\rm Schur}\|.\]

应该接近机器误差。

然后不要显式计算：

\[K_{II}^{-1}.\]

改为：

1
2
3

function apply_S(x):
    z = solve(K_II, K_IΓ x)
    return K_ΓΓ x - K_ΓI z

这一步一旦实现，你就真正跨过了：

\[\boxed{ \ ext{“知道 Schur 补公式” \rightarrow “理解大型求解器怎么用它”} }\]

这条线。

20. 一个尤其值得保留的诊断视角

以后遇到块系统：

\[\begin{bmatrix} A & B\\ C & D \end{bmatrix},\]

第一反应可以不只是：

用 GMRES 还是 CG？

而先问：

\[\boxed{ \ ext{哪些变量局部、便宜、适合消掉？} }\]

以及：

\[\boxed{ \ ext{哪些变量真正承担全局耦合？} }\]

如果找到后者，

它们往往正是最值得构造 Schur complement 的变量。

这个问题比单纯选 Krylov solver 更接近系统结构。

今天值得留下的一句话

Schur complement 最值得记住的不是：

\[S=D-CA^{-1}B.\]

而是：

\[\boxed{ \ ext{被消掉的自由度并没有消失； 它们被压缩成了剩余自由度之间的有效耦合。} }\]

所以它在知识体系里的位置可以理解成：

\[\ ext{Full coupled system}\]\[\downarrow\]\[\boxed{\ ext{eliminate local/internal variables}}\]\[\downarrow\]\[\boxed{\ ext{effective interface operator / Schur complement}}\]\[\downarrow\]\[\ ext{interface solve + local recovery}.\]

而从工程角度看，它教会我们的一个极其重要的原则是：

\[\boxed{ \ ext{真正昂贵的不是系统里有多少变量， 而是多少变量必须参与全局协调。} }\]

Static condensation、domain decomposition、pressure projection、constraint-space contact solve 看起来属于完全不同的领域，但它们背后实际上都在利用同一个结构：

\[\boxed{ \ ext{先解决局部响应， 再集中解决少量全局耦合变量。} }\]

一旦看懂这一点，很多大型物理求解器的架构会突然变得非常统一。

  1. Toselli & Widlund, Domain Decomposition Methods — Algorithms and Theory, Springer, 2005。理解 substructuring、interface Schur complement、FETI/BDDC 等方法最经典的系统资料之一。
    Springer 图书页

  2. MFEM StaticCondensation 官方文档。非常推荐直接对着公式和代码看：element-interior DOFs 如何被局部消元，Schur system 如何只保留 element-boundary DOFs，以及最终如何恢复内部解。
    MFEM StaticCondensation

  3. PETSc PCFIELDSPLIT / Schur complement 文档。这是观察 Schur 思想如何进入工业级 HPC solver 的很好入口；尤其值得看 schur field split、Schur factorization 以及不同的 Schur preconditioning strategies。
    PETSc PCFIELDSPLIT

  4. PETSc PCLSC。如果想理解为什么不可压流体里“近似 Schur complement”本身就是一个完整研究方向，可以从 Least-Squares Commutator preconditioner 入手。

  5. Mathew, Domain Decomposition Methods for the Numerical Solution of Partial Differential Equations, Springer, 2008。偏矩阵视角，覆盖 substructuring、Lagrange multiplier、saddle-point systems 和 nonmatching grids，适合继续把线性代数结构与 PDE 求解对应起来。
