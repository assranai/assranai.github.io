Jacobian-Free Newton–Krylov：不构造 Jacobian 也能解非线性有限元

Oct 04, 2026
阅读时长: 3 分钟

主题：Jacobian-Free Newton–Krylov（JFNK）
领域：非线性有限元 × 数值优化 × 物理求解器
阅读时间：约 4–5 分钟

核心问题：求解非线性方程，是否真的需要知道 Jacobian 矩阵的每一个元素？

在大型非线性有限元中，构造和存储切线刚度矩阵往往是昂贵的。尤其对于超弹性、多物理场耦合或复杂本构模型，推导和实现一致切线矩阵本身就是一项工程负担。

JFNK 提供了另一条路线：保留 Newton 法的非线性求解能力，却不显式构造 Jacobian，而是通过残差函数直接计算 Jacobian 对向量的作用。

这一思想已经广泛应用于大型 PDE 求解。Knoll 与 Keyes 在 2004 年发表于 Journal of Computational Physics 的经典综述中，系统讨论了 JFNK 的理论、预条件策略及其在计算物理中的应用。

一、Newton 法真的需要完整 Jacobian 吗？

考虑非线性有限元方程：

\[ R(u)=0, \]

其中 \(u\in\mathbb R^N\) 是节点自由度，\(R(u)\) 是残差。

Newton 法每次迭代求解：

\[ \boxed{ J(u_k)\Delta u=-R(u_k) } \]

其中：

\[ J(u)=\frac{\partial R}{\partial u}. \]

传统实现需要组装 \(J\)，然后求解线性系统。

但如果使用 GMRES 等 Krylov 迭代方法，情况就不同了。

GMRES 构造的 Krylov 子空间为：

\[ \mathcal K_m(J,r) = \operatorname{span} \{r,Jr,J^2r,\ldots,J^{m-1}r\}. \]

观察这个表达式：算法反复需要的是

\[ \boxed{Jv} \]

即 Jacobian 与某个向量的乘积。

它并不要求事先知道整个 \(J\)。

这就是 JFNK 成立的关键。

二、最重要的公式：用两次残差计算代替 Jacobian

根据方向导数的定义：

\[ J(u)v = \lim_{\varepsilon\to0} \frac{R(u+\varepsilon v)-R(u)}{\varepsilon}. \]

因此可以近似为：

\[ \boxed{ J(u)v\approx \frac{R(u+\varepsilon v)-R(u)}{\varepsilon} } \]

这里：

  • \(u\)：当前 Newton 迭代位置；
  • \(v\)：GMRES 提供的搜索方向；
  • \(\varepsilon\)：有限差分扰动幅度。

由于 \(R(u)\) 在当前 Newton 步可以缓存，每次计算 \(Jv\) 通常只需要额外调用一次残差函数。

举一个二维例子：

\[ R(u)= \begin{bmatrix} u_1^2+u_2-3\\ u_1+\sin u_2-1 \end{bmatrix}. \]

在

\[ u=(1,0)^T,\qquad v=(1,2)^T \]

处，真实 Jacobian 为：

\[ J= \begin{bmatrix} 2&1\\ 1&1 \end{bmatrix}. \]

所以：

\[ Jv= \begin{bmatrix} 4\\3 \end{bmatrix}. \]

但即使完全不知道这个矩阵，也能计算：

\[ \frac{R(u+\varepsilon v)-R(u)}{\varepsilon} = \begin{bmatrix} 4+\varepsilon\\ 3+O(\varepsilon^2) \end{bmatrix}. \]

当 \(\varepsilon\) 足够小时，结果趋近于真实 \(Jv\)。

这意味着：只要能够计算非线性残差，就具备了实现基础 JFNK 的核心条件。

PETSc 和 Trilinos 均提供了相应的矩阵自由实现。

三、为什么不构造 Jacobian，仍然需要预条件器？

查看完整推导与细节

这是 JFNK 最容易被误解的地方。

虽然 GMRES 只需要 \(Jv\)，但如果 \(J\) 的条件数很大，GMRES 可能需要大量迭代。

假设每次残差计算需要 20 ms。

如果一个 Newton 步需要 200 次 GMRES 迭代，仅矩阵向量乘法对应的残差计算就可能消耗约 4 秒。

因此工程上通常使用：

\[ \boxed{\text{Preconditioned JFNK（PJFNK）}} \]

引入预条件器 \(P\)，使其近似：

\[ P\approx J. \]

但 \(P\) 不需要与真实 Jacobian 完全一致。

例如在隐式弹性动力学中：

\[ R(x)= \frac{M}{h^2}(x-y) + f_{\mathrm{int}}(x) - f_{\mathrm{ext}}. \]

真实 Jacobian：

\[ J= \frac{M}{h^2} + \frac{\partial f_{\mathrm{int}}}{\partial x}. \]

可以构造一个简化预条件矩阵：

\[ \boxed{ P=\frac{M}{h^2}+K_{\mathrm{approx}}. } \]

其中 \(K_{\mathrm{approx}}\) 可以来自线性弹性近似、简化本构或较少更新的切线刚度。

于是形成两套不同精度的计算：

部分 采用的模型 目的
Newton 残差 完整非线性物理 保证求解目标正确
Jacobian-vector product 完整残差的方向导数近似 提供 Newton 线性化信息
预条件器 简化物理模型 加速 Krylov 收敛

这是 JFNK 很有价值的工程结构：高保真物理负责正确性，低成本近似负责计算效率。

MOOSE 的官方文档明确采用这种设计。其 PJFNK 求解器可以使用近似 Jacobian 构造预条件器，并支持针对不同物理变量采用不同的预条件策略。

四、JFNK 还有一个重要优化：不必每次都精确求解 Newton 方程

查看完整推导与细节

传统 Newton 实现容易陷入一种计算浪费：

当前非线性残差还很大，却花费大量 GMRES 迭代，将线性方程求解到极高精度。

实际上，Newton 步只需要满足：

\[ \boxed{ \|J_k\Delta u_k+R_k\| \leq \eta_k\|R_k\| } \]

其中 \(\eta_k\) 是允许的线性求解相对误差。

这就是 Inexact Newton（非精确 Newton） 的基本思想。

当非线性求解距离最终解还很远时，可以采用较宽松的线性容差；随着 Newton 迭代接近收敛，再逐渐提高精度。

Eisenstat 与 Walker 在 1996 年研究了如何自适应选择 \(\eta_k\)，避免过度求解，同时保持良好的局部收敛性质。

这类策略在 PETSc 中已有直接实现。

因此，一个成熟的 JFNK 求解器实际上结合了三个层次：

\[ \boxed{ \text{Newton 非线性迭代} + \text{Krylov 线性迭代} + \text{物理预条件} } \]

再通过自适应线性容差协调计算预算。

五、JFNK 的局限：残差必须足够光滑、足够准确

查看完整推导与细节

JFNK 避免了显式 Jacobian，但没有消除线性化的数学要求。

首先，有限差分扰动 \(\varepsilon\) 不能任意小。

过大：

\[ \text{截断误差增加}. \]

过小：

\[ \text{浮点舍入误差和残差噪声被放大}. \]

其次，如果残差函数包含非光滑操作，例如：

\[ R(u)=\max(0,g(u)), \]

那么在接触状态切换处，经典方向导数近似可能不稳定，Newton 收敛也可能退化。

对于摩擦、单侧接触等问题，可能需要半光滑 Newton、主动集方法或专门的正则化处理。

最后，JFNK 不一定比显式 Jacobian 更快。对于小规模问题，或者 Jacobian 可以廉价组装并重复利用的系统，显式矩阵方案可能更有效。

值得注意的是，Jacobian-free 也不等于必须使用有限差分。如果残差代码支持自动微分，可以直接计算：

\[ Jv=\operatorname{JVP}(R,u,v). \]

这样可以避免有限差分步长选择带来的误差，但需要额外的自动微分支持与计算开销。

六、对自研 FEM / 软体求解器的直接启发

查看代码与实现

假设未来使用 Neo-Hookean 材料实现隐式四面体求解器。

传统 Newton FEM 需要实现：

\[ f_{\mathrm{int}}(x) \]

以及：

\[ K_t(x)=\frac{\partial f_{\mathrm{int}}}{\partial x}. \]

后者涉及材料切线张量、单元刚度矩阵及全局稀疏组装。

采用 JFNK，可以先实现可靠的：

def residual(x):
    return inertia(x) + internal_force(x) - external_force(x)

def jacobian_vector_product(x, v, eps):
    return (residual(x + eps * v) - residual(x)) / eps

然后把 jacobian_vector_product 交给 GMRES。

这样可以将求解器开发分成三个阶段：

  1. 先实现正确的非线性残差与无预条件 JFNK，验证数学模型。
  2. 加入简化弹性刚度或质量矩阵预条件器，改善迭代收敛。
  3. 进一步尝试 AMG、自动微分 JVP 和自适应 Newton 容差。

其中第二步恰好连接第 55 张知识卡片的 Algebraic Multigrid。

需要强调：这种方案适合探索大型隐式 FEM 的实现路线，并不意味着应该直接替换现有 XPBD 求解器。两者的时间积分、约束处理和计算预算不同。

它在整个知识体系中卡在哪里？

可以将此前学习的几种求解加速方法放在同一框架中：

方法 主要减少什么成本？
Projective Dynamics 非线性全局矩阵反复变化的成本
Algebraic Multigrid 大型线性系统的迭代收敛成本
Hyper-reduction 非线性算子的评估成本
JFNK 构造和存储完整 Jacobian 的成本

它们并非相互排斥。

例如：

\[ \boxed{ \text{非线性 FEM} \rightarrow \text{JFNK} \rightarrow \text{GMRES} \rightarrow \text{AMG 预条件} } \]

就是一条具有明确工程意义的大规模隐式求解路线。

今天最值得记住的一句话：

对于迭代求解器，矩阵本身有时只是一个昂贵的中间表示；真正需要的是这个矩阵如何作用于向量。

JFNK 将这一认识用于非线性求解，因而可以把复杂物理模型的实现重点重新放回残差计算，并将预条件器设计为独立的性能优化问题。
