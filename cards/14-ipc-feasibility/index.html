IPC：为什么“无穿透”可以被写成一个优化问题，而不是靠碰撞后修补

Aug 27, 2026
阅读时长: 6 分钟

IPC：为什么“无穿透”可以被写成一个优化问题，而不是靠碰撞后修补

主题：Incremental Potential Contact（IPC，增量势接触）
领域：有限元 × 接触力学 × 非线性优化 × 物理求解器
推荐阅读时间：约 8–10 分钟

今天选 IPC，因为它正好处在几个很重要的知识交叉点：

\[ \boxed{ \text{隐式弹性动力学} + \text{Barrier Method} + \text{CCD} + \text{Newton Optimization} } \]

它解决的核心问题非常具体：

在大形变软体仿真里，怎样让接触从算法结构上保持不相交，而不是先允许穿透、再靠 penalty 或 projection 往回推？

Li 等人在 SIGGRAPH 2020 提出的 IPC，把一个时间步的弹性动力学和接触统一进同一个增量势能最小化问题，并用局部 barrier potential 阻止几何距离降到零；项目页明确强调其目标是做到 time-step 级别的 intersection-free 与 inversion-free 大形变动力学。

1. 先看普通接触方法为什么容易变得脆弱

假设两个软体表面发生接近。

Penalty contact 常见形式：

\[ f_c = k\,\max(0,-g)n \]

其中：

\[ g<0 \]

代表已经穿透。

这意味着接触力是在：

\[ \boxed{\text{非法状态已经发生之后}} \]

才开始起作用。

于是你会面对一个熟悉的三角矛盾：

\[ k\text{ 小} \Rightarrow \text{穿透大} \]\[ k\text{ 大} \Rightarrow \text{系统很 stiff} \]\[ \Delta t\text{ 大} \Rightarrow \text{更容易跨过接触面} \]

很多工程调参，本质上都在这个三角形里打转。

IPC 换了一个问题定义：

\[ \boxed{ \text{不要允许 }d=0\text{ 被跨过去} } \]

其中：

\[ d(x) \]

是两个 collision primitives 的距离。

2. IPC 的核心：给接触距离加一个 barrier potential

原始隐式动力学一个时间步可以写成某种增量势：

\[ E(x) \]

其中包含：

  • 惯性项；
  • 弹性能；
  • 外力势。

IPC 增加：

[ \boxed{ B(x)

E(x) + \kappa \sum_{k\in C} b(d_k(x)) } ]

这里：

  • \(C\)：当前可能发生接触的 primitive pairs；
  • \(d_k\)：第 \(k\) 对几何元的距离；
  • \(b(d)\)：barrier energy；
  • \(\kappa\)：barrier stiffness / conditioning parameter。

IPC Toolkit 官方文档当前仍把 contact potential 写成：

\[ B(x)=\sum_{k\in C}b(d_k(x)), \]

并提供势能、梯度和 Hessian 的直接计算接口。

Barrier 的关键性质可以粗略理解为：

\[ d\gg \hat d \Rightarrow b(d)=0 \]

而当：

\[ d\rightarrow0^+ \]

时：

\[ \boxed{ b(d)\rightarrow+\infty } \]

因此优化器越想把两个表面推到重合，目标函数就越大。

于是：

\[ d=0 \]

变成一个不可跨越的能量墙。

3. 为什么 barrier 和 penalty 的数学地位不一样？

Penalty 大概是：

[ E_p(d)

\frac{k}{2}\min(d,0)^2. ]

它在：

\[ d<0 \]

以后才惩罚。

Barrier 则工作在：

\[ d>0 \]

区域：

\[ \boxed{ \lim_{d\to0^+}b(d)=+\infty } \]

所以可以用一句话概括：

\[ \boxed{ \text{Penalty 惩罚违反约束； Barrier 阻止迭代进入违反约束的区域。} } \]

这正是 IPC 与很多传统 soft-contact formulation 最本质的区别之一。

IPC 的原始 formulation 明确采用局部支持的 barrier，只让接近碰撞的 primitive pairs 产生势能，并使离得足够远的 pair 不受影响。

4. 但 barrier 本身还不够

这是理解 IPC 最重要的一点。

你可能会想：

如果 \(b(d)\to\infty\)，那不就天然不会穿透了吗？

不完全是。

Newton iteration 会产生搜索方向：

\[ p. \]

然后尝试：

\[ x_{\rm trial}=x+\alpha p. \]

即使：

\[ x \]

当前合法，

如果：

\[ \alpha \]

太大，trial step 完全可能从：

\[ d>0 \]

直接跨到：

\[ d<0. \]

数学上 barrier 在：

\[ d=0 \]

附近发散，并不代表一个离散 Newton step 不会直接“跳过墙”。

所以 IPC 必须再加入：

\[ \boxed{\text{CCD-controlled line search}} \]

这就是 CCD 在 IPC 中真正具有决定性地位的原因。

5. CCD 在这里不是“碰撞检测完再处理”，而是控制优化步长

给定：

\[ x \]

和 Newton direction：

\[ p, \]

考虑轨迹：

\[ x(\alpha)=x+\alpha p, \qquad 0\le\alpha\le1. \]

CCD 询问：

\[ \boxed{ \text{沿这条连续运动轨迹，第一次发生接触的 }\alpha_{\rm hit}\text{ 是多少？} } \]

然后约束：

\[ \alpha<\alpha_{\rm hit}. \]

于是新的：

\[ x+\alpha p \]

仍然位于：

\[ d>0 \]

的可行区域。

原始 IPC 算法把这一过程直接写进 barrier-aware Newton：先求 Newton direction，再用 CCD 得到 step-size upper bound，然后继续做能量下降 line search。

因此可以非常准确地拆成：

\[ \boxed{ \text{Barrier：告诉优化器不要靠近边界} } \]\[ \boxed{ \text{CCD：保证单次离散搜索步不会跨过边界} } \]

这两者缺一不可。

6. 这也解释了“CCD 才是合法性的决定性约束”为什么只对了一半

如果只讨论：

\[ \boxed{ \text{某一次 Newton step 是否会穿过去} } \]

那么确实：

\[ \text{CCD} \]

非常关键。

因为它直接保证 trajectory feasibility。

但如果只有 CCD，没有 barrier：

每次 Newton step 虽然不允许真正撞上，

优化器可能不断得到一个指向接触面的方向：

\[ p\rightarrow d=0. \]

于是：

\[ \alpha\rightarrow0 \]

求解会越来越难推进。

Barrier 则改变目标函数梯度：

[ \nabla B

\nabla E + \kappa\nabla b. ]

越靠近接触面：

\[ \nabla b \]

越强，

所以 Newton direction 本身会逐渐形成物理上的排斥响应。

因此：

\[ \boxed{ \text{CCD 管“不能走到哪里”， Barrier 管“优化器为什么不应该往那里走”。} } \]

这一区分非常重要。

7. 为什么把接触写成“势能”这么有价值？

因为弹性动力学本身已经可以写成一个 optimization problem。

例如 Backward Euler / variational time integration 常可得到类似：

[ x^{n+1}

\arg\min_x \left[ \frac{1}{2h^2} (x-\tilde x)^TM(x-\tilde x) + \Psi(x) \right]. ]

现在加入：

\[ \kappa B_{\rm contact}(x) \]

以后：

[ \boxed{ x^{n+1}

\arg\min_x \left[ E_{\rm inertia} + E_{\rm elastic} + E_{\rm contact} \right]. } ]

于是 contact 不再是时间步后附加的：

1
2
3
4

solve elasticity
→ detect penetration
→ push apart
→ repair velocity

而变成：

\[ \boxed{ \text{整个时间步解的是一个统一的 coupled state} } \]

这正是 IPC 很强的 formulation-level 优势。

8. 它和上一期的 Complementarity 在哪里分叉？

Complementarity 接触通常写：

\[ g\ge0, \qquad \lambda\ge0, \qquad g\lambda=0. \]

它显式引入 dual variable：

\[ \lambda. \]

IPC 原始 primal barrier formulation 则主要在位置变量：

\[ x \]

上优化：

\[ \min_x E(x)+\kappa B(x). \]

因此可以粗略比较：

\[ \boxed{ \text{Complementarity：显式处理约束反力/冲量} } \]\[ \boxed{ \text{IPC：把约束效应编码进 primal energy landscape} } \]

IPC 原论文也特别讨论了为什么采用 primal barrier：如果对数量巨大的 collision primitive pair 都增加拉格朗日乘子，系统规模会大幅增加，因此他们选择了更适合大量接触约束的 primal formulation。

这是理解两条现代接触路线差异的很好切口。

9. 为什么 IPC 特别适合大形变 FEM？

因为大形变软体接触有三个问题同时存在：

\[ \text{elastic nonlinearity} \]\[ \text{contact nonlinearity} \]\[ \text{geometry nonlinearity}. \]

如果你分别做：

\[ \text{elastic solve} \rightarrow \text{collision correction} \]

它们会互相打架。

例如：

弹性力希望继续压缩，

contact projection 又把节点推出去，

下一次 elastic solve 又拉回来。

IPC 把二者统一为：

\[ \boxed{ \nabla \left( E_{\rm elastic} + E_{\rm contact} \right) =0. } \]

于是最后状态是：

材料变形和接触排斥共同作用下的势能平衡。

原始论文展示了 Neo-Hookean 四面体在强压缩、复杂接触甚至狭窄障碍中的稳定模拟，并强调可以在较大时间步下保持 intersection-free。

10. 为什么 Hessian 又成了一个麻烦？

Newton 法需要：

\[ H=\nabla^2 B(x). \]

但 contact barrier 和某些非线性弹性能的 Hessian：

\[ H \]

并不一定处处正定。

如果直接求：

\[ Hp=-g, \]

可能得到：

\[ g^Tp>0, \]

即：

\[ p \]

甚至不是下降方向。

所以 IPC 使用：

\[ \boxed{\text{SPD projection}} \]

把 Hessian 调整为正定/半正定近似，然后得到稳定 descent direction。

原始算法流程里明确包括：

\[ H\leftarrow\operatorname{SPDProject}(\nabla^2B). \]

这和 Projective Dynamics / quasi-Newton 的思想再次产生联系：

Hessian 的处理方式，往往直接决定非线性物理求解器能不能稳定工作。

这也是为什么 IPC 不能简单概括成“barrier contact”。

12. IPC 为什么还需要 broad phase / constraint culling？

理论上所有三角形、边、点都可能碰撞。

如果有：

\[ N \]

个 primitives，

naive pair 数量：

\[ O(N^2). \]

这是完全不能接受的。

但 IPC barrier 有局部支持：

\[ d>\hat d \Rightarrow b(d)=0. \]

因此只需要维护：

\[ \boxed{ \text{距离足够近的 active constraint set} } \]

而不是所有几何 pair。

这也是现代 IPC Toolkit 持续优化 broad phase 的原因。2026 年 2 月发布的 v1.5.0 已加入 fully parallel LBVH broad phase，同时加入新的接触势 formulation。

所以一个实际 IPC solver 的性能并不仅由：

\[ \text{linear solver} \]

决定。

collision candidate generation 本身就是大头。

13. C-IPC 为什么很重要？

原始 IPC 主要处理实体表面接触。

但很多图形学对象是：

  • cloth：二维曲面；
  • rods：一维曲线；
  • particles：零维点；
  • volumetric solids：三维体。

2021 年的 Codimensional IPC（C-IPC） 把这一体系扩展到：

\[ 0D,1D,2D,3D \]

几何组合，并加入厚度、应变限制和摩擦等处理。论文明确强调其目标是让 mixed-dimensional systems 仍保持 interpenetration-free。

它还提出 ACCD——一种 additive continuous collision detection，用 conservative advancement 逐步逼近 time of impact，主要用于薄结构极严格的碰撞精度要求。

这说明 IPC 真正形成的已经不是一个单点算法，而是一套：

\[ \boxed{ \text{optimization-based contact simulation family} } \]

14. IPC 的局限在哪里？

第一，它不便宜。

每个时间步可能需要多次：

\[ \text{broad phase} + \text{barrier gradient/Hessian} + \text{sparse solve} + \text{CCD} + \text{line search}. \]

相比简单 XPBD/Sequential Impulse：

\[ \boxed{ \text{鲁棒性换计算成本} } \]

非常明显。

第二，CCD 本身必须高度可靠。

如果 CCD 漏掉：

\[ \alpha_{\rm hit}, \]

整个“可行性保证”就可能被破坏。

第三，接触距离接近 barrier 区域时会带来很强的条件数变化，因此 barrier stiffness、Hessian conditioning 和 linear solver 都非常关键。

第四，对游戏实时物理而言，“严格无穿透”并不总值得它的成本。很多场景更愿意接受：

\[ 0.1\text{ mm penetration} \]

换取：

\[ 60/120\text{ FPS}. \]

所以 IPC 更像：

\[ \boxed{ \text{high-fidelity / robust simulation formulation} } \]

而非所有实时引擎都应该照搬的默认方案。

15. 但它对自研求解器有一个非常强的迁移价值

IPC 最值得学的并不是具体 barrier 函数。

而是：

\[ \boxed{ \text{把“物理合法性”放进优化路径本身。} } \]

你可以把求解器分成三个层次：

物理目标

\[ E(x) \]

决定：

系统倾向去哪里。

可行域

\[ d(x)>0 \]

决定：

哪些状态根本不能去。

数值路径

\[ x_k\rightarrow x_{k+1} \]

决定：

求解器是否会在寻找答案途中越过非法区域。

很多不稳定 solver 只设计了第一层。

稍好的 solver 设计：

\[ E+\text{constraint}. \]

IPC 更进一步考虑：

\[ \boxed{ \text{连 optimizer trajectory 本身也必须合法。} } \]

这是非常深的一层。

16. 这对 tet inversion 也有直接启发

假设材料要求：

\[ J=\det F>0. \]

普通 Neo-Hookean 在某些实现或数值路径下，可能仍然面临：

\[ J\rightarrow0 \]

甚至跨入：

\[ J<0. \]

IPC 类思想会促使你把问题拆成：

\[ \boxed{ \text{材料能量是否阻止 }J\to0？ } \]

以及：

\[ \boxed{ \text{Newton / XPBD correction step 是否可能一步跨过 }J=0？ } \]

这与接触完全同构：

\[ d>0 \]

对应：

\[ J>0. \]

所以你会自然想到：

\[ \boxed{ \text{barrier on }J + \text{step-size feasibility check} } \]

这就是 IPC formulation 对软体反转问题很强的迁移启发。

17. 一个很实用的自研调试指标：Feasibility Margin

如果做类似 IPC/Barrier 的 solver，我会建议每个 Newton/constraint iteration 都记录：

\[ d_{\min} \]

以及：

\[ J_{\min}. \]

再记录候选方向：

\[ p \]

对应的：

\[ \alpha_{\rm feasible}. \]

比如：

\[ \alpha_{\rm feasible}\ll1, \]

说明你的搜索方向一直猛烈撞向可行域边界。

这时真正的问题可能并不是：

CCD 太保守。

更可能是：

\[ \boxed{ \text{gradient/Hessian/constraint coupling 产生了很差的优化方向。} } \]

这是一种比单看 penetration count 更有价值的 solver diagnostic。

今天值得留下的一句话

IPC 最值得记住的不是：

[ B(x)

E(x) + \kappa\sum b(d_k). ]

而是：

\[ \boxed{ \text{物理合法性既要体现在最终状态，也要体现在求解路径中。} } \]

进一步拆开：

\[ \boxed{ \text{Barrier 塑造能量地形； CCD 守住可行域； Newton 找平衡点。} } \]

这三个模块各自解决不同问题。

理解这一点之后，很多看起来相近的词会彻底分开：

\[ \text{penalty} \neq \text{barrier}, \]\[ \text{CCD} \neq \text{contact response}, \]\[ \text{collision detection} \neq \text{contact solve}. \]

而从更大的知识体系看，IPC 是一个非常典型的例子：

\[ \boxed{ \text{现代物理求解器正在越来越像“带几何可行域的非线性优化器”。} } \]

这条思想会继续连接到 frictional optimization、strain limiting、injectivity preservation，以及更广义的 constrained differentiable simulation。
